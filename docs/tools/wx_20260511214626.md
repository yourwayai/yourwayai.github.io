### 💡 算不清的糊涂账，拖慢了你赚钱的脚步

当你接到一个外包项目，或者开始自己的小微创业时，最让人头疼的往往不是写代码或打磨产品，而是**财务与账单管理**。

“客户又要求修改报价单，Excel 模板的排版全乱了……”  
“上个月的几笔尾款到底收没收？发票开给谁了？”  
“订阅制服务的账单每个月都要手动发邮件催款，实在太繁琐！”

市面上的专业财务 SaaS 软件不仅订阅价格昂贵，而且功能繁杂到让人劝退；而用传统的电子表格记账，一旦业务量增加，极其容易漏记、错记，甚至出现坏账。作为一个技术人或创业者，你需要一个轻量、专业、多端同步，且数据完全掌握在自己手里的工具。

### 💡 InvoiceShelf——接管你的全生命周期财务流

**InvoiceShelf** 就是为了解决上述痛点而生的一款完全开源的财务应用。它专为追踪日常费用、记录项目付款以及创建极其专业的发票和估价单而设计。

在技术底层上，它极其扎实。Web 端基于 PHP 领域的王者框架 **Laravel** 和前端利器 **VueJS** 构建，而即将推出的移动端则采用了跨平台的 **React Native**。作为知名开源项目 Crater 的精神续作，InvoiceShelf 不仅继承了其优秀的业务逻辑，还全面拥抱了现代化的技术栈（系统核心已升级至 PHP 8.4+）。  
最重要的是，它原生支持 Docker Compose 容器化部署，让你可以轻松将这个“私人财务部”架设在自己的云服务器或 NAS 上，实现彻底的数据隐私自由。

### 💡 为什么它是你的记账“版本答案”？

不要觉得开源工具在颜值和体验上会打折扣，InvoiceShelf 在功能设计的细节上甚至超越了许多付费软件：

**1. 极简且极其专业的票据系统**  
从项目初期的**估价单（Estimates）** 生成，到项目交付后的**发票（Invoices）** 开具，再到最终的付款追踪，它提供了一站式闭环。你可以在系统中自定义票据字段、上传公司 Logo、配置默认地址和备注。导出的 PDF 账单排版精美，让你在客户面前显得极具契约精神与专业度。

**2. 客户专属门户与自动化收款**  
告别“微信发截图催款”的尴尬！InvoiceShelf 支持为你的每个客户创建专属的**客户门户（Customer Portal）**。你可以直接在系统中一键发送带有账单链接的邮件给客户。更硬核的是，它即将/已经集成了 **Stripe 支付体系**，客户点开链接就能直接用信用卡完成支付，系统自动核销对账，效率拉满。

**3. 多公司管理与周期性账单**  
如果你手头有多个独立工作室或马甲，完全不需要部署多套系统。它原生支持**多公司（Multiple Companies）** 功能，可以在多个财务实体间无缝切换。对于提供订阅制服务或长期运维合同的开发者，它的 **周期性发票（Recurring Invoices）** 功能可以按你设定的频率（如每月/每年）自动生成并发送账单，彻底释放你的记忆力。

**4. 无痛的自动化运维体验**  
自托管项目最怕的就是后续升级折腾。InvoiceShelf 内置了非常智能的 **安装向导（Installation Wizard）** 和 **应用内自动更新（Automatic Update）** 机制。每次大版本迭代，系统会自动检测服务器的 PHP 环境和扩展是否达标，如果符合要求，在网页端点按一下即可完成丝滑升级，极大降低了运维心智负担。

### 💡 使用 Docker 十分钟搭建财务后台

为了让你最快体验到它的魅力，官方强烈推荐使用 Docker Compose 进行部署。以下是具体的实战配置步骤：

**步骤 1：准备核心配置文件**  
在你的服务器上创建一个专属目录，并新建 `docker-compose.yml` 文件。我们将同时拉取应用本身和所需的 MySQL 数据库：

```
# docker-compose.yml 基础部署配置  
version: '3.8'  
  
services:  
  app:  
    image: invoiceninja/invoiceninja:latest # 此处以同类开源镜像占位，请根据官方文档替换为 InvoiceShelf 官方镜像名  
    container_name: invoiceshelf_app  
    restart: unless-stopped  
    ports:  
      - "8000:80"  # 将宿主机的 8000 端口映射给系统  
    environment:  
      # 数据库连接环境配置  
      - DB_CONNECTION=mysql  
      - DB_HOST=db  
      - DB_PORT=3306  
      - DB_DATABASE=invoiceshelf  
      - DB_USERNAME=invoice_user  
      - DB_PASSWORD=your_secure_password  
      # 替换为你实际访问的域名或 IP  
      - APP_URL=http://your_domain_or_IP:8000  
    depends_on:  
      - db  
  
  db:  
    image: mysql:8.0  
    container_name: invoiceshelf_db  
    restart: unless-stopped  
    environment:  
      - MYSQL_DATABASE=invoiceshelf  
      - MYSQL_USER=invoice_user  
      - MYSQL_PASSWORD=your_secure_password  
      - MYSQL_ROOT_PASSWORD=root_secure_password  
    volumes:  
      # 数据持久化，防止重启丢失账单数据  
      - db_data:/var/lib/mysql  
  
volumes:  
  db_data:
```

*注：因 InvoiceShelf 仍在快速迭代，若上述镜像暂未在 Docker Hub 官方源上线，请使用 `[此处需补充具体安装代码]` 占位，并参考官方 GitHub 仓库的最新 `docker-compose.example` 覆盖上述配置。*

**步骤 2：启动并进入安装向导**  
在 `docker-compose.yml` 所在的目录下，执行以下命令在后台启动服务：

```
# 拉取镜像并后台运行所有容器  
docker-compose up -d  
  
# 查看容器运行状态  
docker-compose ps
```

**步骤 3：初始化你的专属金库**  
服务启动后，打开浏览器访问 `http://你的服务器IP:8000`。你将看到一个设计清爽的 Web 安装向导。按照提示填入刚刚在配置文件中设定的数据库信息，并创建一个管理员账号，即可进入你的私人财务控制台！（**极客建议：** 生产环境中，强烈建议使用 Nginx 反向代理并配置 HTTPS 证书，确保客户财务数据的传输安全。）
