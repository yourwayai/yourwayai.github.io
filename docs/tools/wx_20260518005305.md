### 告别玩具：有灵魂、知进退的赛博助理

**Mercury Agent** 由 Cosmic Stack 团队开发，是一个由“灵魂驱动”、具备极强权限管理、自带 Token 预算控制，并且支持跨频道（CLI 与 Telegram）访问的本地 AI 智能体。

与那些套着网页壳子的通用大模型（LLM）不同，Mercury 是真正跑在你本地机器上的守护进程（Daemon）。它能读取文件、执行脚本、抓取网页，但它最与众不同的核心价值在于两点：**“在行动前询问”** 和 **“记住真正重要的事情”**。它不是一个冷冰冰的代码执行器，而是一个会随着你日常交流不断成长的专属外包工程师。

### 核心功能与优势详述

Mercury 并非简单的命令行工具，它的底层设计充满了极客美学。以下是它最强悍的 4 个核心能力：

**1. 真正的“第二大脑”**  
这是 Mercury 最令人惊艳的特性。它内置了基于 SQLite 和 FTS5（全文检索）的结构化记忆系统。默认情况下，它会在你每次对话结束后，自动提取 0-3 个核心事实（包括你的偏好、当前目标、习惯和约束条件等 10 种记忆类型）。  
**强在哪里**：当你下周再跟它聊天时，不需要前置上下文，它会根据你的 Prompt 自动检索并注入最匹配的 5 条记忆。甚至每隔 60 分钟，它还会自动在后台进行记忆碎片整理（Auto-consolidation），解决记忆冲突。它比你自己更清楚你上个月写的业务逻辑。

**2. 铁壁般的权限控制**  
让 AI 在本地执行 Shell 命令和读写文件是一把双刃剑。Mercury 采用了绝对保守的防御机制。它内置了 Shell 黑名单（永远拒绝执行 `sudo` 或 `rm -rf /` 等危险指令）。  
**强在哪里**：它拥有“Ask Me”和“Allow All”两种模式。在默认的“Ask Me”模式下，当它需要修改系统配置或执行代码时，会直接在终端弹出一个交互式的 Y/N/A 选项让你二次确认。你可以放心地让它处理复杂的本地任务，享受“一切尽在掌握”的安全感。

**3. 全天候守护与跨端联动**  
Mercury 不是一个用完即走的脚本。你可以通过 `mercury up` 命令将其安装为操作系统的后台服务（支持 macOS, Linux, Windows）。  
**强在哪里**：它是一个 24/7 在线的工作流引擎。你可以下班前在本地 CLI 让它写一段爬虫，然后出门在地铁上通过 Telegram 发送指令检查进度。Telegram 端还支持多用户组织架构，你可以授权团队成员一起使用这个配置好特定技能的 Agent，同时它支持实时流式回复和消息编辑，体验极其丝滑。

**4. 精打细算的 Token 大管家**  
用过 API 的人都知道，无节制的 Agent 很容易导致账单爆炸。Mercury 内置了每日 Token 预算系统。  
**强在哪里**：当使用量达到 70% 时，它会自动切换到“极简模式”来节省开销。你可以随时通过 `/budget` 命令查看剩余额度，彻底告别月底看到账单时的心肌梗塞。此外，它支持多模型无缝回退（DeepSeek, OpenAI, Anthropic, 本地 Ollama），主干网络断了自动切换备用模型，绝不掉线。

### 🛠️ 快速上手指南

Mercury 的工程化做得非常完善，对 Node 环境十分友好。跟着下面的步骤，3 分钟就能在你的电脑上唤醒你的专属 Agent。

**步骤 1：全局安装并初始化**  
首先确保你的机器上有 Node.js 环境（推荐 18+）。

```
# 通过 npm 全局安装 Mercury  
npm i -g @cosmicstack/mercury-agent  
  
# 启动向导，配置你的名字和默认调用的模型（支持 DeepSeek 等性价比王）  
mercury
```

*注：初次运行会触发交互式配置，按照提示输入你的 API Key 即可。*

**步骤 2：启动全天候守护进程（推荐）**  
这是最能发挥 Mercury 实力的运行方式，将其注册为开机自启的系统服务。

```
# 一键安装系统服务、启动后台进程并确认运行状态  
mercury up  
  
# 如果你需要查看后台日志  
mercury logs
```

**步骤 3：绑定 Telegram（解锁移动端办公）**  
在 Telegram 中向你的 Bot 发送 `/start` 获取配对码（Pairing code）。回到你的电脑终端输入以下命令：

```
# 批准该配对码，你将成为第一个拥有最高权限的 Admin  
mercury telegram approve <你的配对码>
```

绑定成功后，你的 Telegram 就是你的私人 AI 运维指挥中心了。你可以随时输入 `/tools` 查看它目前掌握的技能，或者用 `/memory` 查看它都偷偷记住了你哪些习惯。
