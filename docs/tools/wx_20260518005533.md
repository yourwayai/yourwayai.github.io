### 🛑 为什么你的 AI 视频总是做不成“一部剧”？

在当前的 AI 影视创作圈，大家通常面临一个极度撕裂的工作流：你需要用 ChatGPT 写剧本，把大段文字丢进 Excel 人工拆解分镜；接着去 Midjourney 抽卡生成角色图，再去 Runway 或 Sora 生成视频片段。

现实情况是，上一个镜头主角还穿着现代西装，下一个镜头就莫名其妙变成了中世纪骑士。**角色一致性** 成了所有创作者的噩梦。此外，漫长的生图和视频渲染过程经常导致浏览器卡死，没有任何任务进度追踪，一切全凭运气。你需要的不只是一个“会生图的 AI”，而是一个能够像真正的影视工业体系一样，统筹剧本、角色、分镜和渲染的**中枢工作台**。

### 🌟 Jellyfish，你的私人 AI 影视制片厂

**Jellyfish（水母）** 就是为了打破这种低效的“手工作坊”模式而诞生的。它是一个开源的端到端 AI 短剧生产工作台。

它不是那种单一的“一键生图/视频”小工具，而是一个真正懂影视制作的系统。从你输入一段长篇剧本开始，Jellyfish 就能直接接管后续流程：它会自动将剧本结构化为分镜，集中管理所有人物和场景的一致性，编排生成任务，并最终导出视频。它将大模型的能力下沉为基础设施，让个人创作者也能拥有媲美专业工作室的工业化生产力。

### 🔍 Jellyfish 到底强在哪里？

#### 1. 剧本理解与智能分镜拆解

告别手动复制粘贴，Jellyfish 可以直接读取你的剧本章节。系统会自动将大段文本拆解为独立的镜头（Shots），并从中精准提取出角色（Characters）、场景（Scenes）、道具（Props）和台词对话。  
它还内置了剧本优化、简化和一致性检查功能，甚至能专门针对某个角色生成人物小传或场景细节，让后续的画面生成有据可依。

#### 2. 彻底解决一致性的“资产管理”系统

这是 Jellyfish 最硬核的杀手锏。系统在底层维护了一个全局共享的**实体模型（Entity Model）**。  
你只需要建立一次角色、场景或服装的档案，在后续成百上千个镜头的生成中，系统都会强制链接并复用这些资产。这种中心化的资产管理方式，从根本上防止了 AI 生成过程中常见的“风格漂移”和“角色变脸”问题，让你的整部短剧看起来就像是同一个剧组拍出来的。

#### 3. 统一的异步生成任务中心

视频生成往往需要极长的等待时间。Jellyfish 构建了一个极其健壮的异步任务基础设施。  
无论是文本处理、生图还是视频渲染，所有请求都会进入统一的队列。你可以随时在任务面板查看进度、已耗时间，甚至随时取消或恢复任务。生成的每一帧素材都会与特定的镜头和实体上下文深度绑定，支持随时预览和复用，再也不用在混乱的本地文件夹里大海捞针了。

### 快速上手指南：一键部署你的私人工作室

Jellyfish 的工程架构非常清晰，前端基于最新的 Web 技术栈，后端采用 Python 构建，并且官方提供了极其便利的 Docker 部署方案。以下是核心部署步骤：

#### 方案一：Docker Compose 一键启动（推荐）

如果你想快速体验，Docker 是最无痛的选择。

```
# 1. 进入官方提供的 compose 部署目录  
cd deploy/compose/  
  
# 2. 复制并配置环境变量文件  
cp .env.example .env  
  
# 3. 启动所有容器服务（包含前端、后端、MySQL、Redis等）  
docker compose --env-file .env -f docker-compose.yml up --build
```

启动后，你的前端工作台将运行在 `http://localhost:7788`，后端 API 运行在 `8000` 端口。

#### 方案二：本地硬核开发部署

如果你是开发者，想要对 Jellyfish 进行二次开发或接入自己的模型：

```
# === 启动后端服务 ===  
cd backend  
cp .env.example .env  
# 使用 uv 进行快速的依赖同步  
uv sync  
# 启动 uvicorn 开发服务器  
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000  
  
# === 启动前端服务 ===  
cd ../front  
# 安装依赖  
pnpm install  
# 启动前端开发服务器  
pnpm dev
```

**开发者小贴士**：前端所有的 API 请求方法和类型定义，都是通过后端的 OpenAPI 规范自动生成的。你只需在前端目录下运行 `pnpm run openapi:update`，即可实时同步后端接口变更，开发体验极佳。
