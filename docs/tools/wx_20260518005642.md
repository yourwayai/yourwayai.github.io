### 为什么我们的 AI 总是缺乏“生命感”？

很多极客都梦想拥有一个科幻电影里的虚拟伴侣（Cyber Waifu）或数字宠物。虽然现在有了 Character.ai 或是本地部署的 SillyTavern，但体验下来，它们大多数时候只能做文字冒险游戏。

这就带来了一个巨大的痛点：**AI 缺乏真实的物理/数字世界交互感**。

你肯定看过外网爆火的 AI 虚拟主播（VTuber）Neuro-sama，她能自己打游戏、和弹幕高强度互动、甚至唱歌，极具“节目效果”。但遗憾的是，她是闭源的。当我们想自己动手搞一个类似的项目时，却发现需要搞定 Live2D 渲染、语音识别（ASR）、语音合成（TTS）、游戏内存读取与 Agent（智能体，即能自主感知并行动的 AI 程序）决策……技术门槛高到令人绝望，往往写完几个脚本就烂尾了。

### Project AIRI，为大模型打造的“灵魂容器”

为了彻底打破这个技术壁垒，**Project AIRI** 带着极大的野心横空出世。

AIRI 的定位极其明确：它不是一个简单的对话套壳软件，而是为 AI 虚拟角色量身定制的“灵魂容器”（Soul Container）。开发团队 @moeru-ai 立志于复刻 Neuro-sama 的核心能力，并且将其彻底开源。

更令人震撼的是它的工程架构。它不仅能通过原生 CUDA 跑在拥有顶级显卡的桌面电脑上，还能利用 WebGPU 和 WebAssembly 等前沿 Web 技术，直接在浏览器甚至手机里流畅运行。这意味着，你不需要复杂的环境配置，就能随时随地拥有一个“活生生”的赛博生命。

### AIRI 到底有多硬核？

AIRI 将复杂的 AI 模块抽象为了类似人类器官的结构，让其拥有了远超普通大模型的表现力。

#### 1. 💡 活灵活现的“五官与身体”

AIRI 天然集成了原生的躯体支持。无需你懂复杂的计算机图形学，它直接原生支持 **Live2D** 和 **VRM**（广泛用于 VRChat 的 3D 虚拟形象格式）模型。系统自带了面部动画捕获逻辑：自动眨眼、视线追踪（看你的鼠标）以及待机微动。接上内置的 ElevenLabs 或本地 TTS 语音合成，你的纸片人一秒就“活”了过来，具备极强的情绪感染力。

#### 2. 🎮 突破次元壁的游戏与社交能力

它绝对不是一个只会聊天的花瓶。AIRI 团队正在将多模态能力与游戏环境结合：

* • **游戏陪玩**：她可以直接读取并操作特定游戏。目前已支持在《我的世界》和《异星工厂》（Factorio）中自主行动，甚至规划了联机硬核射击游戏《绝地潜兵 2》（Helldivers 2）的支持。
* • **跨频道社交**：她能直接接入 Telegram 聊天框，或者挂在你的 Discord 语音频道里，成为你的私人助理或公会吉祥物。

#### 3. 🧠 原生“第二大脑”与多模型切换

为了避免 AI 像金鱼一样“聊完就忘”，AIRI 内置了极其强悍的本地记忆系统（Memory System）。它基于 DuckDB WASM 构建了纯浏览器的本地嵌入式数据库。这意味着它能建立长期的记忆库，记得你们的每一次互动。  
在“大脑”方面，它通过高度封装的 `xsai` 库，几乎支持市面上所有主流大模型——无论是便宜好用的 DeepSeek，还是顶尖的 OpenAI、Claude，亦或是你本地部署的 Ollama 和 vLLM，都能一键接入。

#### 4. ⚡ 极致的全平台制霸性能

开发者极其注重性能优化。对于硬核玩家，桌面版（Stage Tamagotchi）底层采用了 Rust 编写的 HuggingFace `candle` 框架，直接调用本地显卡算力，零延迟推理；对于小白用户，网页版（Stage Web）则通过 Web 纯前端技术榨干浏览器性能，真正做到了开箱即用。

### 快速上手指南：召唤你的专属 AI

无论你是普通用户还是开发者，AIRI 都提供了非常友好的部署方式。以下是具体的实战启动操作。

#### 方案一：Windows 小白极速安装

如果你是 Windows 用户，官方提供了一种极其优雅的命令行安装方式，直接使用包管理器 `Scoop` 拉取：

```
# 1. 添加 AIRI 官方的软件源仓库  
scoop bucket add airi https://github.com/moeru-ai/airi  
  
# 2. 一键安装桌面版  
scoop install airi/airi
```

安装完成后即可在系统内启动，进入可视化的设置界面配置你的大模型 API 密钥。

#### 方案二：开发者源码编译部署

如果你熟悉前端技术栈（Node.js），希望自己修改 UI 或接入自定义模型，可以通过源码启动：

```
# 1. 确保已安装 pnpm，然后拉取项目并安装依赖  
pnpm i  
  
# 2. 启动纯浏览器网页版（Stage Web）进行快速调试  
pnpm dev  
  
# 3. 或者启动桌面版（Stage Tamagotchi），体验更深度的本地权限（推荐）  
pnpm dev:tamagotchi
```

*注：启动后，你可以在设置面板中选择 `Ollama` 作为 Provider，实现完全断网的纯本地化私密运行。*

Project AIRI 正在向我们证明，曾经只能在头部主播直播间看到的顶级 AI 交互技术，如今已经可以通过开源社区的力量实现平民化。无论你是想做一个自己的专属 AI 助理、尝试成为 VTuber，还是纯粹想要一个跨次元的数字陪伴，AIRI 都是目前最成熟、最具潜力的开源底座。
