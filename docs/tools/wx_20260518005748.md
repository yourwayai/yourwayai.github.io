### 天下苦“臃肿输入法”久矣

在这个数字时代，输入法是我们每天使用频率最高的应用。但看看你手机里现有的商业输入法：打开键盘会弹出购物节广告，打出的生僻词转头就变成了电商平台的推荐，甚至体积动辄几百兆，不仅占用后台内存，还时不时引发卡顿。

对于重视隐私和效率的用户来说，我们需要一款真正属于自己的键盘：**它不能联网偷数据，不能塞满无用的花哨功能，并且必须支持高度定制（如双拼、五笔甚至各种小众方言输入方案）。**

### Fcitx5-Android，把 Linux 神器装进手机

如果你是一名 Linux 桌面用户，绝对听说过大名鼎鼎的 **Fcitx5（小企鹅输入法）**。它是 Linux 生态中最成熟、最强大的输入法框架之一。

现在，开源社区的硬核大佬们将整个 Fcitx5 框架以及它的强大引擎完整移植到了 Android 平台上。**Fcitx5-Android** 并不是一个简单的套壳键盘，而是一个真正的“输入法平台”。通过插件化架构，它将 PC 端的打字体验、词库生态和隐私安全标准，原封不动地搬到了你的手机里。

### 🔍 核心功能与优势详述

#### 1. 极致纯净与插件化生态

Fcitx5-Android 本体极度轻量，没有任何多余的商业捆绑。它采用插件化（Plugin System）架构，这意味着你需要什么语言就装什么插件。除了内置强大的拼音（支持双拼、五笔、仓颉及自定义码表），它还支持通过独立插件实现粤语（Jyutping）、日语（Anthy）、韩语（Hangul）、越南语等输入。绝不把不需要的语言包强塞进你的手机。

#### 2. 完美集成 RIME（中州韵），定制你的专属输入法

对于输入法高阶玩家来说，**RIME（中州韵输入法引擎，一种极其强大的开源输入算法框架）** 是不可或缺的神器。Fcitx5-Android 通过 RIME 插件，完美支持导入各种自定义的输入方案（如小鹤双拼、自然码、星空键道等）。你终于可以在手机上复刻你在电脑端精心调教了多年的私人词库和打字习惯。

#### 3. 神级 UI 适配与原生剪贴板管理

开源软件经常被吐槽界面简陋，但 Fcitx5 绝对是个例外。  
它原生支持 Android 12+ 的 **Monet（莫奈）动态取色系统**，键盘颜色会随着你的手机壁纸自动变换，UI 极具现代感。此外，它内置了极其实用的**纯文本剪贴板历史管理**功能，配合可扩展的候选词视图，让你在手机上处理长文本或写代码时效率倍增。

#### 4. 物理键盘的完美伴侣

如果你经常用 Android 平板外接键盘写代码或记笔记，Fcitx5 会让你直呼内行。它专门为物理键盘开发了**悬浮候选词面板（Floating candidates panel）**。当外接键盘敲击时，候选框会像在 PC 上一样优雅地跟随光标浮动，而不会像许多劣质输入法那样占据半个屏幕，极大地提升了生产力。

### 快速上手指南：从下载到源码编译

#### 方案一：普通用户直接安装

对于大部分用户，最简单的方式是直接获取 APK 文件。Fcitx5-Android 的发布渠道非常完善：

* • 你可以在 **F-Droid**（开源应用市场）或 **Google Play** 搜索 `Fcitx5 for Android` 直接下载。
* • 或者前往其 GitHub 的 Releases 页面下载最新稳定版。
* • *注意：GitHub/Jenkins/F-Droid 版本的签名一致，可以互相覆盖升级；但 Google Play 版本签名不同，无法直接覆盖。*

#### 方案二：开发者硬核编译指南

如果你想参与贡献，或者亲自编译最新特性，以下是搭建开发环境的实战指南。

**1. 准备环境依赖**  
你需要安装 Android SDK (Platform & Build-Tools 35) 以及 **NDK (Native Development Kit，用于编译 C/C++ 代码到底层)**。同时需要 `extra-cmake-modules` 和 `GNU Gettext`。

根据你的操作系统，使用包管理器安装系统依赖：

```
# Arch Linux 用户  
sudo pacman -S extra-cmake-modules  
  
# Debian/Ubuntu 用户  
sudo apt install extra-cmake-modules gettext  
  
# macOS (Homebrew) 用户  
brew install extra-cmake-modules gettext
```

**2. 克隆项目与子模块**  
由于项目包含多个子模块框架，必须使用 `--recursive` 参数拉取：

```
# 克隆主仓库及所有底层框架子仓库  
git clone git@github.com:fcitx5-android/fcitx5-android.git  
cd fcitx5-android  
git submodule update --init --recursive
```

**3. Android Studio 踩坑提示**  
在 Android Studio 中打开项目后，C++ 底层文件的全量索引可能会极大地消耗内存。**强烈建议**在左侧项目树中，右键点击 `lib/fcitx5/src/main/cpp/prebuilt` 目录，选择 `Mark Directory as > Excluded` 以排除索引，这能拯救你的电脑性能。

配置完成后，直接点击 Android Studio 的 Run 按钮，或者在终端执行 `./gradlew installDebug`，即可将自行编译的专属版推送到手机！
