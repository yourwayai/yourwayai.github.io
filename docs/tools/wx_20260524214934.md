### 当 AI 搜索成为“隐私黑洞”

在这个万物皆可 AI 的时代，我们习惯了遇到问题就向各种 AI 搜索引擎提问。从代码报错到行业报告，从内部财务数据到个人学习笔记，我们几乎把所有信息都抛给了云端大模型。

但这背后隐藏着巨大的隐患。你的每一次搜索、每一份上传的 PDF 文档，都可能成为大厂训练下一个模型的免费语料。对于开发者和职场人来说，处理公司内部的敏感代码或是涉密文件时，使用云端 AI 工具无异于是在“裸奔”。手动搭建一套隔离的本地 AI 搜索系统又极其繁琐，既要配置大语言模型，又要处理网络爬虫和数据解析，极高的门槛让许多人望而却步。

我们需要一个既能联网搜索、能看懂复杂文件，又能**百分之百把控数据隐私**的解决方案。

### Vane，你的私有化 AI 问答引擎

今天的主角 **Vane**，正是为了解决这个痛点而诞生的开源项目。它是一个完全注重隐私的 AI 问答引擎，主打“让数据留在你的本地硬件上”。

Vane 的核心理念非常纯粹：将浩瀚的互联网知识与你选择的 LLM（大语言模型，即支撑 ChatGPT 等应用的核心 AI 模型）完美结合。无论你是想通过 Ollama 运行绝对安全的本地模型，还是想通过 API 接入 OpenAI、Claude、Gemini 等云端最强大脑，Vane 都能为你提供一个统一、整洁且功能强大的搜索入口。它在为你提供精准解答并附带引用来源的同时，确保你的搜索行为和上传的文件完全私密。

### 为什么 Vane 如此强大？

Vane 并不是一个简单的套壳 UI，它在底层设计上深度考量了开发者的真实使用场景。

##### 模型自由，随心切换的 AI 大脑

Vane 打破了单一模型的限制。如果你追求极致隐私，它完美适配 **Ollama**，你可以一键调用 Llama 3、Qwen 等本地模型；如果你需要处理极其复杂的推理任务，它同样支持填入 API Key 来调用 OpenAI、Anthropic Claude 或 Groq。你可以根据任务的涉密程度和复杂度，自由组合和切换模型，真正的“我的地盘我做主”。

##### SearxNG 强力驱动，无痕的深网搜索

普通的网页搜索很容易被追踪，而 Vane 的网络搜索由 **SearxNG**（一款保护隐私的开源元搜索引擎）驱动。这意味着 Vane 在帮你聚合多个搜索引擎结果的同时，抹去了你的身份标识。即将加入的 Tavily 和 Exa 支持，更是会让它的深度调研能力再上一个台阶。

##### 智能搜索模式与垂直域检索

Vane 针对不同场景提供了智能模式切换：想要秒出结果？开启 **Speed Mode（极速模式）**；需要深度调研？切换到 **Quality Mode（质量模式）**。不仅如此，当你明确知道信息来源时，还可以限制它只在特定域名（如技术文档网站库或学术期刊库）内进行搜索，过滤掉互联网上的无效噪音。

##### 全能的文件解析与多模态支持

无论是几十页的 PDF 财报、纯文本代码文件，还是包含信息的图片，Vane 都能轻松理解。这意味着你可以把 Vane 当作你的私人文档分析助手，即使断网，它也能基于你的本地文件给出精准的回答。加上即时显示天气、计算器、股票的小组件（Widgets），它的体验已经非常接近成熟的商业产品。

### 三分钟本地部署 Vane

官方强烈推荐使用 Docker 进行部署。通过 Docker，你可以免去繁琐的环境配置，一次性拉取并运行 Vane 及其内置的 SearxNG 搜索引擎。

**系统要求**：请确保你的电脑或服务器上已安装并运行 Docker。

打开终端，直接运行以下一行代码：

```
# 运行 Vane 及内置的 SearxNG，映射到本地的 3000 端口  
docker run -d -p 3000:3000 -v vane-data:/home/vane/data --name vane itzcrazykns1337/vane:latest
```

**参数说明**：

* • `-d`：让容器在后台运行，不会占用你的当前终端窗口。
* • `-p 3000:3000`：将容器内的 3000 端口映射到你主机的 3000 端口。
* • `-v vane-data:/home/vane/data`：创建一个名为 `vane-data` 的持久化数据卷。这一步非常关键，它能确保你的搜索历史、系统配置和上传的文件在容器重启或更新后不会丢失。

**配置指南**：

1. 1. 容器启动后，打开浏览器访问 `http://localhost:3000`。
2. 2. 首次进入会看到初始设置界面。如果你使用的是本地的 Ollama 模型，请在设置中填入你的 Ollama API 地址。

* • *Mac/Windows 用户*：通常填写 `[http://host.docker.internal:11434](http://host.docker.internal:11434)`
* • *Linux 用户*：填写 `http://<你的本地私有IP>:11434`

1. 3. 选择你已下载的本地模型（或填入各大云端 API Key），保存配置即可开始你的隐私搜索之旅！
