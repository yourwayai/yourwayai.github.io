### 强大的开源背景与核心价值

AirTranslate 是一款专为 macOS 生态设计的全局系统音频实时翻译与字幕悬浮应用。它由独立开发者 himomohi 开源，完全免费且遵循 Apache 2.0 开源协议。

与市面上绝大多数需要依赖外部麦克风收音，或者需要复杂音频路由劫持的翻译软件不同，AirTranslate 采用了最优雅的解法：直接从操作系统底层“截胡”你的系统播放音频。无论你是在看本地的无字幕电影、收听硬核英文播客，还是在使用任何视频会议软件，它都能无缝且无损地抓取这些声音，实时转化为文字，并以悬浮字幕的形式呈现在屏幕最上方。

可以说，有了它，你的 Mac 就等于拥有了一个常驻内存的原生“同声传译”小助手。

### 核心功能与优势详述

不要以为它只是一个简单的套壳翻译器，AirTranslate 在技术底层的实现思路上非常硬核。我们为你拆解了它的四大核心优势：

🚀 **系统级原生无损音频捕获**  
传统的屏幕翻译工具往往受限于收音质量。AirTranslate 直接调用了苹果官方最新的 ScreenCaptureKit（macOS 系统内置的现代屏幕与系统音频高保真采集框架）。这意味着它可以完全绕过扬声器和麦克风的物理传播路径，直接从系统内部数字层面提取音频流。  
为什么这个设计极具颠覆性？试想一下，你坐在人声鼎沸的咖啡馆里带着耳机看视频，由于采用的是底层直采技术，外界环境里的任何噪音都不会干扰到 AirTranslate 的收音。没有了物理外放的声音损耗和杂音干扰，语音识别模型能够拿到最纯净的原始音频数据，其转录准确率自然实现了质的飞跃。

⚡ **双引擎随时切换：本地隐私与云端极致**  
为了适配不同场景的安全和网络需求，开发者在应用内内置了两套相互独立的处理引擎供你随时切换：

* • **Apple 本地模式**：这一模式直接调用你 Mac 本地的 Apple Speech（苹果原生系统级语音识别）和 Apple Translation（苹果原生翻译服务）。它的优势在于**完全离线、零使用成本且绝对保护隐私**。如果你的会议涉及公司商业机密，使用这个纯本地处理管线可以确保数据不上传、不留痕。
* • **GPT 大模型模式**：对于追求极致上下文连贯性和特定专业领域词汇翻译准确度的用户，你可以填入个人的 OpenAI API Key（应用程序编程接口密钥，即允许第三方工具合法调用云端大模型的凭据令牌）。值得重点关注的是，它接入了 OpenAI 最新的 Realtime API（基于 WebSocket 的低延迟实时流式处理技术），打破了传统翻译模型往往需要等待好几秒的延迟魔咒。真正做到了主讲人话音刚落，双语字幕就已经流畅浮现。

💡 **沉浸式全局悬浮字幕与双语对照**  
我们在全屏看视频或跨国开会时，最讨厌的就是硕大的字幕框挡住代码或演示的核心画面。AirTranslate 提供了一个轻量级的透明悬浮字幕面板。你可以将它自由拖放到屏幕的任意边缘角落，系统底层的权限控制会让它始终“置顶”在所有窗口的最高层。  
并且，它的面板设计非常符合现代人的阅读习惯，源语言（外语）和翻译后的目标语言（中文）会“肩并肩”左右对照高亮显示。你在专注看屏幕时，只需用余眼在边缘扫一下“熟肉”字幕，整个学习和开会过程完全不被打断。

📂 **纯净的本地转录文档与隐私控制**  
AirTranslate 绝不仅仅是一个阅后即焚的字幕机，它更是一个强大的会议记录库。为了杜绝隐私外泄隐患，该软件没有设立任何中心化的账号系统。你的所有大模型 API Key 都会被安全地加密存放在你电脑本机的 Keychain（钥匙串，苹果系统底层的密码安全管理容器）中。  
更棒的是，你的所有翻译历史对话都不会上传云端，而是以最极简、最通用的纯文本格式（`.txt`）自动保存在你的 Mac 硬盘深处。系统会自动为你生成原文和译文两个对照文本文件，方便你后续导入到其他大语言模型中进行二次会议总结提炼。

### 快速上手与实战指南

AirTranslate 的安装和配置对小白和极客都非常友好，请跟着以下步骤进行：

*步骤 1：下载安装包并绕过安全限制*

1. 1. 前往项目 GitHub Releases 页面，下载最新打包好的 `AirTranslate.dmg`。
2. 2. 双击打开并将 `AirTranslate.app` 拖拽到“应用程序”文件夹。
3. 3. 因为这是开源且尚未经过苹果付费企业签名的独立应用，首次打开时可能会遇到 macOS 的安全拦截提示。请打开“访达”（Finder），在“应用程序”中找到该软件图标，**右键点击并选择“打开”**，然后在弹出的安全警告弹窗中再次点击“打开”即可豁免该限制。

*步骤 2：校验安全哈希值（硬核极客选项）*  
如果你对系统的安全性要求极高，可以在终端应用中运行以下 Shell（系统命令行解释器环境）代码，来校验你下载的安装包的 SHA256 哈希值（一种用于验证文件完整性、防止在下载过程中被恶意植入木马的单向加密校验码）：

```
# 1. 打开终端，使用 cd 命令进入你的下载目录，然后执行底层校验命令  
shasum -a 256 AirTranslate.dmg  
  
# 2. 查看并打印开发者官方提供的哈希值记录文件  
cat AirTranslate.dmg.sha256  
  
# 3. 对比上方两步输出的字符串序列。如果完全一致，说明下载的文件绝对安全无篡改
```

*步骤 3：配置离线翻译环境（Apple 模式必做）*  
如果你打算使用免费的本地计算模式，必须先让 macOS 将语言模型包固化到本地。  
请进入 Mac 的“系统设置 > 通用 > 语言与地区 > 翻译语言”，找到你要翻译的源语言和目标语言（例如英语和简体中文），点击后方的“下载”按钮进行离线预加载。

*步骤 4：面向开发者的本地源码编译*  
如果你本身就是一名熟练的 Swift（苹果软件生态的主力编程语言）开发者，且你的系统版本在 macOS 14 或以上，你可以直接拉取代码仓库在本地自己编译、魔改并构建：

```
# 将官方代码仓库完整克隆到你的本地电脑  
git clone https://github.com/himomohi/AirTranslate.git  
  
# 进入刚刚下载的源码主目录  
cd AirTranslate  
  
# 运行开发者提供的一键编译与自动化测试脚本  
./script/build_and_run.sh
```

*步骤 5：赋予必要权限并开始翻译*  
一切准备就绪后打开应用。首次运行时，软件会合规地请求你的**屏幕录制权限**（请放心，这是为了调用底层框架合法捕获系统内部音频的必要系统级权限途径，它并不会真的截取你的屏幕画面）和**语音识别权限**。前往系统设置完成授权后，重启应用，在左侧边栏选择你要的工作引擎，点击 "Start" 按钮，播放任意音频，尽情享受丝滑的悬浮翻译体验吧！
