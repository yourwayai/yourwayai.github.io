### 天下苦 Windows 臃肿久矣

回想一下你日常使用 Windows 的场景：买来的新电脑还没怎么装软件，内存就莫名其妙被占了一大半；打游戏正激烈时，突然因为系统的某个后台定时任务导致帧率暴跌；想要关掉烦人的系统级搜索广告、禁用自动更新，却发现必须去浩如烟海的“注册表”里跟着网上的残缺教程一步步改。

更要命的是，手动修改注册表就如同在雷区跳舞，一旦改错，轻则功能失效，重则面临系统蓝屏死机的风险。难道想要一个干净、纯粹、流畅的操作系统就这么难吗？我们真的需要一种既安全、又直观的方式，来给臃肿的系统做个彻底的“大扫除”。

### 专为纯净与性能而生的 optimizerDuck

为了解决这些痛点，**optimizerDuck** 应运而生。这是一款完全免费、开源的 Windows 深度优化工具，核心主打性能提升、隐私保护以及极简的交互体验。

不同于那些界面杂乱、甚至夹带私货的商业安全软件，optimizerDuck 是一个极为干净的纯技术驱动项目。它采用了现代化的 WPF（Windows Presentation Foundation，微软的一种桌面应用图形界面技术）框架，基于 .NET 10 开发，完美融入了 Windows 的 Fluent 现代设计语言。它不仅界面颜值极高，而且完全没有任何捆绑组件，甚至直接切断了任何遥测（Telemetry，即软件在后台自动收集用户数据上传的行为）机制。最让极客们喜爱的是，它采用了无依赖的单文件可执行程序设计，无需安装，随点随用。

### 核心功能与优势：克制、精准与安全

很多同类软件只是暴力精简系统组件，容易导致日后系统更新失败或出现各种诡异的 Bug。optimizerDuck 的强悍之处，恰恰在于它的“精准与克制”。

* • ⚡ **深度且克制的系统级调优**  
  它内置了 30 多项经过开源社区严格测试与基准验证的优化方案，涵盖 6 大核心维度。在**性能与电源**方面，它可以基于你的实际内存大小智能调整系统服务宿主（Service Host），降低键盘输入延迟，并注入定制的高性能电源计划以避免性能节流；在**GPU 调教**方面，它针对 AMD、NVIDIA 和 Intel 显卡提供了专属的注册表级时钟和电源状态优化，有效降低显示延迟；在**隐私保护**方面，只需一键即可彻底切断微软的后台追踪、广告 ID 分发以及 Cortana 数据收集。最关键的是，每一个优化开关都明确标注了风险评级（安全、中等、高风险），让你明明白白做优化，拒绝黑盒操作。
* • 🧰 **直击痛点的特性开关与内置工具箱**  
  Windows 11 的右键菜单折叠和任务栏强制设定是不是让你很抓狂？optimizerDuck 提供了一个极为直观的“特性开关（Feature Toggles）”面板。你可以一键恢复经典的右键菜单、关闭烦人的 Bing 搜索建议，或是去除快捷方式上的小箭头。此外，它还是一个全能的“系统瑞士军刀”。自带的**启动项管理器**与预装软件移除器（Bloatware Remover）能精准识别系统级的 AppX 应用包，为你清晰列出哪些是安全可删的冗余软件，哪些是不可触碰的系统核心，让你放心大胆地给 C 盘“瘦身”。
* • 🛡️ **极致的安全感与“一键后悔药”**  
  折腾系统最怕的就是翻车，而 optimizerDuck 把“安全防线”做到了极致。它不预设任何强制开启的默认操作，所有的修改权利全部交还给你。更硬核的是它底层的状态持久化机制——当你执行任何一项优化时，它都会自动在本地生成一个基于 JSON 格式的备份文件。如果感觉某项调整不合适，只需在界面上点击一次，就能瞬间撤销（One-click revert）对注册表、服务或计划任务的修改。在首次使用前，它甚至会强制引导你创建 Windows 系统还原点，真正做到零风险折腾。
