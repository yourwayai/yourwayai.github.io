### 1. 被困在聊天框里的 AI

作为每天重度使用电脑的职场人或开发者，我们常常感到一种深深的撕裂感。

一方面，大模型拥有极高智商，能写出精妙的代码、策划出完美的方案；但另一方面，当你需要把生成的方案排版进 PPT，或者需要根据要求在数十个网页中比对数据并录入系统时，你依然要像个机器一样手动点击、复制、粘贴。市面上的自动化工具往往依赖复杂的接口，一旦软件更新界面，自动化脚本就全盘崩溃。

我们需要一个真正懂视觉、能直接像人类一样操控 GUI（图形用户界面）的超级助理。

### 2. TuriX-CUA 降维打击

由 TurixAI 团队开源的 **TuriX-CUA**（Computer-Use Agent，一种能直接模拟人类控制电脑鼠标和键盘的智能体），正是为了打破 AI 与本地操作系统之间的次元壁而生。

与那些需要针对每个软件单独定制接口的伪自动化工具不同，TuriX-CUA 的核心逻辑极其霸道：**只要人类能点击到的地方，它就能点击。** 无论你是使用 WhatsApp、Excel、Outlook 还是公司内部毫无 API 支持的自研系统，它都能通过纯视觉识别和系统级指令完成操作。最重要的是，这款针对个人与研究用途完全免费开源的框架，在多平台的兼容性上做到了极致。

### 3. 为什么它能霸榜桌面自动化？

TuriX 并非只是一个套壳脚本，它在架构设计和性能表现上展现出了行业顶尖的统治力。

* ⚡ **SOTA 级别的恐怖执行力**  
  在业界权威的多模态桌面智能体评测基准 **OSWorld** 中，TuriX 斩获了全榜第三（总得分 64.2%）的傲人战绩。尤其在 macOS 平台上，它在本地自测基准中达到了惊人的 80% 成功率。这意味着绝大多数的日常办公琐事，它都能一次性无错跑通。

* 🧠 **四维一体的“热插拔”多模型架构**  
  传统的 Agent 往往绑定单一模型，成本高昂且不灵活。TuriX 创新性地将系统拆分为四个角色：大脑（Brain）、行动者（Actor）、记忆（Memory）和规划师（Planner）。你可以通过简单的配置，将高智商规划交给云端（如 Gemini-3-pro），将涉及隐私的屏幕识别交由本地部署的 **VLM**（视觉语言模型，如 Ollama 跑 Llama3.2-Vision）。这种“热插拔”设计彻底消除了平台绑定。

* 🔌 **原生融合 MCP，无缝对接主流生态**  
  该项目完美支持最新的 **MCP (Model Context Protocol)** 协议。你可以直接在 Claude for Desktop 中通过 MCP 唤醒 TuriX。比如你在 Claude 查阅完最新的 AI 新闻，可以直接命令它调用 TuriX，把总结内容自动写入本地的 Pages 文档并发送给指定联系人，全程行云流水。

* 📖 **极简的 Markdown 技能库**  
  如果遇到 AI 不熟悉的专属软件怎么办？TuriX 提供了一种极其优雅的“教导”方式：**Skills（技能 playbook）**。你只需用通俗易懂的文本写一个 `.md` 文件（包含名称、描述 and 操作步骤指南），Planner 就会在遇到相关任务时，自动调取这篇指南来指导具体的操作动作。无需重写任何底层代码。

### 4. 快速上手：3分钟极速部署指南

接下来，我们以 macOS 15+ 为例（项目同样提供了 Windows 与 Linux 的专属分支支持），带你实战部署这个超级外脑。

**步骤一：构建纯净的 Python 环境**

我们需要克隆代码仓库，并使用 Conda 创建专属运行环境（建议 Python 3.12 版本）。

```bash
# 创建并激活专用的虚拟环境
conda create -n turix_env python=3.12
conda activate turix_env

# 安装项目所需的所有核心依赖包
pip install -r requirements.txt
```

**步骤二：赋予系统级操作权限**

为了让 AI 能真正接管你的电脑，你需要通过两道安全验证：

1. 打开 **系统设置 ▸ 隐私与安全性 ▸ 辅助功能**，将你的终端（如 Terminal 或 VS Code）添加进去。
2. 运行下方提供的脚本，快速激活 Safari 浏览器的底层自动化权限。

```bash
# 在终端中运行此命令，触发 Safari 的权限弹窗
osascript -e 'tell application "Safari" \to do JavaScript "alert(\"Triggering accessibility request\")" in document 1'
```

*注：执行后请在弹出的对话框中点击“允许”。*

**步骤三：配置大模型与任务清单**

核心的配置文件位于 `examples/config.json`。你可以在这里定义你的任务指令（Prompt）以及各个角色所使用的模型 API。以下是一个挂载 TuriX 官方 API 的标准配置示例：

```json
{
    "agent": {
         // 这里是你下达的具体指令！越详细成功率越高！
         "task": "打开系统设置，并切换到深色模式"
    },
    "brain_llm": {
      "provider": "turix",
      "model_name": "turix-brain",
      // 请替换为你申请的真实 API Key
      "api_key": "YOUR_API_KEY",
      "base_url": "https://turixapi.io/v1"
   },
   "actor_llm": {
      "provider": "turix",
      "model_name": "turix-actor",
      "api_key": "YOUR_API_KEY",
      "base_url": "https://turixapi.io/v1"
   }
   // 内存与规划模型的配置格式相同，此处省略...
}
```

**步骤四：一键启动执行**

配置就绪后，深呼吸，不要碰鼠标，在终端敲下启动命令：

```bash
# 启动你的专属桌面超级助理
python examples/main.py
```

你将看到屏幕上的窗口自动切换、鼠标自动游走，仿佛有一个隐形的极客正在帮你快速处理任务！
