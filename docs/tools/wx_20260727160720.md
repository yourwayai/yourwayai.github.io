# 商汤开源 SenseNova-U1-V3，高密度信息图终于能像改文档一样精确定点编辑了

* **原文链接**: [https://mp.weixin.qq.com/s/Eb3oP-OL3dtRiHw7pCcTqg](https://mp.weixin.qq.com/s/Eb3oP-OL3dtRiHw7pCcTqg)
* **作者**: YourwayAI

---

商汤科技（OpenSenseNova 团队）近日正式开源了其信息图垂直大模型系列的最新迭代版：**`SenseNova-U1-8B-MoT-Infographic-V3`**。

该版本攻克了高密度信息图“生成易、修改难”的技术瓶颈，首次将信息图的生成与编辑一体化能力在开源领域落地。

#### 💻 从生成到编辑的混合多任务（MoT）破局

要理解 V3 的突破，我们需要透视它在底层训练架构上的调整。

前代 V2 版本主要聚焦在 T2I（文生图，即通过纯文字描述直接渲染整张图像）专项能力的强化，提升整体美感和小字的清晰度。

而 V3 则选择在 MT（多任务混合，在模型基础训练阶段就混入多种不同任务形式的技术）阶段重新启动。

技术团队构建了丰富的图像编辑数据，将 T2I 任务与 IT2I（图像编辑，即输入一张图片配合一段编辑指令生成修改后图片）任务按特定比例进行联合训练，并在随后的 SFT（监督微调）和 RL（强化学习，特别是引入 DPO 与 GRPO 算法）阶段持续收敛。

这使得 U1-V3 能够无缝支持常规版面修改、单参考风格迁移、精确文本替换、单图主体卡片生成、局部伪影修复、带红框局部修改、图表编辑、版面重排、整页结构重构、以及红框掩码自然插入等 10 类极其细腻的编辑能力。

尤其在高密度文本中，以往的图像编辑模型在修改局部文字时，常常会产生类似于牛皮癣的模糊色块，或者导致周围完好的文字发生不可逆的崩坏。

U1-V3 的看家本领，是在密集小字中实现字对字的精准修复与改写，同时通过局部编码对齐，最大限度地保持非编辑区域的一致性。

#### 🛠️ 纯本地极客部署与性能基准

对于喜欢本地折腾的开发者来说，部署门槛和显存开销是考量模型成色最核心的硬指标。

根据官方文档，U1-8B 核心项目支持通过 `transformers` 后端直接进行本地推理。环境搭建推荐使用比 pip 快数十倍的新一代包管理器 `uv`（一款由 Rust 编写的高效环境与依赖管理工具）：

```
git clone https://github.com/OpenSenseNova/SenseNova-U1.git  
cd SenseNova-U1  
uv sync  
source .venv/bin/activate
```

在推理时，项目内置了可选的 `flash-attn`（闪速注意力机制，一种通过合并 GPU 读写操作极大降低显存和加速注意力计算的算法）支持。

如果本地由于 CUDA 或驱动问题不便安装，模型也会自动平滑回退到 PyTorch 内置的 SDPA（缩放点积注意力机制）计算，无需繁杂的排雷工作。

根据官方在单张 NVIDIA H100 80G（运行在 bfloat16 精度、全显存模式下）下的基准测试，在标准文生图模式下（模型加载约耗时 88.85 秒），生成一张带 4096 图像 Token 的高保真信息图：

* • **加载峰值显存**：Allocated 32.77 GiB / Reserved 33.10 GiB
* • **生成峰值显存**：Allocated 34.83 GiB / Reserved 35.82 GiB
* • **平均生成耗时**：22.10 秒
* • **每秒生成吞吐**：185.27 Token

这意味着如果开发者在本地使用轻量级显存缩减模式，单张 RTX 4090（24G 显存）或双卡环境，完全能够流畅把玩该模型。

如果是追求生产环境高并发吞吐的业务团队，项目还支持基于 LightLLM + LightX2V 的容器化部署，在双卡 GPU 上，以 `colocate`（理解与生成服务共用同一组可见 GPU 资源池）模式启动并行生成服务：

```
PYTHONPATH=/workspace/LightX2V/ \  
python -m lightllm.server.api_server \  
  --model_dir $MODEL_DIR \  
  --enable_multimodal_x2i \  
  --x2i_server_deploy_mode colocate \  
  --x2i_server_used_gpus 2 \  
  --x2v_gen_model_config /workspace/LightX2V/configs/neopp/neopp_dense_parallel_cfg.json \  
  --host 0.0.0.0 \  
  --port 8000 \  
  --mem_fraction 0.75 \  
  --tp 2
```

#### 📊 登顶评测榜与实用的“架构折中”

在图像编辑专项评测集 **WeEdit** 上，U1-V3 在 Instruction Adherence（指令遵循度）、Text Clarity（文字清晰度）和 Background Preservation（背景保持度）三项维度中，以 **5.89**的综合得分，登顶本次评测的开源模型榜单（击败了 FireRed-Image-Edit 5.87 与 HY-Image-3-Instruct5.73），仅次于部分闭源商业模型。

而在图像编辑综合基准 **GEdit-Bench** 评测中，V3 也以 **7.89** 的高分位居开源模型第一名。

然而客观来看，商汤 U1-V3 并非完美。**在做出卓越局部编辑功能的同时，模型做出了不小的架构折中。**

在 MT 阶段的联合训练中，为了给复杂的图像编辑任务腾出足够的数据配比空间，项目技术团队对部分图表（Chart）相关的训练数据比例进行了缩减。

这就直接导致其在以图表生成准确度为核心的 IGenBench 评测中（Q-ACC 为 66.3，I-ACC 为 13.2），得分落后于专注于信息图生成的 V2 前代版本（Q-ACC 71.4，I-ACC 18.3）。

简单来说，这就是一次典型的“用极少数特定生成能力的微调，换取高维编辑能力质变”的实用折中。

如果你的日常业务场景是直接渲染高精确度的折线图、柱状图，前代 V2 版本依然是更好的选择；但如果你的核心痛点是需要频繁对已有的信息图版式、文字、卡片进行微调、替换和精修，那么 V3 是目前开源界毋庸置疑的第一选择。
