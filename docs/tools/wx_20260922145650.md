Python 入门教程通常有两条路：一条是「语法速成 + 算法刷题」（LeetCode、剑指 Offer），另一条是「框架入门 + 项目实战」（Django、FastAPI、爬虫框架）。前者离「能解决实际问题」太远，后者又要铺垫太多脚手架——虚拟环境、路由、ORM、模板引擎、前端模板，写个「PDF 合并」得先装 20 个包、写 200 行配置。

更现实的痛点：很多非全职开发者（运营、财务、科研、学生）只想**把手头重复的活自动化**——把 20 个 PDF 合成一个、给合同加密码、从会议录音里导出 mp3、定时弹窗提醒喝水。他们不需要 MVC、不需要 REST API、不需要数据库，只需要**能跑、能改、依赖少、复制粘贴就能用**的脚本。

### 破局点

qxresearch-event-1 的思路极其务实：**每个应用严格控制在 10 行核心代码以内**，只用 Python 标准库 + 极少量高星第三方库（tkinter、PyPDF2、pyaudio、moviepy、win10toast、pyshorteners 等），**不写类、不写装饰器、不造轮子、只调库**。仓库按「Applications/」目录平铺 50+ 个子文件夹  
，每个文件夹里一个 `main.py` + 一个 `README.md`，README 列依赖、讲原理、给视频讲解链接。克隆下来零配置、随便进一个文件夹 `python main.py` 就能跑出功能。作者 @xiaowuc2（IBM 工程师）把这套教材用在内部培训和社区活动，强调「增强知识、创造酷东西」，不搞理论推导。

### 核心工作流拆解

#### 典型用例：把 15 个扫描件 PDF 合成一份、加密码、发给同事

**步骤 1：合并 PDF**（`Applications/Merge Multiple PDF/main.py`，8 行）

```
from PyPDF2 import PdfMerger  
import os  
  
merger = PdfMerger()  
for f in sorted(os.listdir('input_pdfs')):  
    if f.endswith('.pdf'):  
        merger.append(f'input_pdfs/{f}')  
merger.write('merged.pdf')  
merger.close()
```

依赖：`pip install PyPDF2`。把 PDF 扔进 `input_pdfs/`，跑完得到 `merged.pdf`。

**步骤 2：加密码**（`Applications/Password Protect PDF/main.py`，7 行）

```
from PyPDF2 import PdfReader, PdfWriter  
  
reader = PdfReader('merged.pdf')  
writer = PdfWriter()  
for page in reader.pages:  
    writer.add_page(page)  
writer.encrypt('your-password-2024')  
with open('merged_encrypted.pdf', 'wb') as f:  
    writer.write(f)
```

同库、同风格、无额外依赖。

**步骤 3：桌面通知「搞定」**（`Applications/Windows Notification/main.py`，6 行）

```
from win10toast import ToastNotifier  
toast = ToastNotifier()  
toast.show_toast('PDF 任务完成', 'merged_encrypted.pdf 已生成', duration=5)
```

依赖：`pip install win10toast`。Windows 原生 Toast，无需 Electron、无需 Webhook。

**全流程耗时**：装依赖 10 秒、写三脚本 2 分钟、跑通 3 秒。若要定时跑，套个 `schedule` 或 Windows 任务计划程序，再加 1 分钟。

#### 另一条线：音视频处理「不装 Premiere、不装 FFmpeg 命令行」

| 需求 | 仓库应用 | 核心库 | 代码行数 |
| --- | --- | --- | --- |
| 语音录制 30 秒存 wav | Voice Recorder | `sounddevice` + `scipy.io.wavfile` | 9 |
| mp4 提取音频存 mp3 | Extract mp3 from mp4 | `moviepy` | 8 |
| 音频实时频谱可视化 | Audio Visualization Tool | `pyaudio` + `tkinter` + `numpy` | 12 |
| 文字转语音 | Text to Speech | `pyttsx3` | 7 |

**实测**：`Extract mp3 from mp4` 对 200 MB mp4（H.264/AAC），`moviepy` 底层调 FFmpeg，提取 3 分钟音频约 4 秒，输出 128 kbps mp3。`Audio Visualization Tool` 用 `tkinter.Canvas` 画频谱条，60 FPS 下 CPU 占用 8%（M2 MacBook Air），够用于直播伴奏监听、播客录制确认有声。

#### 办公自动化小工具：依赖零外部 API、全本地跑

* • **Link Shortener**：`pyshorteners` 接 TinyURL/Is.gd/Clck.ru，6 行生成短链，适合文档里贴长参数 URL
* • **Random Password Generator**：`secrets` + `string` 标准库，0 第三方依赖，生成含符号/可读/可记三模式密码
* • **Birthday Reminder**：`tkinter` + `datetime` + `json` 持久化，启动时弹窗提醒未来 7 天生日
* • **Terminal Tricks**：`colorama` + `pyfiglet`，把终端输出变成彩色 ASCII 艺术字，适合 CLI 工具美化

### 总结

**适用人群**：

* • Python 语法入门完、想「练手有成品、改两行就能用」的初学者
* • 非开发岗需要自动化办公、不想学框架、只想复制粘贴跑通的「脚本使用者」
* • 教学场景：老师想找「每节课 1 个能跑的小作品、依赖极简、讲清楚 1 个库用法」的素材

**不适用场景**：

* • 要学软件工程（分层、测试、CI/CD、类型提示、错误处理）——这里全没有
* • 要做生产级服务（并发、安全、监控、部署）——这些脚本全是单进程、同步、无异常处理
* • 要跨平台 GUI（tkinter 在 Linux Wayland/高 DPI 下有渲染问题，macOS 需额外装 Tcl/Tk）

**一个可操作的结论**：  
把这个仓库当「**Python 标准库+高星第三方库的用法速查表**」用。遇到「PDF 怎么合并」「怎么录音」「怎么发桌面通知」「怎么做频谱图」，进对应文件夹读 10 行代码、装 1 个 `pip`、跑通、改成自己的参数，比查文档、找 Stack Overflow 快十倍。想系统学就按作者视频顺序（YouTube 搜 `qxresearch 10 lines of code`）跑一遍 50 个，大概两个周末，Python「调库能力」能从零跳到「日常自动化随手拈来」。
