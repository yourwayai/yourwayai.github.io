# Asyar 实测：Tauri+Rust 重写 Raycast，冷启动 572ms、内存 435MB、开源免费、三端通用

用过 Raycast 的人都知道那种「爽」：`⌘Space` 唤起、模糊搜索极快、扩展生态丰富、AI 聊天顺手。但也清楚那种「痛」：Electron 打底、**冷启动近 1 秒、常驻内存 300MB+、Pro 功能要订阅、Linux 彻底不支持、扩展跑 Node.js 拿全盘权限**。

看到 Asyar（GitHub: Xoshbin/asyar，542 Star、GPL-3.0、Tauri v2 + Rust + Svelte 5）时，标语是「The power of Raycast. The speed of Alfred. Privacy by design.」。官方自带基准测试：**M4 Max 上热键→窗口可见中位数 12ms、冷启动 572ms、空闲内存 435MB、安装包 64MB**。我不信邪，分别在 macOS (M4 Max)、Windows 11、Debian 12 (X11) 上装了一遍，把核心流程、AI Agents、Silent AI Commands、MCP、扩展开发全跑通。下面记录真实部署细节、踩坑、以及我认为最值得用的功能组合。

### 部署实录

**环境**：

* • macOS 15.5 (Apple M4 Max, 36GB)
* • Windows 11 24H2 (Ryzen 7940HS, 32GB)
* • Debian 12 Bookworm (X11, i7-12700, 32GB)

**安装**：

```
# macOS / Linux 一键脚本（推荐）  
curl -fsSL https://raw.githubusercontent.com/Xoshbin/asyar/main/install.sh | sh  
  
# macOS Homebrew（需信任第三方 tap）  
brew tap Xoshbin/asyar  
brew trust --tap xoshbin/asyar  
brew install --cask asyar  
  
# Windows / 手动下载：去 Releases 抓 .msi / .AppImage / .dmg
```

**首次运行**：

* • macOS：弹「辅助功能」权限授权（Snippets/窗口管理/ Silent AI 需要），去「系统设置 → 隐私与安全性 → 辅助功能」勾上 Asyar
* • Windows：无额外弹窗，直接跑
* • **Linux Wayland 注意**：全局热键、Snippets、窗口管理**在 Wayland 下不工作**（协议限制），需登出切 X11 会话，或在 DE/WM 里手动绑定 `asyar` 到快捷键（GNOME/KDE/Hyprland/Sway 文档里都有对应配置示例）

**配置同步（可选）**：Settings → Account → Encrypted Sync，设置 passphrase（Argon2id 派生 → AES-256-GCM 分项加密），自动生成 24 词 BIP-39 恢复短语。**数据只在本地加密、经 Asyar 服务器中转、不存明文**，忘 passphrase 且丢恢复短语 = 数据永久丢失。

### 核心亮点

**1. 原生性能：Rust 后端 + Svelte 5 前端，告别 Electron 开销**

| 指标 | Asyar 0.1.1 | Raycast 1.104 (稳定版) | 差异 |
| --- | --- | --- | --- |
| 热键→窗口可见 (中位数) | **12.0 ms** | 21.7 ms | **快 45%** |
| 热键→窗口可见 (p95) | **14.7 ms** | 24.0 ms | **快 39%** |
| 冷启动→可用 | **572 ms** | 888 ms | **快 36%** |
| 空闲内存 (全进程组) | **435.6 MB** | 272.6 MB | **高 60%** |
| 空闲 CPU (30s 平均) | **3.20%** | 0.04% | **高 80 倍** |
| 安装包大小 | **64 MB** | 209 MB | **小 69%** |

**解读**：

* • **延迟碾压 Raycast**：Rust 后端直接调原生 API（macOS Spotlight/Accessibility、Windows HWND、X11 Xlib），无 V8 启动、无 IPC 开销
* • **内存更高**：Tauri 进程组含 WebView (WebKit/Edge/WebView2) + Rust 后端 + 扩展 iframe，**Raycast 只算主进程，Asyar 算全家桶**；实际体感上 Asyar 更轻（无 Chromium 多进程）
* • **CPU 占用高**：Svelte 5 细粒度响应式 + Live Subtitles 轮询 + 文件索引后台任务，**配置里可关「Live Subtitles」「File Search 实时索引」降 CPU**

**2. Silent AI Commands：选中文本 → 热键 → 就地替换，启动器窗口都不打开**

这是我用完最想留下的功能。配置步骤：

1. 1. `Manage Agents → New Agent`，名字 `Grammar Fix`，System Prompt：`Reply ONLY with the corrected text — no preamble, no quotes`
2. 2. 勾选 **Run silently (no chat view)**
3. 3. Input source: `Selected text in the active app`（通过 Accessibility 读取高亮文本）
4. 4. Output action: `Replace the selection with the result`（自动备份剪贴板 → 写入结果 → 粘贴替换 → 恢复剪贴板）
5. 5. `⌘K → Set Shortcut` 绑 `⌥G`

**实测场景**：

* • VS Code 里选中一段注释 → `⌥G` → 直接变成规范英文注释
* • 邮件回复选中一段中文 → `⌥T` (另配的 Translate agent) → 就地变英文
* • 浏览器文本框改措辞、缩短、调语气，**全程不离开当前应用、不打开启动器、无确认弹窗**

**工具调用也支持**：Silent agent 可开 `tools:register` 权限，循环调用工具直到最终回复，**只在最后触发输出动作**。

**3. MCP 集成：自动检测 Claude Desktop/Cursor/Cline/Zed 配置，bun/uv 内置**

Settings → MCP：

* • 点「Auto-import」，**自动读取**`~/Library/Application Support/Claude/claude_desktop_config.json`、Cursor/Cline/Continue/Zed 同类配置
* • **内置 `bun` 和 `uv` sidecar**：`npx`/`uvx` 类 MCP 服务器**无需本机装 Node.js/Python**，首次用到时经同意对话框下载、校验 sha256、安装到 `~/.asyar/runtimes/`
* • 首次调用写/执行工具时，**按 Agent 单独弹权限确认**，不再是全局开放

**实测**：接入 `mcp-server-git`、`mcp-server-filesystem`、`mcp-server-sqlite`，**Agent 能直接在对话里跑 `git log`、读写本地文件、查 SQLite**，上下文自动保留。

**4. 扩展沙箱：双层权限门 + iframe 隔离，社区扩展不再「全盘授权」**

Raycast 扩展跑 Node.js、拿完整文件系统/网络/子进程权限。**Asyar 不同**：

* • **前端门**：IPC 路由拦截每个扩展调用，按 `manifest.json` 声明的权限放行/拦截
* • **Rust 门**：权限注册表在后端再查一遍，**前端被攻破也绕不过 Rust 层**
* • **iframe 隔离**：每个安装扩展跑在独立 iframe，**无宿主 DOM 访问、无跨扩展数据访问、CSP 禁外部脚本**
* • **通信仅走 typed `postMessage` 桥**，畸形消息直接拒绝

**权限粒度**（共 9 类）：

```
clipboard:read/write | fs:read/write | network | shell:execute | shell:open-url  
notifications:send | store:read/write | tools:register | runs:track
```

**开发体验**：`npm i -g asyar-sdk` → `asyar dev` (热更) → `asyar build` → `asyar publish`。**也能不出启动器**：`Create Extension` 选模板、`Build Extension with AI` 自然语言描述让 Agent 写代码（BYOK Anthropic key）、**My Extensions** 一键发布。

**5. 文件搜索：Rust 原生索引、按键级响应、真缩略图、macOS Quick Look 预览**

* • **Arena-based 索引非哈希表**，查询成本**由构造上界、与索引文件数无关**，100 万文件下按键延迟仍 <5ms
* • **智能默认排除**：`node_modules`、`.git`、缓存、构建产物、VM 镜像自动跳过
* • **预览**：图片真缩略图、文本/代码直接内容、macOS 其它类型 Quick Look 式预览，**全由 Rust 后端生成缓存、不把大文件塞进 UI 线程**
* • `⌘⇧F` 升级到系统原生搜索，按需不常驻

### 避坑与总结

**踩过的坑**：

1. 1. **Linux Wayland 下全局热键/片段/窗口管理全挂**——文档已明确，只能切 X11 或手动绑 `asyar` 到 DE 快捷键，**不算 Bug 但易劝退 Linux 新手**
2. 2. **空闲 CPU 3%+ 看起来吓人**——关掉 Settings → File Search「Real-time indexing」、关掉「Live Subtitles」，CPU 降到 <0.5%
3. 3. **Silent AI Commands 在某些 Electron 应用（VS Code、Obsidian）里 Accessibility 读不到选中文本**——需在应用里授权辅助功能，或改用 `Clipboard` 作为 Input source（先 `⌘C` 再热键）
4. 4. **MCP 服务器首次跑 `npx`/`uvx` 下载 `bun`/`uv` 要翻墙**（GitHub Releases 下载），国内需配代理或手动放运行时到 `~/.asyar/runtimes/`
5. 5. **扩展开发调试**：`asyar dev` 热更仅限前端，Rust 后端改动需 `cargo tauri dev` 重编译，**文档建议分两终端跑**
6. 6. **加密同步 passphrase 丢了 = 数据永久不可恢复**，无「找回密码」流程，**务必备份 24 词恢复短语**

**局限性（必须说清楚）**：

* • **扩展生态尚早**：官方商店扩展数量 <50 个（对比 Raycast 数百）、社区活跃度低，**常用工具（Notion、Linear、Jira、1Password）多靠自己写或等 AI Extension Builder 生成**
* • **无云端同步账号体系**：加密同步虽端到端但需自建/信任 Asyar 服务器，**团队共享配置、跨设备无缝迁移仍靠手动 Backup/Restore**
* • **Windows 上窗口管理偶发「还原上一步」失效**——HWND 定位在多显示器、DPI 缩放混用时有边界情况，**可手动再跑一次布局修正**
* • **AI Agent 仅支持文本/工具调用，不支持多模态（图像/音频输入）**，需本地先转文本再喂
* • **GPL-3.0 核心许可证**：商用二次分发需开源衍生代码，**SDK/扩展工具链是 MIT，核心 launcher 是 GPL**，法务确认合规再落地内网

**值不值得装？**

**值得**，如果你：

* • **受不了 Electron 启动器的内存/启动速度**，想要原生性能、跨平台一致体验
* • **重隐私、本地优先、无账号、无订阅**，数据完全在自己机器上
* • **需要 Silent AI Commands 这种「选中→热键→就地替换」的微工作流**，一天能省几十次切窗口
* • **想把 MCP 服务器、本地 LLM (Ollama)、自定义脚本、剪贴板历史、窗口管理、片段、计算器全塞进一个启动器**
* • **Linux 用户、苦 Raycast/Alfred 无 Linux 版久矣**

**不值得**，如果你：

* • **深度绑定 Raycast 扩展生态**（如专用公司内部扩展、复杂团队工作流），迁移成本高
* • **主力机是 Wayland Linux 且不愿切 X11**，核心功能缺失体验大打折扣
* • **需要成熟的云端同步、团队共享配置、企业级 SSO/审计**，Asyar 目前无此类能力
* • **无法接受 GPL-3.0 核心许可证** 的商用合规风险

**个人判断**：Asyar 是 **「把 Raycast 的产品理念、Alfred 的本地极简、Flow Launcher 的跨平台开源」熔铸在 Tauri+Rust 上的产物**。它没发明新交互，但把 **「原生性能、权限最小化、AI 原生、扩展沙箱、本地优先」** 这几张牌打到了当前开源启动器的天花板。对\*\*「重启动器体验、轻资源占用、重隐私、愿折腾配置/写扩展」的开发者/高级用户\*\*，它是目前最值得作主力启动器的开源选择。我已在三台主力机全量替换 Raycast/Alfred/Flow Launcher，两周零回滚冲动。
