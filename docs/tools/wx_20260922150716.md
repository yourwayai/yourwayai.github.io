# Open-Sora-Plan v1.5 发布：北大团队用 Wavelet-Flow VAE + Skiparse Attention 在 8B 模型上逼近 HunyuanVideo

* **原文链接**: [https://mp.weixin.qq.com/s/16-NOqPue_lerjEDLx-yog](https://mp.weixin.qq.com/s/16-NOqPue_lerjEDLx-yog)

2024 年 2 月，北大元组（PKU-YuanGroup）发起 Open-Sora-Plan，目标是**开源复现 OpenAI Sora（T2V 模型）**。两年多迭代至 v1.5.0（2026 年 3 月最新推送），核心里程碑：

* • **v1.0**：基础 DiT 架构、无条件/文本条件视频生成
* • **v1.2**：**3D 全注意力**替代 2+1D、4s 720p 训练、I2V（图生视频）/ 转场生成
* • **v1.3**：**Wavelet-Flow VAE (WFVAE)**、4×8×8=256× 压缩率、**Skiparse Attention** 稀疏注意力、Cross-DiT + 3D RoPE
* • **v1.5**：**SUV 稀疏 DiT 架构**、8B 参数、4000 万视频样本、**全流程在昇腾 910 系列（国产算力）训练推理**、性能逼近 HunyuanVideo（开源版）

代码开源于 GitHub（MIT 协议）、模型权重托管 Hugging Face、技术报告公开于 arXiv:2412.00131，**全链路可复现、可商用、可迁移国产算力**。

### 核心优势解析

**1. Wavelet-Flow VAE (WFVAE)：小波变换 + 光流建模，压缩率 256×、质量超 Wan2.1 VAE**

传统视频 VAE（如 VideoMAE、CogVideoX VAE）多用 3D 卷积下采样，压缩率通常 4×8×8=256× 但重建质量受限，或 8×8×8=512× 显存压力大。WFVAE 创新点：

* • **多级小波变换**：将视频帧分解为低频（近似）+ 高频（细节）子带，**频域压缩保留更多纹理信息**
* • **光流引导的运动建模**：在潜空间显式建模帧间光流，**运动先验显式化**，减轻 DiT 学习负担
* • **因果卷积设计**：**同一 VAE 同时支持图像/视频编码**，单节点即可训练，无需分布式 VAE
* • **实测指标**：8×8×8 下采样率下，**PSNR 高于 Wan2.1 VAE**，为上游 DiT 训练大幅降低计算成本（潜空间更小、Token 更少）

**2. Skiparse Attention：全局稀疏注意力，保持全局感受野、FLOPs 降 40%+**

3D 全注意力（v1.2）虽捕捉时空联合特征，但复杂度 O(N²) 在 720p/4s 视频（约 100k tokens）上显存/算力不可控。Skiparse Attention 核心思想：

* • **交替跳采集**：固定稀疏比 k=4，通过两种互补的跳跃采样模式（Skip-Gather），**覆盖全局 Token 但只计算 1/k 注意力**
* • **保留首尾层稠密**：第一层、最后两层保持 Full Attention，**保证输入编码完整、输出解码高保真**
* • **实测收益**：2.7B 模型应用 k=4 后，**训练显存降 ~40%、吞吐提升 ~35%**，生成质量与稠密 Attention 基持平（VBench 评测）

**3. Cross-DiT + 3D RoPE + 条件控制器：文本/图像/转场多模态统一建模**

* • **Cross-DiT 块**：每层注入 **T5 文本编码**（文本条件）、**时间步嵌入**、**可选图像/首尾帧条件**
* • **3D RoPE (Rotary Positional Embedding)**：时空统一位置编码，**天然支持任意分辨率、任意帧率、变长视频**（Bucket Training 策略配合）
* • **条件控制器模块化**：T2V / I2V / Transition（首尾帧指定）共用同一骨干，**仅切换条件注入方式**，无需分模型训练

**4. v1.5 SUV 架构 + 国产算力全链路：8B 模型、40M 样本、昇腾 910 原生训练**

* • **SUV (Sparse Unified Video DiT)**：在 Skiparse 基础上进一步优化稀疏模式、融合 FFN 选择性重计算，**稀疏注意力逼近稠密性能**
* • **数据规模**：4000 万视频样本（含高质量字幕、美学评分过滤），**约 32×240 H100 小时**完成字幕生成（v1.1 报告披露）
* • **硬件适配**：**全流程在昇腾 910 系列（NPU）训练推理**，代码分支 `mindspeed_mmdit` 基于 MindSpeed-MM 框架，**打破「视频生成只能跑英伟达」的刻板印象**
* • **基准对标**：VBench / VBench-I2V 等公开榜单，**8B SUV 模型性能接近 HunyuanVideo（13B 开源版）**，参数量降 38%、训练成本大幅下降

### 行业影响

**它与同类开源视频生成项目的区别在于：**

**生态信号**：

* • **国产算力落地标杆**：视频生成领域**首个全链路昇腾原生训练的大模型**，为「算力替代」提供了可复现范式
* • **稀疏注意力工程化**：Skiparse/SUV 证明了\*\*「全局稀疏」在视频 DiT 上可行\*\*，后续项目（如 Wan2.1、VideoSys）均有借鉴
* • **学术-工程双轨产出**：arXiv 论文 + 工程级代码 + 详细技术报告（v1.0~v1.5 每版本均有 Report-vX.Y.Z.md），**复现门槛极低**
* • **教育/研究价值**：北大元组开放的「从零训练视频生成模型」完整流程（数据清洗→字幕生成→VAE 训练→DiT 训练→评测），已成为多高校课程/实验室入门教材
