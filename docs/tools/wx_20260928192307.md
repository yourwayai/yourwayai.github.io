# OpenHands V1：70K 星的开源 AI 软件工程师平台，从单体重构为模块化 SDK，SWE-bench 68.4% 超越 Devin

* **原文链接**: [https://mp.weixin.qq.com/s/zfgq5CgiToES9LlQcxFJvA](https://mp.weixin.qq.com/s/zfgq5CgiToES9LlQcxFJvA)

OpenHands（原 OpenDevin，GitHub: `OpenHands/OpenHands`，70K+ ⭐，Apache-2.0）于 2024 年底完成 **V0→V1 架构重构**，2025 年初发布 ICLR 2025 论文《OpenHands: An Open Platform for Cloud Coding Agents》，2025 年中推出 **Software Agent SDK（V1 核心）**，将原本单体的 Agent 运行时拆解为四个解耦包：`openhands-sdk`（核心循环）、`openhands-aci`（Agent-Computer Interface）、`openhands-runtime`（沙箱抽象）、`openhands-llm`（LiteLLM 封装）。最新版本支持 **ACP（Agent-Client Protocol）**，可统一接入 Claude Code、Codex、Gemini、OpenHands 自身等 Agent；新增 **Headless Mode（REST API 提交任务）**、**多 Agent 协作（Controller 生成 Subagent）**、**MicroAgent/Skills 系统（领域知识注入）**。SWE-bench Verified（500 真实 GitHub Issue）上，**Claude Opus 4.6 达 68.4%**，Devstral 24B 开源模型达 **46.8%**（已超 Devin 2.0 公开报告的 45.8%），Qwen3-235B-A22B MoE 预估 52%+。

### 核心优势解析

#### 1. V1 模块化架构：从「单体 Agent」到「可组装 SDK」

**V0 痛点**：所有逻辑耦合在一个 Python 进程里——Agent 循环、工具执行、沙箱管理、LLM 调用、记忆压缩、安全审查、Web UI、CLI 入口全纠缠。**本地 CLI 执行需特殊分支、MCP/工具本地实现重复、测试需完整栈启动、插件系统不可用**。

**V1 重构**：四包解耦，核心循环仅 300 行：

```
# openhands-sdk 核心循环（伪代码）  
class Agent:  
    def __init__(self, llm: LLM, tools: list[Tool], event_stream: EventStream):  
        self.llm = llm  
        self.tools = {t.name: t for t in tools}  
        self.events = event_stream  
  
    def step(self, state: State) -> Action:  
        # 1. 读取事件历史（不可变追加日志）  
        history = self.events.get()  
        # 2. LLM 推理 → Action  
        action = self.llm.act(history, self.tools, state)  
        # 3. 发射 Action 事件（不执行！）  
        self.events.append(ActionEvent(action))  
        return action  
  
# 执行侧完全分离：Runtime 执行 Action → 返回 Observation → 追加事件
```

| 包 | 职责 | 关键接口 |
| --- | --- | --- |
| `openhands-sdk` | Agent 循环、事件流、状态机、记忆压缩、安全审查钩子 | `Agent.step()` , `EventStream`, `Memory`, `SecurityReviewer` |
| `openhands-aci` | **ACP 协议实现** 、工具定义、标准工具集 | `ACPAgent` , `Tool`, `Action`, `Observation` |
| `openhands-runtime` | 沙箱抽象：Docker/E2B/Modal/Daytona/K8s 本地进程 | `Runtime` , `Sandbox`, `FileSystem`, `Process` |
| `openhands-llm` | LiteLLM 统一网关、提供商路由、成本/Token 统计 | `LLM` , `Message`, `ToolCall` |

**白话注解**：

* • **Event-driven**：每步只发 Action 事件，执行、审查、记忆、UI 都是**事件流的旁路消费者**，互不阻塞、可热插拔。
* • **ACP（Agent-Client Protocol）**：类似 LSP 但针对 Agent，定义 `initialize`/`session/new`/`session/prompt`/`session/update`/`session/end`，Agent 与前端/CLI/Controller 通信的标准语言。
* • **MicroAgent/Skills**：`.openhands/microagents/` 下放 Markdown+YAML 知识片段（如「React 组件规范」「内部 API 约定」「安全审查清单」），Agent 启动时自动注入上下文，**比系统提示词更结构化、可版本控制、可共享**。

#### 2. 沙箱隔离：Docker 为主、多后端可选、写时复制层

每个任务会话 = 一个隔离 Docker 容器（或 E2B/Modal/Daytona 远程沙箱）：

```
# docker-compose.yml 片段  
services:  
  openhands-sandbox:  
    image: openhands/runtime:latest  # 预装 Python/Node/Java/Go/Rust、git、gh、playwright  
    volumes:  
      - workspace:/workspace:rw,z    # 工作目录，支持 bind mount / named volume  
      - /var/run/docker.sock:/var/run/docker.sock:ro  # 可选：嵌套 Docker  
    security_opt:  
      - no-new-privileges:true  
    cap_drop: [ALL]  
    cap_add: [CAP_DAC_OVERRIDE, CAP_FOWNER]  # 最小权限  
    network_mode: bridge  # 可选：host/none/自定义网络
```

**关键能力**：

* • **写时复制**：`overlayfs` 挂载代码库，Agent 改动不污染宿主、可快照回滚、可并行分支。
* • **网络可控**：默认仅允许访问 GitHub/包管理器/文档站，可配置 egress 白名单/代理。
* • **持久化**：`/workspace` 绑定宿主目录或 Docker volume，会话结束代码留存。
* • **多语言预装**：镜像内置主流语言工具链、LSP 服务器、测试框架，**Agent 开箱即能跑 `pytest`/`cargo test`/`npm test`/`go test`**。

#### 3. 完整工程闭环：写代码 → 跑测试 → 修 Bug → 开 PR → 回复 Review

OpenHands 标准工具集（`openhands-aci` 内置）覆盖 **软件工程全流程**：

| 工具类别 | 典型工具 | 说明 |
| --- | --- | --- |
| **文件系统** | `read` /`write`/`edit`/`list`/`glob`/`grep` | 原子操作、支持行号/正则/补丁格式 |
| **终端** | `bash` /`run` | 交互式/非交互式、超时/环境变量/工作目录控制 |
| **版本控制** | `git` /`github` | `git diff` /`commit`/`push`/`pr create`/`pr review`/`pr comment` |
| **Web** | `browser` /`fetch` | Playwright 无头浏览器、HTTP 客户端、搜索 API |
| **代码智能** | `lsp` /`symbol`/`diagnostics` | 基于语言服务器的跳转定义/引用/诊断 |
| **任务管理** | `task` /`delegate` | Controller 生成 Subagent、并行子任务、聚合结果 |

**实测流程**（解决一个真实 GitHub Issue）：

```
# 无头模式提交任务  
curl -X POST http://localhost:3000/api/tasks \  
  -H "Content-Type: application/json" \  
  -d '{  
    "repository": "owner/repo",  
    "issue_number": 1234,  
    "agent": "openhands",  
    "model": "claude-opus-4",  
    "max_iterations": 50,  
    "microagents": ["react-patterns", "security-review"]  
  }'
```

Agent 在沙箱里：`git clone` → 读 Issue → 探索代码库 → 定位文件 → 写修复 → 跑测试 → 失败则循环修 → 全绿 → `git commit` → `gh pr create` → 填 PR 描述/关联 Issue → **可选：等 CI 通过 → 回复 Reviewer 意见 → 再改 → force push**。全程 **EventLog 可回放、可暂停、可人工介入**。

#### 4. 多 Agent 协作与无头模式：批量处理、并行子任务

* • **Controller Agent**：接收高层目标（如「修复这 20 个 Issue」），规划分解 → 生成 Subagent 规格（各自 repo/branch/目标/模型/预算）→ 并行启动 → 聚合结果 → 汇总报告。
* • **Headless REST API**：`POST /api/tasks`、`GET /api/tasks/{id}/events`（SSE 流式事件）、`POST /api/tasks/{id}/intervene`（人工注入指令）、**无需 Web UI 点点点**，CI/CD 流水线可直接调用。
* • **SWE-bench 批量跑法**：脚本读取数据集 → 并发提交 N 个任务 → 收集 `patch`/`test_results`/`cost`/`tokens` → 生成评测报告。

#### 5. 可观测性与安全：全链路审计、确定性回放、最小权限

* • **EventLog 不可变追加**：每步 Action/Observation/LLM 调用/工具执行/安全判定/Token 用量/耗时/错误堆栈 **全记录**，JSONL 格式，**支持完整会话回放、时间旅行调试、离线分析**。
* • **安全审查钩子**：`SecurityReviewer` 接口，默认规则拦截 `rm -rf /`/`curl | bash`/`访问私钥`/`修改系统配置`，**可注入自定义规则**（如「禁止向生产数据库写入」）。
* • **成本控制**：`openhands-llm` 统计每模型/每任务/每步 Token 与美元成本，**可设硬预算、软预算告警、自动停止**。

### 行业影响

#### 与竞品的本质定位差异

| 维度 | Cursor / Copilot / Claude Code | Devin (Cognition) | OpenHands |
| --- | --- | --- | --- |
| **核心产品** | IDE 插件 / 编辑器内聊天 | 托管 AI 工程师 SaaS | **开源 Agent 运行时平台 + SDK** |
| **部署** | 云端/本地 IDE | 仅云端 | **自托管（本地/私有云/GPU 云/远程沙箱）** |
| **数据隐私** | 代码片段上传模型 | 全仓库上传云端 | **代码不出沙箱、模型可本地跑（Ollama/vLLM）** |
| **可扩展性** | 提示词/规则文件 | 官方功能迭代 | **SDK 四包解耦、自定义 Runtime/Tool/Reviewer/Skill** |
| **批量/自动化** | 单会话交互 | 单任务云端执行 | **Headless API + Controller + 并行 Subagent** |
| **基准测试** | SWE-bench 非标准跑法 | 报告 45.8% (Devin 2.0) | **公开可复现跑法、开源模型 46.8%+、SOTA 68.4%** |
| **商业模式** | 订阅制 | 企业定价 | **Apache-2.0 免费、企业版售支持/托管/合规功能** |

#### 它不解决、也不声称解决的问题

* • **模型训练/微调**：不造基座模型，依赖外部 LLM（闭源/开源均可），`openhands-llm` 只做路由与统计。
* • **IDE 深度集成**：无 VS Code/JetBrains 插件（社区有第三方），定位 **「后台自主执行」** 而非「编辑器内 Copilot」。
* • **非代码工程任务**：不做文档写作/设计/产品规划/运维运维（虽可通过 Skills 扩展，但非核心优势）。
* • **实时协作编辑**：多人同时改同一文件冲突解决靠 Git，无 Google Docs 式实时合并。

#### 生态信号

* • **Agent 基础设施标准化**：ACP 协议、SDK 解耦、Runtime 抽象，正在形成「Agent 操作系统」的雏形——**类比：LLM=CPU、SDK=内核、Runtime=进程隔离、ACP=系统调用、Skills=共享库、Controller=调度器**。
* • **开源模型追赶闭源**：Devstral 24B（Mistral/NVIDIA 训练，代码专用）在 OpenHands 上跑到 46.8%，**证明「强推理开源模型 + 完善 Agent 基建」可替代闭源模型**，降低企业自托管门槛。
* • **企业自托管合规化**：金融/医疗/国防等强合规行业，**代码不出 VPC、模型跑自建 GPU 集群、审计日志满足 SOC2/ISO27001**，OpenHands 成首选落地框架。
