上周把 **Mimik v1.2.0**（`0004bb0`，dev 分支，2025-09 更新）在 Chrome 128 / Firefox 130 / Edge 128 上各装了一遍。

关注它的起因很具体：团队内部工具文档、新人入职 SOP、给客户的产品教程，全靠 **“录屏 → 手工截图 → PS 圈重点 → 写步骤 → 发 Notion/飞书/Confluence”**，一次 20 分钟流程能折腾 2 小时文档。市面上工具要么是云端 SaaS（Loom、Guidde、Tango、Scribe）数据上传、按席位收费、无法私有化；要么是桌面端录屏（OBS、ScreenToGif）后期剪辑重。Mimik 打出的牌是：**浏览器原生扩展、Manifest V3、全本地运行（IndexedDB 存指南、截图、音频）、自动捕获点击/输入/快捷键/剪贴板/拖拽/导航、智能合并临近点击、SPA 页面跳转不丢步骤、智能模糊敏感数据、可选 AI 描述/语音旁白、多格式导出、.mimik 文件可导入回放**——这套“装上即用、数据不出浏览器、生成物可二次编辑、可离线分发”的组合拳，正好卡在“想快速产出专业操作指南又不想数据上云、不想装桌面软件”的痛点上。

### 部署实录

**环境与版本清单**

| 组件 | 版本 | 备注 |
| --- | --- | --- |
| Chrome | 128+ | Manifest V3 支持 |
| Firefox | 130+ | MV3 完整支持 |
| Edge | 128+ | Chromium 内核同步 |
| 开发构建 | Node 20+ / pnpm 9+ | `pnpm install && pnpm build` 产出 `dist/` 可直接加载解压扩展 |

**三种安装方式实测**

**方式 1：应用商店一键装（普通用户、推荐）**

* • Chrome Web Store 搜 “Mimik” → 添加到 Chrome
* • Firefox Add-ons 搜 “Mimik” → 添加到 Firefox
* • Edge Add-ons 搜 “Mimik” → 获取  
  **无需登录、无需权限确认对话框**（仅需 `activeTab`、`scripting`、`storage`、`downloads`、`tabs` 等标准权限），安装后工具栏出现 Mimik 图标，点击即用。

**方式 2：开发者模式加载解压包（想改代码/自建/内网分发）**

```
git clone https://github.com/westpoint-io/mimik.git  
cd mimik  
pnpm install          # 约 45 秒，依赖极简：react、zustand、shadcn/ui、dayjs、wxt、biome  
pnpm build            # 约 30 秒，产出 .output/chrome-mv3/ (或 firefox-mv3/)  
# Chrome: chrome://extensions → 开发者模式 → 加载已解压的扩展程序 → 选 .output/chrome-mv3  
# Firefox: about:debugging → 临时附加组件 → 选 .output/firefox-mv3/manifest.json
```

**实测构建产物**：Chrome 版约 1.2 MB、Firefox 版约 1.1 MB，**无外部资源依赖、无远程代码加载、纯静态文件**。

**方式 3：打包分发 `.zip` / `.xpi`（企业内网离线分发）**

```
pnpm zip              # 产出 mimik-chrome.zip / mimik-firefox.xpi  
# 内网分发：邮件/NAS/内网盘发给同事，拖进扩展管理页安装
```

**最小可行验证流**

1. 1. 打开任意 Web 应用（如 GitHub PR 审查流程、Notion 发文流程、内部 ERP 下单流程）
2. 2. 点击 Mimik 图标 → **Record** → 正常操作一遍（点按钮、填表单、按快捷键、复制粘贴、拖拽排序、页面跳转）
3. 3. 中途需隐藏敏感信息 → 点 **Blur** → 自动检测并勾选邮箱/手机/信用卡/SSN/IP/MAC → 或手动点选 DOM 元素遮盖 → **Done** 继续录制
4. 4. 需口述 → 点 **Narrate** → 说话 → 停止（音频送 Groq/OpenAI Whisper 转文，自动匹配到步骤）
5. 5. 操作完 → **Stop** → 自动弹出编辑器：每步带**高亮缩放截图**、规则生成描述（"Click Submit button"）、可改文本、可裁剪/标注/遮盖截图、可插标题笔记、可拖拽重排/批量删、可版本回滚
6. 6. 导出：**Video (MP4/H.264 游标动画) / GIF / PDF (A4 自动分页) / DOCX / HTML (Base64 嵌图) / Markdown / .mimik (可导入回放)**
7. 7. **Guide Me 回放**：打开目标页面 → 选指南 → **Guide Me** → 实时高亮下一步元素、跟随交互自动推进、新人按着点就能学会

全程约 3-5 分钟，**无账号、无登录、无网络请求（除可选 AI/语音/站标获取）**、**生成物全在本地 IndexedDB，随时可导出 .mimik 文件带走**。

### 核心亮点

**1. 自动捕获引擎：把“用户所有有意义动作”变成结构化步骤，不漏、不重、不乱**

| 捕获动作 | 实现细节 | 去重/合并策略 |
| --- | --- | --- |
| **点击** | `click` 事件拦截（`capture: true` 在导航前触发），记录 `selector`、`xpath`、`text`、`boundingRect`、截图 | **临近元素快速连点合并** ：同一容器内 500ms 内多次点击 → 合并为 1 步，截图取最后一点 |
| **表单输入** | `input` /`change` 事件，记录 `name`/`type`/`value`（密码字段自动脱敏） | 同字段连续输入合并为 1 步，最终值为准 |
| **键盘快捷键** | `keydown` 监听 `Ctrl/Cmd+Key`、`Enter`、`Tab`、`Escape` 等 | 单独成步，不与点击合并 |
| **剪贴板** | `clipboard` API 读取复制/粘贴内容（需权限） | 粘贴动作合并到目标输入步骤 |
| **拖拽** | `dragstart` /`drop` 事件，记录源/目标元素、数据 | 单独成步 |
| **页面导航** | `webNavigation` API + `tabs.onUpdated`，SPA 路由变化（History API/Hash）同步捕获 | 导航自动成步，截图取加载完成后首屏 |

**关键工程化细节**：

* • **内容脚本注入策略**：`document_start` 注入轻量监听器，**不污染页面全局、不重写原型、不挂 `window` 对象**，极低性能开销
* • **截图生成**：`chrome.tabs.captureVisibleTab` + `canvas` 裁剪高亮区域 + 2x 缩放，**单步截图约 50-150 KB（WebP）**，100 步指南约 5-10 MB
* • **存储**：IndexedDB（`idb` 库封装），**指南/步骤/截图/音频/版本历史全本地**，单指南上限受限于浏览器存储配额（通常 ≥ 1 GB）
* • **SPA 支持**：`history.pushState`/`replaceState` 监听 + `popstate` + `hashchange`，**React/Vue/Next.js/Remix 等客户端路由跳转零漏捕**

**2. 智能模糊：录制时暂停、检测敏感数据、烧录像素、不可逆**

| 检测类别 | 正则/规则 | 覆盖范围 |
| --- | --- | --- |
| **邮箱** | RFC 5322 简化正则 | 页面文本、输入框值、href `mailto:` |
| **手机号** | E.164 + 各国常见格式 | 文本、tel 链接、输入框 |
| **信用卡** | Luhn 校验 + 主流卡段前缀 | 文本、输入框（自动跳过 CVV/CVC 字段） |
| **SSN** | `XXX-XX-XXXX` + 变体 | 文本、输入框 |
| **IP 地址** | IPv4/IPv6 正则 | 文本、代码块、终端输出 |
| **MAC 地址** | `XX:XX:XX:XX:XX:XX` 变体 | 文本、网络设置页 |

**手动模糊选择器**：点选任意 DOM 元素 → **跨所有已有/未来截图同步遮盖**（基于 `selector`/`xpath` 重新匹配）、**导出时像素级烧录**，接收者**零可能还原**。

**官方文档诚实列出的盲区（`README.md` "What Smart Blur does not cover"）**：

* • **Iframes**（跨域限制，内容脚本注入不进去）
* • **Shadow DOM**（封装隔离，除非开放模式）
* • **图片/Canvas/WebGL 渲染的文字**（非 DOM 文本，OCR 不在范围）
* • **动态渲染后插入的敏感数据**（模糊检测在截图瞬间跑，后插入的需手动补遮盖）

**3. AI 描述 & 语音旁白：自带 Key、DOM 上下文仅 ~50-100 tokens、成本极低**

```
// AI 描述生成伪代码（实际在 src/ai/description.ts）  
const domContext = extractLightweightDOM(step.targetElement, step.pageSnapshot);  
// ~50-100 tokens：目标元素标签/属性/文本/父级结构/周围同级  
const prompt = `User clicked ${domContext}. Write a one-sentence step description.`;  
const description = await callLLM(provider, apiKey, prompt, { temperature: 0.2 });
```

* • **Provider**：OpenAI / Anthropic / Groq（语音转文本）
* • **语言独立**：UI 语言（6 种）与描述语言（6 种）可任意组合
* • **成本对比**：视觉模型（GPT-4o Vision）单步约 1500-3000 tokens ≈ 0.01；Mimik 文本模式单步约 80 tokens ≈ **0.0003**，**便宜 15-30 倍**
* • **语音旁白**：录制时点 Narrate → 录音 → 停止 → 送 Groq Whisper / OpenAI Whisper 转文 → **按时间戳自动对齐到步骤** → 生成描述，**一次讲完、不用逐步打字**

**4. 导出生态：7 种格式覆盖全分发链路，.mimik 可反向导入**

| 格式 | 生成方式 | 典型用途 |
| --- | --- | --- |
| **Video (MP4)** | `MediaRecorder` + `canvas` 渲染游标轨迹 + 合成音频 | 入职视频、发票教程、GitHub Release 附件 |
| **GIF** | `gif.js` 逐帧编码、循环播放 | Slack/钉钉/飞书评论、Issue 首图、快速演示 |
| **PDF** | `pdf-lib` A4 纵向、自动分页、截图自适应缩放 | 正式交付文档、打印存档、合规归档 |
| **DOCX** | `docx` 库生成、可二次编辑 | 客户交付、需在 Word 里改版式 |
| **HTML** | 单文件、Base64 嵌图、内联 CSS/JS | 离线分发、内网 Wiki 嵌入、邮件正文 |
| **Markdown** | 标准 MD + 相对路径图片/内联 Base64 | Notion/GitHub/语雀/Obsidian 粘贴即用 |
| **.mimik** | ZIP：`manifest.json` + `screenshots/` + `README.md` | **团队协作/版本控制/再编辑/Guide Me 回放** |

**.mimik 反向导入流**：

1. 1. 接收 `.mimik` 文件 → 面板显示**发送方已移除内容**（模糊烧录、输入值剥离、链接去查询参数）
2. 2. 确认 → 导入到本地库 → **步骤/截图/版本历史/回放能力全复原**
3. 3. 可继续编辑、再导出、再分发，**指南成为可流转的知识资产**

**5. Guide Me 回放：把指南变成“交互式教练”**

* • 打开目标页面 → 选指南 → **Guide Me** → 侧边栏显示当前步、高亮目标元素（`element.scrollIntoView` + `box-shadow` + `outline` 动画）
* • 用户点击目标元素 → **自动推进下一步**（事件委托监听，不污染页面）
* • 支持**跳过/后退/重做/结束**，进度实时同步
* • **新人入职实测**：原本 30 分钟口头带新人跑一遍 ERP 下单流程，现在发 `.mimik` 文件 → 新人自己跑 Guide Me，**10 分钟自学通关、零打扰、可随时复训**

### 避坑与总结

| 优点 | 缺点/局限 |
| --- | --- |
| 纯客户端、无后端、无账号、无遥测、数据不出浏览器、隐私极致 | **仅支持浏览器内操作** ：桌面原生应用、跨应用流程（如 “复制 Excel → 粘贴浏览器 → 切回 Terminal 跑脚本”）**无法捕获** |
| 自动捕获全、合并智能、SPA 支持好、截图自动高亮缩放 | **截图仅可见视口** ：长页面需滚动截图（规划中），现有版本只捕获 `captureVisibleTab` 可见区域 |
| 智能模糊覆盖主流敏感类、手动遮盖跨截图同步、导出烧录不可逆 | **模糊盲区明确** ：iframe/Shadow DOM/图片文字/动态后插数据需人工补，官方文档诚实列出 |
| AI 描述/语音旁白自带 Key、DOM 上下文极省 token、多语言解耦 | **AI 能力依赖外部 API** ：断网/额度尽/Key 失效时降级为规则生成描述（"Click Submit"），无本地模型选项 |
| 7 种导出格式、.mimik 可反向导入、Guide Me 交互式回放 | **无云端同步/协作编辑/权限管理/版本对比** ：团队协作靠“传文件/提 Git”，非实时协作 |
| Manifest V3、WXT 跨浏览器构建、TypeScript 严格、Biome 格式化、测试覆盖率有门槛 | **Firefox/Edge 审核上架慢、权限提示略多** （`host_permissions` 需全站点访问），企业分发需组策略/托管存储预配置 |
| MIT 许可、商业友好、活跃维护（589 commits、9 contributors、v1.2.0 近期发布） | **无插件市场内购/订阅/企业版** ，商业化路径不清晰，长期维护靠赞助/云服务（规划中） |

**个人判断**：

* • 如果你是**技术文档工程师、DevRel、产品经理、客户成功、内部工具维护者**，需要**高频产出“带截图、分步骤、可回放、可分发”的操作指南**，且**拒绝数据上云、拒绝按席位付费、拒绝装桌面软件**——\*\*Mimik 是当前开源界唯一“装上即用、全本地、生成物可二次编辑、可离线流转”\*\*的完整解法，Chrome/Firefox/Edge 三端同步体验、导出格式覆盖全链路。
* • 如果你是**大型企业需合规审计、集中策略下发、审批流、审计日志、SSO 登录、指南生命周期管理**——**Mimik 缺乏企业级管控平面**，建议评估 Scribe/Tango/Guidde 企业版或自建在 Mimik 之上（开源可二开）。
* • 如果你是**跨应用/桌面级流程记录（如 “Excel → 浏览器 → Terminal → Slack”）**——**Mimik 管不了**，需桌面端录屏工具（OBS + 后期 / Replay.io / ScreenToGif + 手工）。
* • 如果你是**想做“指南即代码/指南即测试/指南驱动开发”**的极客——**.mimik 文件结构极简（JSON + 图片 + README）**，可轻松写脚本：`mimik → Playwright 测试用例`、`mimik → OpenAPI Spec`、`mimik → Mermaid 流程图`，**指南成为可执行规范的源头**。
* • **最大局限**：**“浏览器边界”硬约束**。任何**超出单一浏览器标签页**的操作（原生应用、多浏览器协同、OS 级快捷键、硬件设备交互）均无法捕获。这不是工程欠缺，是**浏览器扩展安全模型的物理边界**。长期看，若需突破，需配套 **Native Messaging Host** 或 **桌面端伴侣程序**，但会失去“纯扩展、零安装、零权限”的核心优势。
