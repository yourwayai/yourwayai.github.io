香港大学数据科学实验室（HKUDS）开源 **Vibe-Trading v0.1.16**（34.3k Star，MIT 许可），定位为 **“Your Personal Trading Agent”**——一个**全链路量化研发与交易执行平台**。

核心能力覆盖：

1. 1. **自然语言驱动研究**：`vibe-trading run -p "Backtest 20/50 MA crossover on AAPL"` → 自动选技能、拉数据、写策略、跑回测、出报告
2. 2. **多 Agent Swarm 协作**：30 个预设 Swarm（投资委员会辩论、量化策略桌、加密交易桌、宏观利率外汇桌…），Agent 间辩论、分工、互相挑战
3. 3. **极致数据源工程**：**28 个市场数据源、按 IP 封禁风险排序的 fallback 链**，零 Key 跑全市场（A 股/美股/港股/加密/外汇/期货/宏观/基本面/另类数据）
4. 4. **Alpha Zoo 策略库**：**462 个预置量化 Alpha**（Qlib 158 + Kakushadze 101 + GTJA 191 + 学术/基本面），一键 bench、组合、导出
5. 5. **回测引擎矩阵**：**10 种回测引擎 + 期权组合 + 跨市场合成**，导出 Pine Script / TDX / MT5
6. 6. **Broker Connectors 18 家券商**：Alpaca/Binance/OKX/IBKR/eToro/Futu/MT5/Robinhood… **读/纸交易/受限实盘**三模式，Mandate 机制 + Kill Switch + TAP 代理凭证隔离
7. 7. **MCP 双向集成**：**74 个 MCP Tools** 暴露给外部 Agent（Claude Desktop/Cursor/OpenClaw），**也能作为 MCP Client 调用外部 MCP Server**
8. 8. **Web UI + CLI + 定时任务 + 跨会话记忆 + 文档上传分析 + 影子策略挖掘**

### 核心优势解析

**1. 多 Agent Swarm：把“量化团队”装进一个命令里**

| Swarm Preset | 组成 | 典型任务 |
| --- | --- | --- |
| `investment_committee` | 多角色辩论（多头/空头/风控/主席） | “TSLA 当前价位值得买吗？” |
| `quant_strategy_desk` | 筛选员、研究员、组合经理、风控 | “S&P 500 三个月动量策略从筛选到回测” |
| `crypto_trading_desk` | 资金费率分析师、爆仓流监控、现货/永续套利、风控 | “ETH-USDT 1 周高频套利机会” |
| `macro_rates_fx_desk` | 宏观策略、利率交易员、外汇交易员、组合配置 | “美联储转向对新兴市场债券的影响” |
| `earnings_season_desk` | 财报预测、期权隐含波动、事后复盘 | “财报季 NVDA 盈利超预期的隐含波动交易” |

**Swarm 运行机制**：

```
用户提交目标  
    ↓  
Planner Agent：拆解为子任务、分配给 Worker Agents  
    ↓  
Worker Agents 并行：各自调用工具（数据、回测、代码执行、搜索）产出制品  
    ↓  
Critic Agent：挑战制品、指出缺陷、要求补充证据  
    ↓  
Coordinator：综合意见、生成最终报告/策略代码/回测结果  
    ↓  
人工确认 → 入库/部署
```

**关键工程化**：**Worker 间隔离上下文、仅通过结构化制品交换**、**支持 `--swarm-resume` 断点续跑**、**`--swarm-retry` 失败重试**、**每轮工具调用预算 8 次、超额触发恢复请求防死循环**。

**2. 数据源 Fallback 链：按“IP 封禁风险”排序的工程学现实主义**

```
# 伪代码：单一 get_market_data 调用，内部自动走链  
async def get_market_data(symbol: str, source: str = "auto", ...) -> MarketData:  
    if source == "auto":  
        chain = FALLBACK_CHAINS[detect_market(symbol)]  # 如 A-share → tencent·mootdx → eastmoney → baostock → akshare → tushare → gildata → local  
    else:  
        chain = [source]  
      
    for src in chain:  
        try:  
            return await loaders[src].fetch(symbol, ...)  
        except (IPBanError, RateLimitError, AuthError) as e:  
            log.warning(f"{src} failed: {e}, trying next")  
            continue  
    raise AllSourcesExhaustedError()
```

**实测 Fallback 链（按市场、按 IP 封禁风险升序）**：

| 市场 | Fallback Chain（前→后风险递增） |
| --- | --- |
| **A 股** | `tencent·mootdx` （TCP 直连通达信、从不封 IP） → `eastmoney`（节流） → `baostock·akshare`（免费备用） → `tushare`（需 Token、最全） → `gildata`（商业级恒生聚源） → `local` |
| **美股** | `yahoo·stooq·sina·eastmoney·yfinance·tiingo·fmp·finnhub·alphavantage·longbridge·akshare·local` |
| **港股** | `tencent·eastmoney·yahoo·futu·akshare·yfinance·tushare·longbridge·local` |
| **加密** | `okx·ccxt·binance·yfinance·local` |
| **外汇/贵金属** | `mt5` （本地 MT5 终端） → `yfinance·akshare·local` · `tickerall`（托管 MT5、显式启用） |

**零配置、零单点故障、免费源优先、付费源（QVeris/Tushare/Longbridge/FMP/Finnhub…）显式启用**。**`source: "auto"` 是默认且推荐**，显式指定 source 仅用于对比/调试/强制用付费源。

**4. 回测引擎矩阵：10 种引擎覆盖从“快速验证”到“机构级模拟”**

| 引擎 | 定位 | 特性 |
| --- | --- | --- |
| **vectorized** | 极速向量化 | 秒级跑完 10 年日频、无订单簿模拟、适合因子筛选 |
| **event\_driven** | 事件驱动 | 逐 Bar 处理、支持限价单/滑点/手续费/资金占用 |
| **portfolio** | 组合级 | 多资产、再平衡掩码、换手率约束、资金曲线合成 |
| **options\_portfolio** | 期权组合 | Greeks、隐含波动面、Payoff 场景、Delta 对冲模拟 |
| **cross\_market** | 跨市场合成 | 多市场不同时区对齐、汇率换算、合成指数 |
| **walk\_forward** | 滚动窗口 | 训练/验证/测试分离、防前视偏差、参数稳定性 |
| **monte\_carlo** | 蒙特卡洛 | 收益分布采样、尾部风险、置信区间 |
| **bootstrap** | 自助法 | 非参数统计推断、策略鲁棒性 |
| **regime\_aware** | 机制感知 | 结合 Correlation Regime（边缘密度+滞后）切换子策略 |
| **shadow\_backtest** | 影子回测 | 基于实盘成交单反推策略、发现隐性策略 |

**导出目标**：`--pine` → TradingView Pine Script、`--tdx` → 通达信公式、`--mt5` → MetaTrader 5 EA、**直接可部署**。

**5. Broker Connectors：18 家券商、三模式、安全边界工程化**

| Broker | 读 | 纸交易 | 实盘（受限） | 特殊能力 |
| --- | --- | --- | --- | --- |
| **Alpaca** | ✅ | ✅ | Mandate + Kill Switch | **TAP 模式** ：凭证代理、人工审批每单、纸/实 Key 结构性隔离 |
| **Binance/OKX** | ✅ | ✅ | Mandate | 现货/合约、USDT/币本位 |
| **IBKR** | ✅ | ✅ | 仅本地 TWS/Gateway | 官方 MCP 只读探针、本地连接无需 OAuth |
| **eToro** | ✅ | ✅ | Mandate + Copy Trading | 路径隔离（demo/real 不同 API 路径）、Copy 启停需 Reference ID |
| **Futu** | ✅ | ✅ | 仅本地 OpenD | 港股/美股/期权、需本地终端 |
| **MT5** | ✅ | ✅ | Mandate + 对冲账户处理 | Windows 仅、Lot 计价、Kill Switch、强平路径审计 |
| **Robinhood** | ✅ | — | MCP Agentic Trading | 官方远程 MCP、OAuth、实盘需 Mandate |
| **其他** | … | … | … | Tiger/Longbridge/KIS/Zerodha/Upbit/Trading212/Dhan/Shoonya/Futu/Toss/Scalable… |

**安全边界硬核设计**：

* • **纸交易 ≠ 模拟器**：**直连券商 Demo 账户**，每次调用 `account_info().trade_mode` 校验，**指向实盘账号直接拒绝**。
* • **Mandate 机制**：实盘下单需**人工授权额度（USD 计价）**、**Kill Switch 一键熔断**、**审计日志不可篡改**。
* • **TAP 模式（Alpaca 首发）**：**Agent 进程完全不持有 API Key**，所有调用走 TAP 代理 → TAP 注入 Key → **写操作阻塞等待人工批准（Telegram/面板）**、读操作自动放行、**`allowed_hosts` 结构性拒绝纸 Key 打实盘接口**。
* • **凭证存 OS Keyring**（macOS Keychain/Windows Credential Manager/Linux Secret Service）、**永不落配置文件、永不进环境变量、永不进 Docker 容器**（除显式传入）。

**6. MCP 双向：既是 Server 也是 Client**

| 方向 | 能力 | 典型用法 |
| --- | --- | --- |
| **MCP Server** (`vibe-trading-mcp`) | 暴露 **74 个 Tools**（研究、回测、Alpha、数据、券商、Swarm、记忆、文档…） | Claude Desktop 配置 → 直接让 Claude 调用 `backtest`、`alpha_bench`、`trading_quote`、`run_swarm` |
| **MCP Client** (`~/.vibe-trading/agent.json`) | 内置 Agent 调用**外部 MCP Server**（本地 stdio / 远程 SSE/Streamable HTTP） | 接入私有知识库、内部风控服务、IBKR 官方 MCP、自定义数据源 |

**Swarm Worker 可调用外部 MCP Tools**（配置 `VIBE_TRADING_SWARM_AGENT_CONFIG` 允许列表）、**Caller 变量仅作模板数据、不可注入 MCP URL/命令/环境变量/允许列表覆盖**——供应链安全硬约束。

### 行业影响

**定位对比**：

| 维度 | Vibe-Trading | 传统量化平台 | 云端量化 SaaS | 单 Agent 交易 Bot |
| --- | --- | --- | --- | --- |
| **架构** | 多 Agent Swarm + 自然语言编排 | 代码框架（需写 Python/C++） | 黑盒托管 | 单模型端到端 |
| **部署** | **完全本地/私有化** （Docker/本地/ClawHub） | 本地/服务器 | 云端托管 | 本地/云端 |
| **数据源** | **28 源 Fallback、零 Key 可跑** | 自建/购买/单源 | 供应商提供 | 单源/手工 |
| **策略库** | **462 Alpha + 组合引擎** | 自研/购买 | 供应商策略 | 无/提示词 |
| **回测** | **10 引擎 + 期权 + 导出 Pine/MT5** | 单引擎/自研 | 供应商引擎 | 无/简易 |
| **券商直连** | **18 家、三模式、安全工程化** | 自适配/IBKR/CTP | 供应商支持 | 单券商/简易 |
| **可审计** | 结构化 Run Card、Run Detail、回测溯源 | 日志/报表 | 定期报告 | 极弱 |
| **扩展性** | **插件化技能、自定义数据源、MCP 双向、Swarm 预设** | 硬编码 | 供应商路线图 | 提示词工程 |
| **许可证** | **MIT（商业友好）** | 多样 | 商业协议 | 多样 |

**Vibe-Trading 的差异化护城河**：

1. 1. **“自然语言 → 多 Agent 协作 → 结构化制品”端到端闭环**——不是“ChatGPT 包装器”，是**工程化的工具调用链、回测验证环、回测制品导出、实盘安全闸口**。
2. 2. **数据源 Fallback 链的工程学现实主义**——承认“免费源会被封 IP、付费源会挂、券商 API 会变”，**把容错、降级、优先级、显式/隐式源选择全做透明**，这是生产环境能跑、Demo 环境跑不通的分水岭。
3. 3. **Alpha Zoo + 回测引擎矩阵 + 导出目标**——**从“因子挖掘”到“可部署策略代码”全链路打通**，Pine Script/TDX/MT5 一键导出，量化研发到实盘部署“无缝衔接”。
4. 4. **Broker Connectors 的安全工程化**——**纸交易=券商 Demo 账户校验、Mandate=USD 额度授权、Kill Switch=熔断、TAP=凭证代理+人工审批**，这套组合拳把“AI 下单”的风险降到工程可控范围。
5. 5. **学术机构背书 + 活跃社区 + MIT 许可**——HKUDS 长期维护、172 贡献者、13 个版本、Roadmap 清晰、不搞“核心开源+企业版闭源”割裂。

**潜在竞争风险**：

* • **复杂度极高**：2661 commits、90.7% Python、74 MCP Tools、30 Swarm、18 Broker、10 Backtest Engine、462 Alpha——**上手曲线陡峭**，非量化背景用户极易迷失。
* • **实盘验证不足**：README 明确写“broker-trading capability is experimental and not verified by us against a real broker account”，**实盘前必须自行压测、灰度、法务审核**。
* • **中文市场（A 股/港股）数据源依赖单一学术/开源项目**（mootdx/akshare/baostock/tushare），**商业级稳定性、完整性、合规性无保证**，机构级落地需接商业数据。
* • **无图形化策略可视化编辑器**、**无分布式回测/参数搜索集群**、**无原生 Kubernetes Operator**——规模化运维需自建。
* • **模型选择强依赖工具调用能力**：推荐 Opus-4.7/Sonnet-4.6/GPT-5.5/Gemini-3.5/DeepSeek-V4-Pro/Grok-4.2/GLM-5.1，**小模型/蒸馏模型工具调用不可靠、会“凭记忆答题”**。
