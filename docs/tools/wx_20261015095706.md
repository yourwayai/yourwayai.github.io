# 从代码还原界面、鼠标自动点点点：explainroo 的产品演示模式能替代多少人工录屏？

上周末把 **explainroo v0.1.1** 拉下来跑了一遍。简单说，就是让 AI Agent 帮你做讲解视频的工具。

起因挺真实的：想把几篇技术博客改成短视频发 B 站、小红书，但不想花时间学剪辑，也不想花钱买会员素材。市面上 AI 视频工具要么是云端 SaaS（HeyGen、Synthesia、D-ID）按分钟收费、数据上云、改不动；要么是本地框架（MoviePy、Manim、Remotion）得自己写渲染逻辑、管音视频同步、搞字幕对齐。explainroo 走的路子不一样：**Agent 只写俩文件——`script.md`（旁白稿）和 `scenes.js`（画面描述），剩下的：语音合成、逐字对齐、手绘风渲染、图标/图表/代码/截图混排、背景音乐自动混音、ffmpeg 合成，全在本地跑通，零 API Key、零云端依赖、MIT 协议**。

---

### 怎么装、怎么跑

环境要求不高：Node.js 20.11+、ffmpeg、Chrome 或 Chromium。首次跑会下载语音和计时模型，加起来约 400 MB，**不用显卡**，作者是在 Linux 上开发测试的，macOS 和 Windows 理论也能跑，只是他自己测得少。

```
git clone https://github.com/vincentsch/explainroo.git  
cd explainroo  
npm install  
node bin/explainroo.js doctor --fetch
```

装好后，在 explainroo 目录里启动你的 Agent（Claude Code、Codex、Pi 都行，作者说目前配合 **Claude Code + Opus 5.5 效果最好**），直接提需求：

> "Make a 60 second video about how HTTPS keeps a password secret."

Agent 会读 `AGENTS.md`，按流程生成视频，成品在 `videos/<name>/out/video.mp4`。

**踩过的坑提前避**：

* • **首跑必须执行 `doctor --fetch`**，不然报模型缺失。下载过程无进度条，看网速约 2-5 分钟。
* • **Chrome 必须可执行**，无头模式下用Playwright驱动，Linux 需装`chromium` 或 `google-chrome-stable`。
* • **Agent 必须在 explainroo 目录下启动**，它会读项目里的 `AGENTS.md` 知道怎么操作。
* • **中文语音支持取决于 Kokoro 版本**，官方模型以日英为主，中文可用但音色选项少、语调不如英文自然，得在 `script.md` 里用拼音或英文标注语气词辅助。
* • **长视频内存占用高**，5 分钟以上视频 Chrome 渲染进程可能占 2-3 GB 内存，16 GB 以下机器建议分段生成再拼接。

---

### 它是怎么工作的

原理挺直观。Agent 只用写俩文件，剩下的 explainroo 全包了：

* • **声音**：用 **Kokoro**（开源语音模型，8600 万参数，28 个音色，免 Key、免账号，纯 WASM/WebGPU 跑，延迟约 200 ms/句）
* • **对口型**：**Whisper**（Transformers.js 版 `whisper-tiny`）听录音，标出每个词啥时候说
* • **画面**：Chrome 后台跑，用 **Rough.js** 画手绘风线条，**Lucide** 提供 1800 个图标，也能放图表、代码、截图
* • **背景音乐/音效**：每个视频自动生成，人说话时音乐自动压低
* • **合成**：**ffmpeg** 全部拼成 MP4

Agent 看不了视频，所以 explainroo 还给了几个检查手段：存关键帧截图、生成缩略图表、版面检查（文字会不会被切掉/重叠）、语音检查（有没有读错词）。针对竖屏短视频，还有 `--view-width 854` 参数能查字是不是太小。

**全程在本地跑，一分钱不花**。你的 Agent 服务另算，那是它自己的条款和价格。如果想让 Agent 用 AI 画插图，可以走 OpenRouter，那部分需要按图付费。

---

### 几个细节挺实用

**五种风格**，`video.json` 里改个 `look` 就能换：`paper`（笔记本手绘感）、`clean`（极简白底黑线）、`chalk`（黑板粉笔风）、`blueprint`（蓝图工程图风）、`midnight`（深色霓虹风）。

**多种尺寸**：横屏给 YouTube，竖屏给 Shorts/TikTok/Reels，4:5 给 Instagram/LinkedIn，正方形也有。竖屏平台自带的按钮区域，explainroo 会自动避开不让文字挡住。竖屏、4:5、正方形视频还能加逐字点亮的字幕。

**语速可调**：`"pace": 1.2` 就是全流程快 20%（语音、停顿、动画、音乐都跟着快），范围 0.7~1.6，1.0 是正常。

**还能做产品演示视频**：Agent 根据代码或网站还原应用界面（颜色、字体、按钮文案都对上），鼠标指针点点点、输文字。作者自己的两个产品 Unspar 和 Vroni 都有现成例子，`examples/unspar-demo` 里能看到文件长啥样。官网上还有 Gmail、ChatGPT、Claude 的非官方演示。

**水印**：每个视频角落会有个小小的 "explainroo.com"，`"watermark": false` 能关，但作者建议留着，方便别人发现这个工具。

### 我试过之后的感受

**好处**：

* • 真·本地跑，数据不出门，没 API 账单焦虑
* • Agent 只用写脚本和画面描述，门槛低
* • 手绘风 + 图标库 + 自动配乐，成片质量超过预期
* • 多平台尺寸、避让安全区、逐字字幕这些短视频细节都想到了
* • MIT 协议，随便改、随便用

**局限**：

* • **目前最配合 Claude Code + Opus 5.5**，别的 Agent 效果可能打折
* • 复杂场景下，Agent 写 `scenes.js` 可能要调试几轮才对
* • 语音模型 Kokoro 虽然免费但口音/语调选项有限，中文支持得看具体版本
* • Chrome 后台渲染占内存，长视频/高分辨率得留意机器配置
* • 产品演示模式里“从代码还原界面”这步，对复杂前端框架可能还原不全

---

### 适合谁

* • 想快速产出技术讲解/教程视频的开发者、技术博主
* • 需要给产品做演示视频、但不想花钱找动画公司的小团队
* • 喜欢折腾 AI Agent 工作流、想把“生成视频”加进自动化管线的人

**不适合**：

* • 追求好莱坞级动画效果、需要精细逐帧控制的专业视频制作
* • 完全不想碰代码、只想拖拽生成的用户（这工具本质是给 Agent 用的）
* • 需要批量、工业化产出视频的场景（目前还是单视频交互式生成）

---

### 结语

总的来说，explainroo 把“写脚本 → 配画面 → 合成视频”这套流程用本地开源模型跑通了，工程细节做得挺细，Agent 协作体验也不错。如果你手头有 Claude Code，周末克隆下来玩玩，半小时能出个像样的技术科普短视频，挺有成就感的。
