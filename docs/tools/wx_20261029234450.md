# 多开几个 Claude Code 就忘了谁在跑测试、谁卡在权限确认？实测这个像素风监控面板能不能救场

手里常跑三四个 Claude Code 会话，再加个 Codex CLI，经常遇到这情况：终端 A 卡在“Do you want to run npm test?”，终端 B 跑 build 跑了 20 分钟还没出结果，终端 C 早就跑完了但我忘记看，Codex 那边更是不知道跑到哪步了。以前靠 `tmux` 分屏、靠 `claude statusline` 看额度、靠 `gh run watch` 盯 CI，终究是“信息在终端里、人在终端外”，得频繁切窗口、敲命令才能拼凑全貌。

前几天在 GitHub 看到 **Habblaud**，号称“Claude Code 和 Codex 的虚拟办公室：每个项目一间房、每个 Agent 一个像素人、实时显示活动、额度、等待、Shell 进度，还能在网页上批权限、发指令、甚至围观他们下班后打乒乓球”。我用 Docker 在 MacBook Pro M2（macOS 14.6）和一台 Ubuntu 22.04 服务器上分别跑通，记录一下实测细节。

---

### 装上手：Docker 一条命令、Mod 插件自动装好

前置：Node.js 22.12+、Docker Desktop、Claude Code 2.1.287+（用 Mod 插件）、已登录一个或多个账号。

```
git clone https://github.com/marmottajr/habblaud.git  
cd habblaud  
npm install          # 只装构建工具，运行时零依赖  
npm run docker:up    # 推荐：自动检测账号、只读挂载 ~/.claude*、构建镜像、后台常驻
```

脚本会自动检测 `~/.claude`、`~/.claude-*` 等配置目录，只读挂载进容器；如果你用 `CLAUDE_CONFIG_DIR` 或 alias 管理多账号（如 `alias c='claude'`, `alias d='CLAUDE_CONFIG_DIR=~/.claude-work claude'`），它会读 shell rc 里的 alias 给每个账号分字母（C、D…）。

浏览器打开 `http://localhost:4747`，楼里已经有电梯、前台、茶水间、休息室、走廊。这时候在任意项目里跑 `claude`，几秒后你会看到：电梯“叮”一下，一个像素人（随机巴西名字，如 Marina、Henrique、Luan）走进对应项目的房间，坐到桌前，显示器亮起 💻、键盘发出细微敲击声（可开声音）。

**装 Mod 插件（强推，解锁额度实时显示、批权限、发消息）**

```
npm run mod:install              # 全装：mod + 权限插件 + 消息插件  
npm run mod:install -- --sem-permissoes   # 不装权限插件  
npm run mod:install -- --sem-mensagens    # 不装消息插件
```

它会用 `claude plugin` 把 `habblaud`、`habblaud-permissoes`、`habblaud-mensagens` 装进每个账号的 `settings.json`，旧版 tap/hook 自动备份并移除。装完 `npm run mod:status` 确认，已开会话用 `/reload-plugins` 生效。

### 核心亮点一：像素办公室里，“状态”不是图标而是动画

每个 Agent 的状态不是列表里的一个 badge，而是**有行为、有节奏、有细节的动画**：

| 状态 | 你在办公室里看到的 |
| --- | --- |
| **Working** | 坐在桌前，显示器亮着，头顶气泡显示 📖 读文件、✏️ 写代码、💻 跑终端、🧪 跑测试、🌐 搜网页…… |
| **Needs You** | **跑到桌前举手、红灯闪烁、屏幕弹“需要回应”卡片** ——正等你批权限或答问题 |
| **Waiting Shell** | 任务交完了但留了命令跑（测试、构建、部署），人留在桌前，**头顶沙漏转**；0-3 分钟吃爆米花看终端，3-10 分钟抱怨转椅，10-25 分钟长蜘蛛网，25 分钟打瞌睡；命令结束撒彩带庆祝，失败落雨云 |
| **Idle** | 下班溜达：去茶水间喝咖啡、去饮水机、去洗手间、去休息室沙发刷手机、去洗手间镜子前整理仪表；有别的闲人会自发凑成“社交圈” |
| **Subagent Done** | 拿着 📦 走到主 Agent 桌前交付结果，然后坐电梯走人 |
| **Session End** | 最后一个离开时，**走到墙边关灯、坐电梯下楼**，房间变成花园；如果花园夹在两房间中间，远的那间房会“搬家”过去填空 |

日夜循环：凌晨草地蓝幽幽、路灯亮、萤火虫飞；清晨/黄昏暖色调、阳光斜射地板形成光带；白天全亮。`Config > 日夜循环` 可锁定白天/黑夜/自动，URL 加 `?hora=21:30` 定点预览。

### 核心亮点二：权限批准、回答问题、发消息——全在网页上，不用切终端

**权限请求**（需装 `habblaud-permissoes`）：  
Agent 要跑命令、改文件、开网页，终端里弹确认的同时，办公室里对应像素人举手、屏幕弹卡片，显示完整命令或 diff，按钮：

* • **批准**（含“批准且不再询问”，同终端规则）
* • **拒绝**（可填理由，可选“中断 Agent”）
* • **回终端处理**（撤回办公室卡片）

**Agent 提问**（AskUserQuestion）：单选/多选/填空，网页上直接选、回车提交。

**发消息**（需装 `habblaud-mensagens`，Claude Code 2.1.287+）：  
点进任意主 Agent 详情，底部有输入框，回车发送，**像在终端里打字一样进会话**。Agent 忙时进队列（显示“排队中/已送达/未送达”），闲时立刻生效。Codex 也支持（走 `codex queue`）。

**关键安全设计**：终端、批权限、发消息、改角色**仅在“仅本机访问”下可用**（`HABBLAUD_HOST=127.0.0.1` / `HABBLAUD_BIND=127.0.0.1`）。一旦 `.env` 里 `HABBLAUD_BIND=0.0.0.0` 暴露局域网，这些功能**自动彻底关闭**，无法手动开启。手机端只能看、不能动。

### 核心亮点三：5 小时 / 周额度实时、多账号自动识别、Codex 零配置进场

**多账号**：每个 `~/.claude*` 目录 = 一账号。读 `~/.zshrc`/`~/.bashrc` 里 `alias x='... claude ...'`（≤3 字母）给账号分字母、配色。顶部卡片实时显示：`账号 C：5h 用了 63%，周用了 41%，5h 重置于 14:22`。

**数据来源**：Mod 插件在会话内拿到 Claude Code 返回的 plan limits，只存百分比、重置时间到 `~/.habblaud/usage/<账号>.json`。**不读对话、不调模型、不出网**。旧版本用 `statusline` tap 做同样事，Mod 方式更准、更省事。

**Codex**：零安装自动检测 `~/.codex*`、`CODEX_HOME`，读 `sessions/`、`thread-writer-locks/` 显示会话、活动、额度（仅 token、无成本）。装 hooks（`npm run codex:install` 并去 `/hooks` 批准）后：实时活动、举手批权限（25 秒超时）、发消息（`codex queue`）。Docker 下发消息需宿主机跑 `npm run codex:bridge`。

### 核心亮点四：GitHub 事件原地“庆祝/报警”、Timelapse 回放、My Day 统计

**GitHub 动画**（零 token、零网络、纯读 transcript）：

* • PR 开/合、Release 发布 → **全屋彩带、所有人鼓掌跳、横幅“PR #12 merged!” 12 秒**
* • CI 红 → **屋顶警灯闪、地板变红、责任人头顶 “!” 气泡**，直到绿了再庆祝或 10 分钟超时
* • Push → 仅提示 + 进 Feed

**Timelapse**（L 键 / 顶部时钟）：  
把一天压缩回放：60×/180×/600×（10 小时压成 10/3.3/1 分钟），时间轴可拖、峰值标记可跳转、播放时画面轻微复古滤镜 + “REPLAY 14:32”水印。服务端每秒采样写 `~/.habblaud/timeline/`，保留 7 天，`HABBLAUD_TIMELINE=0` 关掉。

**My Day**（M 键）：  
今天时间去哪了？**Agent-小时**口径（两人同时干 1 小时 = 2 小时）：Working / Waiting You / Idle / Shell Running 各多少，**重点标出“等你批权限/答问题”总时长、最长一次是谁、哪项目、几点**。按小时/项目/账号拆解、表格导出、图例开关。保留 30 天。

### 核心亮点五：社交模拟——闲人不闲着，有性格、有关系、有经济系统

≥2 个 Agent 闲置（或等 Shell 超 40 秒）会自发凑“圈子”，**完全由客户端模拟、不影响真 Agent**：

| 圈子 | 场景 |
| --- | --- |
| 📺 TV | 看球/追剧/看动画，进球闪“GOL”全屋欢呼/叹气，瞌睡虫睡沙发 |
| 🎮 电玩 | 分屏赛车/格斗，BO3、嘴臭互怼、围观 |
| 👾 街机 | 单局对决 |
| 🏓 乒乓 | 5 分制、小球来回、气泡计分、围观 |
| ☕ 茶水间闲聊 | 八卦同事（“看见 Rafaela 的 commit 了？👀”）、讲笑话（集体大笑）、聊工作（“周五上线？😈”）、应景梗（“周五啦🎉”） |
| 💬 走廊闲聊 | 两人站着聊 |
| ✊ 猜拳赌币 | “乔肯波！”手势浮现、赢家庆祝、金币飞过去，**赌注取决于性格（爱赌的押大、抠门的押小）、不超输家余额** |
| 💄 洗手间镜子 | 涂口红/梳头、镜面倒影发光，可双人互借梳子 |

**性格系统**：每 Agent 2-3 特质（竞争/赌博/游戏/追剧/八卦/爱美/咖啡因/讲笑话/运动/害羞/抠门/爱睡/冷静/爱读书），决定偏好圈子、主动找谁、说话风格、甚至猜拳胜率。**种子固定，跨浏览器同一个人**。

**金币经济**：进办公室 100🪙（子代理 30）、任务完成 +10、下班 +5、子代理交付 +15、猜拳转账。余额、战绩、流水存 `localStorage`，3 天不用清零。**纯前端表演，不写服务端、不影响 Agent 行为**。

### 核心亮点六：隐私优先、只读本地、零遥测、可审计

* • **只读 Claude Code 目录**：`sessions/*.json`、`projects/**/*.jsonl`、`subagents/**/agent-*.jsonl`。安装脚本除外（有备份）。
* • **Mod 权限最小**：跑在会话里，只做 `mod/README.md` 列出的事；`claude plugin validate mod/habblaud` 可不运行直接看事件与调用。
* • **本地优先**：默认只监听 `127.0.0.1`，暴露局域网需显式 `.env` 配置，**暴露即失去终端/权限/消息/改角色**。
* • **零遥测**：唯一外网请求 = 每 6 小时匿名查 `api.github.com/repos/marmottajr/habblaud/releases/latest`（UA 带版本号），`HABBLAUD_UPDATE_CHECK=0` 可关。
* • **无凭证**：不读 password/token。`.claude.json` 只取 email/org/usage 缓存。敏感字段（Bearer、sk-、ghp\_、AKIA、JWT、URL 密码）进浏览器前全打码 `***`。
* • **CSRF/DNS Rebinding 防护**：拒绝非 localhost 来源 POST、拒绝 iframe 嵌入、拒绝非本机 IP 访问终端/权限/消息/角色编辑 API。
* • **Codex 隔离**：Docker 只挂 `sessions/`、`archived_sessions/`、`thread-writer-locks/` 三目录只读；不碰 `auth.json`、`config.toml`、shell 快照、prompt 历史、数据库。

### 避坑与总结

1. 1. **强依赖 Claude Code 非公开会话文件格式**（版本升级可能破坏，作者在 Aviso 里明确提醒）
2. 2. **仅 macOS/Linux 测试**（Windows 需 WSL2 + Docker Desktop）
3. 3. **手机端只读、无交互**（安全设计）
4. 4. **社交模拟纯前端、无服务端状态同步**（换浏览器金币/性格重置）
5. 5. **Timelapse/My Day 仅记录 Habblaud 运行期间的数据**
6. 6. **Mod 插件需 Claude Code 2.1.287+**，旧版需用 tap/hook 方案
7. 7. **安装体积**：Docker 镜像约 1.2 GB（Node 24 Alpine + 构建产物），`npm install` 仅构建依赖，运行时零 npm 包
8. 8. **启动耗时**：`docker:up` 首次约 2-3 分钟（构建），后续约 10 秒；宿主机 Node 直接跑 `npm start` 约 3 秒
9. 9. **内存占用**：容器约 80-120 MB，浏览器标签页约 60-100 MB，Canvas 渲染轻量，长开不漏
10. 10. **CPU 占用**：空闲 <1%，满屋 10+ Agent 约 3-5%（浏览器侧），服务端 1 秒轮询极轻
11. 11. **延迟**：终端输出 → 网页显示约 1-2 秒（SSE 推流），权限卡片几乎同步弹出
12. 12. **多账号识别**：alias 解析准确，无 alias 自动派 A/B/C，需在 shell rc 里写 `alias x='... claude'`
13. 13. **Codex 集成**：免配置可看，装 hooks 可批权限/发消息，Docker 下发消息需宿主机 `codex:bridge`

---

我个人觉得：如果你常在本地并行跑多个 Claude Code/Codex 会话，**想用“楼层、房间、人、动画”这种直观隐喻把“谁在干啥、谁卡住了、额度还剩多少、CI 红没红”一次性看清**，Habblaud 是目前**最好玩、最贴心、工程完成度最高**的可视化方案。它没搞复杂的 Dashboard、没要你配 Prometheus/Grafana、没上云、没要 token，就是把 Claude Code 已经写在硬盘上的文件“翻译”成像素办公室，顺手加了批权限、发消息、看额度、回放一天、数等待时长这些**正好解决痛点**的功能。

比较适合：本地多会话并行开发的个人/小团队；想直观掌握“Agent 时间去哪了、等待成本多高”的 Tech Lead；喜欢把工具链可视化、甚至想围观 Agent “下班生活”的极客。

不太适合：完全在云端/远程服务器跑 Agent、不在本地开 Claude Code 的团队；需要企业级审计、RBAC、历史留存、告警对接的生产监控场景；Windows 原生不装 WSL2/Docker 的用户。

把它当“给本地 Agent 装个可视化前台、顺手接管权限确认和额度看板”用，心态最稳。v0.8.0 已支持 Codex hooks、GitHub 事件动画、Timelapse 导出素材、角色编辑器，更新频繁（CHANGELOG 细致、Release 自动化），值得 Star 跟进。
