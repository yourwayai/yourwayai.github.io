Mac 用久了，菜单栏右侧一定会变成难民营：一个软件一个图标，还个个不肯消失。Thaw 干的就是这件事——把不用的图标收进隐藏区，留一个手势或快捷键唤起，还能用键盘直接搜。这种工具不是没有先例，商业方案里 Bartender 是老面孔，Thaw 的区别是 GPL-3.0、免费、无订阅。我在这台 macOS 26.6.2 的机器上完整走了一遍安装和核验流程。

### 💻 部署实录

安装路径按 README 的分版本表走，我这台机器跑 macOS 26，对应的稳定线命令是：

```
brew install --cask thaw
```

实际输出：

```
✔︎ Cask thaw (2.1.0)  
==> Moving App 'Thaw.app' to '/Applications/Thaw.app'  
🍺  thaw was successfully installed!
```

装完做了几项核验。公证状态：

```
$ spctl -a -vvv /Applications/Thaw.app  
/Applications/Thaw.app: accepted  
source=Notarized Developer ID  
origin=Developer ID Application: Toni Foerster (456BPWQ6U5)
```

签名细节、版本号、系统要求和 URL 协议也都读了 Info.plist：`LSMinimumSystemVersion` 是 26.0，也就是说 Thaw 2 这条线直接放弃了 macOS 15 及更早（那些机器要去发布页下 Thaw 1）；`LSUIElement` 为 true，Dock 里不出头；`CFBundleURLSchemes` 里确实注册了 thaw。应用包 34 MB，launch 前 `defaults read com.stonerl.Thaw` 确认没有残留配置写入。

需要说明的是，我没有启动它做交互——装完之后要真跑起来得手动给 Accessibility（辅助功能）权限，这步我在当前会话里点不了，所以本篇只覆盖安装、签名、包体层面的实测，动效、触发器和外观这些 README 里的描述一律按项目口径转述。

### 🍺 两个我觉得设计得不错的点

一个是**菜单栏被当成可编程对象**。每个核心动作都有 thaw:// 深链，比如 `open "thaw://toggle-hidden"`、`open "thaw://search"`，官方有 Raycast 扩展，Shortcuts、Alfred、Keyboard Maestro、BetterTouchTool 乃至一行 shell 都能驱动它。Info.plist 里能看到协议注册是真的，不是营销说法。配合键盘搜索任意菜单栏图标这个入口，「隐藏一半图标」就从设置题变成了随手操作。

另一个是**网络行为写到明处**。README 挂了一个"What Thaw sends over the network"文档，内容很具体：没有分析和追踪，联网只发生在更新检查（ thaw-app.github.io ）、随之而来的更新说明和 What's New（ raw.githubusercontent.com ），每一项在设置里都能关，关死之后零请求。更新包签名校验后才安装。它还在 README 里明确说 Screen Recording（屏幕录制）权限是可选的——不开就退化成用应用图标代替实时预览，壁纸取色功能会没有。对一个要常驻后台的工具，这套披露比多数竞品体面。

### 📊 避坑与总结

问题不少，而且集中在它最核心的能力上：

1. 1. **52 个 open issue，大半是操作层面的回归**。比较扎眼的：`#1338` 从 v2.0 开始，把应用切全屏会触发屏幕录制的「蓝点」；`#1330` 3.0.0-alpha.8 在 macOS 27.0.1 启动即崩（Fatal error: Duplicate values for key）；`#1329` 隐藏区一有东西，菜单项就消失；`#1324` 一启动 LibreOffice 或 Safari 菜单栏就乱；`#1265` 直接「点哪都没反应」。
2. 2. **三条版本线并存，容易装错**。macOS 27 要装 `thaw@beta` 拿 3.0，macOS 26 是 `thaw` 的 2.1.0，14/15 只有 Thaw 1。就这还出过 `#1221`：`thaw@beta` 曾经同时指向 2.1.0-beta.6 和 3.0.0-beta.1，用户根本分不清自己装了什么。
3. 3. **外观配置不跨 Space**。`#1038` 外观不跟随虚拟桌面，`#1044` 配置文件不尊重不同菜单栏图标布局——对一个卖点就是「按 Space 排布」的工具，这两条有点打脸。
4. 4. **成熟度**。Roadmap 自己写的是「保持兼容 + 加固发布实践」，清单很短且注明「是意图不是承诺」；OpenSSF Best Practices Gold 和 Scorecard 徽章在 README 里挂着，我没有逐一验证这两个 badge 的当前状态。

我的判断：macOS 26、想清菜单栏、又愿意给辅助功能权限的人，值得装——免费、GPL、无追踪，深链和 Raycast 集成是真的能打；依赖外观跨 Space 或者系统版本在 26 以下的，先看 issue 列表再决定。把它当「免授权费的菜单栏整理方案，不是开箱即用的 Bartender 替代品」用，心态最稳。
