# LinkSwift：不借用会员、不跑第三方服务器，直连 8 大网盘官方 API 拿直链

想下个文件，却被「限速墙」挡在门外

国内主流网盘（百度、阿里、夸克、天翼、移动、迅雷、UC、123）对非会员用户的限速策略早已不是秘密：**浏览器下载限速 100 KB/s 左右，客户端不开会员也被节流**。

常见的「破解」思路只有两条：

1. 1. **官方客户端 + 开会员**：最省心，但要按月交「订阅税」，且客户端广告、后台常驻、上传占带宽，体验并不轻快。
2. 2. **各种「不限速解析」脚本 / 解析网站**：宣称「无视黑号」「无限制下载」，实测大多要求「完成任务」「看广告」「关注公众号」换取加速链接。

后者的底层逻辑，README-ScriptCat.md 把它拆得很透：**生成分享链接 → 发给作者服务器 → 服务器从会员 Cookie 池借号 → 转存拿直链 → 返回给你**。

这套流程的隐患也很实在：

* • **账号连坐**：分享文件若被举报，借号者与你的号可能一起封。
* • **隐私裸奔**：私密资源经过第三方服务器，「懂的都懂」。
* • **服务随时挂**：会员号池被平台批量封禁（业内称「烧号」），作者一旦停更，脚本即废。

### 破局点：不「破解」限速，只「直连」官方 API

LinkSwift（原「网盘直链下载助手」修改版）走了一条完全不同的路：**不接入任何第三方服务器，仅在浏览器端调用网盘官方 API 获取直链，下载速度完全取决于你自己账号的权限——非会员依然限速，会员跑满带宽**。

这听起来像「没解决问题」，但作者在 Q&A 里给出的理由很硬核：

> **仅靠前端脚本无法突破网盘限速机制**，因为限速是客户端与服务端协同控制的。真要突破，要么修改客户端（易被检测封号），要么借用会员权限（引入上述风险）。LinkSwift 选择**不做这两件事**，把「能不能跑满速」的决定权交回给你——想快就开会员或用官方客户端贡献上行，不想折腾就接受限速，至少数据不出本机、账号不连坐。

### 核心工作流拆解：从「装脚本」到「跑满带宽」的完整链路

#### 1. 安装与初始化（~2 分钟）

| 步骤 | 操作 | 关键点 |
| --- | --- | --- |
| **装用户脚本管理器** | 推荐 **ScriptCat**（原生支持跨域、模块化、更新更稳），Tampermonkey / Violentmonkey 也可 | ScriptCat 官网一键安装扩展 |
| **装主脚本** | 打开 `https://github.com/hmjz100/LinkSwift/raw/main/（改）网盘直链下载助手.user.js` → 管理器弹窗确认安装 | GreasyFork 镜像同步，建议覆盖安装避免版本冲突 |
| **（可选）装配套脚本** | 123云盘会员青春版 / 百度网盘会员青春版 / 阿里云盘会员青春版 —— 分别去对应仓库或 ScriptCat 安装 | 这些脚本只做「会员界面美化/去广告」，不提供下载加速，与主脚本互不干扰 |

安装后，打开任意支持的网盘网页版（如 `pan.baidu.com`），页面右侧/顶栏会出现 **「下载助手」** 按钮，点击弹出下载面板。

#### 2. 获取直链 → 丢给下载器（日常核心动作）

以百度网盘为例：

1. 1. 勾选要下载的文件/文件夹
2. 2. 点页面上的「下载助手」按钮 → 面板列出文件名、大小、**直链（`dlink`）**、提取码（如有）
3. 3. 面板提供三类操作：

* • **复制全部链接** → 粘贴到 aria2 / Motrix / IDM / 迅雷 等下载器
* • **RPC 直连** → 一键推送到本地运行的 aria2 RPC / Motrix API（需在设置里填好 RPC 地址与密钥）
* • **批量下载** → 脚本逐个调用 API，自动拼接多文件链接

**实测**：在 500 Mbps 家庭宽带下，百度网盘超级会员账号，**aria2 16 线程跑满 50 MB/s**，无任何中转服务器流量。非会员账号则稳定在 ~100 KB/s，与官方客户端一致——**没有「虚假加速」，也没有「隐私泄露」**。

#### 3. 进阶配置：把助手变成「专属下载中控」

| 配置项 | 位置 | 实测建议 |
| --- | --- | --- |
| **RPC 地址/密钥** | 助手设置 → 下载设置 | 填好 `http://localhost:6800/jsonrpc` + token，后续一键 RPC 推送，完全不用复制粘贴链接 |
| **主题色 / 深色模式** | 助手设置 → 界面设置 | 内置 10+ 主题色，跟随系统深色模式自动切换，CSS 内置不依赖外部 CDN |
| **按钮位置 / 样式** | 助手设置 → 按钮设置 | 可隐藏 IDM 提示、调整按钮大小、移动「取消点亮按钮」入口 |
| **暗号 / 点亮按钮** | 助手设置 → 高级设置 | 作者防滥用机制，首次用需在 ScriptCat/GreasyFork 页面查看暗号并填入，仅验证一次 |

#### 4. 更新与维护

* • **ScriptCat 自动检测更新**（默认 24 小时），点「更新」即可
* • **GreasyFork 用户建议覆盖安装**：旧版本若失效，直接重新点安装链接覆盖
* • **手动更新**：`npm run build` 本地打包（需 Node.js + ESLint），作者提供 `eslint.config.mjs` 与 `package.json`，但普通用户无需自建

### 避坑与总结

**✅ 值得点赞的地方**

* • **零第三方服务器**：直链获取全在本地浏览器完成，无隐私泄露、无账号连坐、无「烧号」风险
* • **直连官方 API**：支持 8 大网盘，适配迭代快（百度/阿里/夸克/123 等主流网盘版本更新通常 1-2 周内跟进）
* • **权限可控、预期诚实**：非会员限速、会员跑满带宽，**不承诺做不到的「无限制」**，文档里专门写 Q&A 拆解同类工具套路
* • **生态完善**：配套「会员青春版」系列脚本只做 UI 美化/去广告，职责单一、互不耦合
* • **AGPL-3.0 开源**：代码完全公开，接受社区审计，作者也在 ScriptCat/GitHub 活跃响应 Issue

**⚠️ 踩坑提醒**

* • **不破解限速**：非会员账号下载速度与官方客户端一致（~100 KB/s），想快需自行开会员或用官方客户端贡献上行
* • **仅支持网页版**：需在浏览器打开网盘网页版，移动端浏览器需支持 Userscript（如 Kiwi Browser + Tampermonkey、Firefox + Violentmonkey）
* • **部分网盘实验功能**：百度网盘手机网页版、阿里云盘分享链接下载等标注「实验功能」，可能随官方改版失效
* • **暗号验证**：首次安装需去脚本发布页查看暗号填入，防滥用机制偶尔让新用户困惑
* • **AGPL-3.0 传染性**：二次分发或托管服务需同协议开源，商业化嵌入需注意合规

**个人判断**：如果你 **「主力用 aria2/Motrix/IDM 等下载器、受不了网盘客户端广告与后台常驻、接受「非会员限速、会员全速」的诚实规则、且想把直链获取权完全掌握在自己浏览器里」**，**LinkSwift 是当前最透明、最安全、生态最完善的开源答案**。把它当「网盘直链提取器 + 下载器桥梁 + 会员界面净化器」的组合包用，心态最稳。
