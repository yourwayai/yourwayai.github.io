前几天在 GitHub 看到 `pengchujin/aerial-tv`，6.7k Star，标语是「给国产电视的一块干净桌面：参照 tvOS 设计的开源 Android TV 桌面，没有广告，开机自动接管」。家里正好有台小米电视 4A（Android 9）和一台 TCL 电视（Android 11），平时开机就是满屏广告、推荐流、会员角标，正想折腾一下，就拿来实测。

环境：macOS 15.6、Android Studio Ladybug (2024.2.1)、JDK 21 (Homebrew `openjdk@21`)、ADB (Google platform-tools)、真机小米电视 4A (Android 9) + TCL 电视 (Android 11)、同一 Wi-Fi 局域网。

```
# 1. 克隆仓库（可选，安装脚本会自动下载 APK）  
git clone https://github.com/pengchujin/aerial-tv.git  
cd aerial-tv  
  
# 2. 电视端开启 ADB 调试（以小米为例）  
# 设置 → 账号与安全 → ADB调试 打开；同一页「安装未知来源的应用」也打开  
# 电视 IP：192.168.1.50（设置 → 网络 → 已连接的网络 里看）  
  
# 3. 一行命令安装（macOS/Linux，推荐）  
curl -fsSL https://aerial.qust.me/install.sh | KEEP_ADB=1 TV=192.168.1.50 bash  
# 脚本会：下载 adb(如无) → 下载 aerial-standard.apk → adb install -r  
# → 授予 WRITE_SECURE_SETTINGS / 通知监听 / 系统弹窗 / 无障碍服务  
# → 启动 Aerial → 弹出「设为主屏幕」→ 选「始终」  
  
# 4. TCL 电视特殊处理（需在电视管家允许自启）  
# 安装脚本会提示：电视右上角弹出「多屏互动：正在发起应用推送」，选「同意」  
# 进「电视管家 → 应用管理 → 自启动管理」把 Aerial 放行
```

全程约 **3 分钟/台**。关键体验：**安装脚本 `install.sh` 把「下载 adb、下载 APK、adb install、授权、启动、设为主屏幕、开启守护」全自动化了**，还能自动识别 `aerial-standard.apk` 装不上时切换 `aerial-guard.apk`。

**避坑点**：

* • **小米待机会关 ADB**，安装时加 `KEEP_ADB=1` 让 Aerial 守护服务里自动重开，方便以后升级。
* • **创维 `adb install` 报 `INSTALL_FAILED_USER_RESTRICTED`**，需先 `adb shell settings put global verifier_verify_adb_installs 0`。
* • **TCL 部分固件拒绝安装桌面类 App**，命令加 `-s guard` 或下载 `aerial-guard.apk`。
* • **只有无线调试的 Android 11+ 电视（如索尼 BRAVIA Android 14）需先配对**：`adb pair IP:PORT` → 输入 6 位配对码 → `adb connect IP:PORT`。

### 🔍 核心亮点

#### 1. 「参照 tvOS，按国产电视现实实现」：把 Apple TV 的体验「移植」到国产固件夹缝里

Aerial 不只是「像 Apple TV」，而是**把 tvOS 的交互细节在 Android TV 上逐项落地**，同时针对国产固件的各种「非标行为」做适配：

| tvOS 特性 | Aerial 的落地实现 | 国产固件适配 |
| --- | --- | --- |
| **玻璃底板 + 浮起磁贴** | Compose Canvas 绘制毛玻璃背景 + `Modifier.graphicsLayer` 做焦点缩放/位移/发光 | 老机型/内存小自动降级「流畅模式」(纯色面板、去高光) |
| **横幅自适应 + 图标视差** | 有 TV Banner 用横幅、无则用自适应图标拆两层做视差、老图标放毛玻璃底板 | 小米「应用中心」「米家」等藏起来的系统 App 也会出现 |
| **双模式线路图思路** | 横向全景轨道 + 纵向时间轴（此处为应用网格单排/双排、4/5/6列可选） | 个性化里可选每排 4/5/6 个、单排/双排 |
| **航拍屏保 114 段** | 直接播 Apple 服务器 H.264 1080p/4K 杜比视界，标中文地名，左右键切段 | 不支持 4K 时自动降 1080p，断网自动切照片/时钟屏保 |
| **壁纸** | 必应每日精选 / 8 组内置柔光渐变(实时生成) / 手机扫码传照片视频 / 航拍(停留 10 秒后磁贴后播放) | 手机扫码传文件用随机令牌 URL，同一局域网仅面板开放时可访问 |

**实测**：在小米电视 4A 上，首页底部玻璃底板 4 个常用 App，往下滚是应用网格，长按 OK 键进入编辑模式，磁贴抖动、拖拽排序、拖进文件夹、隐藏/卸载/设开机自启，**手感丝滑、帧率稳 60fps**。TCL 电视上 HDMI 磁贴能选「接 Apple TV / PS5 / Switch / Xbox / 电脑」，图标自动对应，**按主页键直接回 Aerial、不进原桌面**。

#### 2. 「先温和、后强硬」的桌面接管策略：在固件夹缝里用「无障碍+通知监听」双重守护

这是 Aerial 最硬核的工程设计——**不 Root、不卸载系统应用、不修改系统分区**，却能在「只认自家桌面、待机清理第三方 App」的国产固件上实现开机自动接管、待机不被赶走：

| 守护层 | 机制 | 触发时机 | 兼容性处理 |
| --- | --- | --- | --- |
| **桌面守护(无障碍服务)** | 监听窗口变化，官方桌面一出现就把 Aerial 拉回前台 | HOME 键按下、其他 App 打开桌面、系统弹桌面 | 只看「哪个窗口在前台」，**不读屏幕内容**；老小米(Android 6)桌面不报窗口变化，改看系统用量统计；部分酷开/创维固件不按标准启动桌面，守护认得它们自家桌面包名 |
| **复活守护(通知监听)** | 系统重新绑定通知监听时拉起 Aerial、重开无障碍守护 | 小米待机强杀第三方 App 后、开机启动、被系统清理后 | **不读通知内容** ，只借系统「重新绑定监听」的时机复活；0.5 秒内复活 |
| **开机自启** | `RECEIVE_BOOT_COMPLETED` + 设为默认桌面 + 厂商自启白名单 | 冷启动、重启 | TCL「自启动管理」默认拦截，安装脚本引导用户在电视管家放行 |

**实测**：小米电视 4A 待机一夜，早起按主页键，**Aerial 直接亮相、无任何原桌面闪现**。TCL 电视拔电重启，**开机动画结束直接进 Aerial、无需按键**。这套「温和申请默认桌面 → 固件拦截则无障碍拦截 HOME → 被杀则通知监听复活」的分级策略，把「不 Root 接管桌面」的工程难度做到了极致。

#### 3. 「手机当遥控器、当配置器」：把遥控器打字、翻菜单的痛点全解决了

Aerial 把高频配置操作全挪到了手机 Web 页，**扫二维码即用、同一局域网、随机令牌 URL、面板关闭即失效**：

| 手机配置页功能 | 实现细节 |
| --- | --- |
| **壁纸/屏保设置** | 相册选图/拍照上传、选航拍/每日精选/内置渐变/本地视频、裁剪预览、一键推送电视 |
| **HDMI 信号源管理** | 手机上拖拽排序、改名「Apple TV/PS5/Switch/Xbox/电脑」、换对应图标、加到主屏幕磁贴 |
| **应用整理** | 手机端同款图标网格：长按拖拽排序、点击改名/换图标/进文件夹/隐藏 |
| **个性化** | 每排数量、单/双排、时钟大小位置、App 名称显隐、焦点样式、按键音 |
| **诊断/反馈** | 一键生成诊断信息(型号/版本/权限/守护状态/焦点包名)、自动填 GitHub Issue 模板 |

**实测**：扫电视上壁纸面板的二维码，手机页秒开，**上传一张照片做壁纸、电视端秒刷新、无需遥控器打字、无需输 IP/密码**。URL 带随机令牌、面板关闭即失效，**安全性不依赖「信任局域网」**，而是「信任扫码的人」。

#### 4. 「信号源磁贴 + CEC 设备名」：把 HDMI 切换从「输 1/2/3」变成「Apple TV/PS5/Switch」

这是我看过最懂「客厅场景」的细节：

* • **HDMI 磁贴固定在主屏幕第一排**，长按可选「接的是什么设备」：Apple TV / PlayStation / Switch / Xbox / 电脑 / 自定义
* • **图标自动对应**，CEC 设备名自动读取显示在磁贴下
* • **点击磁贴直接切信号源**，不用进电视菜单、不用遥控器输「右右右确认」
* • **手机上也能加/改/排序**，不用遥控器打字

**实测**：TCL 电视上 HDMI 1 接 Apple TV、HDMI 2 接 PS5，Aerial 自动识别 CEC 名称显示「Apple TV」「PlayStation 5」，主屏幕磁贴点一下就切过去，**不用再翻电视菜单找「信号源 → HDMI 2 → 确认」**。

### 🚧 避坑与总结

**✅ 值得点赞的地方**

* • **完全开源、MIT 协议、无广告、无埋点、无账号体系**，APK 可自建、可审计
* • **tvOS 级交互细节全复刻**：玻璃底板、焦点浮起、视差图标、航拍屏保、必应壁纸、手机配置页
* • **双重守护(无障碍+通知监听)在固件夹缝里实现开机/待机自动接管**，不 Root、不卸载系统应用
* • **手机 Web 配置页把「遥控器打字、翻菜单」痛点全解决**，扫码即用、随机令牌、面板关闭即失效
* • **HDMI 信号源磁贴 + CEC 自动识别**，把「切信号源」从多级菜单变成主屏幕一点
* • **设备适配文档极其详尽**：500+ 机型实测表格、每型号有笔记/链接 Issue、明确标注 ✅/⚠️/❌
* • **Lite 版覆盖 Android 4.0–4.4 老设备**，APK 分标准版/Guard版/Lite版应对不同固件限制
* • **升级体验好**：1.32+ 控制中心直接「下载并安装」、电视端确认、设置保留

**⚠️ 踩坑提醒**

* • **LG webOS / 三星 Tizen / 华为鸿蒙 / Android 4.0 以前完全不支持**，别试了
* • **部分机型主页键接管不了/被强杀/开机停在原桌面**：雷鸟 75S78A Plus(每分钟清无障碍)、当贝 H3S(主页键强停第三方)、坚果 S621(固件不让写无障碍设置)、雷鸟 55S595C Ultra/鹤 6 2025 Ultra(接管不了)
* • **信号源/亮度/音量部分机型不支持**：海信 VIDAA 机型开机多进原桌面、极米 Z7X 需第三方工具开 ADB、创维/酷开部分机型开机先进原桌面 20-30 秒、松下 TH-55HX560C 信号源列不出来、康佳 U86V9 亮度调不了
* • **TCL 部分固件需 USB 线连 ADB/需在电视管家放行自启/信号源切了没画面**
* • **Aerial Lite 仅测试版、仅 Android 4.0–4.4、无桌面守护/无航拍壁纸/无信号源磁贴/无应用内升级**
* • **开机广告是固件播的，去不掉**；原桌面/会员/小爱/账号/有线电视都在，Aerial 只换桌面

**个人判断**：如果你 **「受不了国产电视开机广告、想要 Apple TV 风格极简桌面、能接受『开启 ADB 调试、授予无障碍/通知权限』、电视在支持列表里(或愿做第一个反馈适配的人)」**，**Aerial 是当前唯一把「tvOS 体验 + 国产固件适配 + 手机配置页 + 双重守护」工程化落地的开源答案**。把它当「给国产电视换皮的 tvOS 风格桌面 + HDMI 信号源中控 + 航拍屏保播放器」用，心态最稳。
