# FluentRead：开源双语阅读神器，网页/文档/图片/视频全模态翻译，本地优先可接 Ollama

* **原文链接**: [https://mp.weixin.qq.com/s/h2sfMH-2XQBFi4nnw54sEA](https://mp.weixin.qq.com/s/h2sfMH-2XQBFi4nnw54sEA)

**FluentRead**（FluentRead/FluentRead）是一个 **开源浏览器双语翻译扩展**，GitHub 斩获 10.1k Star、568 Fork。它的定位很务实：**「An open-source browser extension for bilingual translation.」**——不做云端 SaaS、不做账号体系、**只做浏览器里最好用的双语阅读工具**。核心能力覆盖 **网页/选词/文档/图片/视频** 五大模态，支持 **免费引擎/DeepL/OpenAI/Gemini/Ollama 本地模型** 多引擎切换，内置 **AI 读书卡（句法/用法/练习）+ 学习中心（语境词汇书）**，**GPL-3.0 协议、本地优先、可选 WebDAV/Google Drive 同步**，支持 **Chrome/Edge/Firefox/Safari/Userscript/Thunderbird** 全平台分发。

### 核心优势解析

#### 1. 「五模态一体」：把「翻译」从「网页」拓展到「文档/图片/视频/会议」

这是 FluentRead 最大的产品护城河——**一次安装，覆盖所有「读外语」场景**：

| 模态 | 核心能力 | 典型场景 | 技术支撑 |
| --- | --- | --- | --- |
| **网页双语** | 逐段对照、悬停/划词翻译、原文还原、自动规则 | 读外文新闻/技术博客/社交媒体 | WXT content script + DOM 克隆插入 |
| **选词/划句** | 读书卡（释义/句法/用法/练习/朗读）、语境保存 | 精读长难句、积累词汇 | Vue 3 组件 + AI SDK (OpenAI/Gemini/Anthropic/Ollama) |
| **文档翻译** | PDF/ePub/DOCX 双语对照、编辑导出、保留排版 | 读论文/电子书/合同/报告 | pdfjs-dist (PDF) + pdf-lib (编辑) + turndown (HTML→MD) |
| **图片/漫画** | OCR 识别+翻译覆盖、保留画风/阅读序、气泡级对照 | 读日漫/韩漫/图表/截图 | tesseract.js (OCR) + onnxruntime-web (文本检测) + Canvas 覆盖 |
| **视频/会议** | YouTube/X 双语字幕、Google Meet/Teams/Zoom 会议实时字幕 | 看外语视频/参会/听课 | WebVTT 解析 + 字幕注入 + X 本地 AI 转录 |

**实测体验**：打开一篇英文技术博客，**右键「翻译页面」→ 双语对照保留原排版**；选中一句长难句，**弹出读书卡 → 句法树/用法解释/跟读练习 → 一键存入词汇书**；拖入一份 PDF 论文，**双语对照阅读 → 修正术语翻译 → 导出双语 PDF**；打开日漫图片，**OCR 自动跑完 → 气泡级中日对照 → 阅读序自动排序**；打开 YouTube 视频，**双语字幕同步显示 → 生词点击存词**。**全流程零切换上下文，一个弹窗/侧边栏搞定。**

#### 2. 「多引擎 + 本地模型」：把「翻译质量」的选择权还给用户

FluentRead **不绑定单一翻译服务商**，提供 **分级可选** 的引擎矩阵：

| 引擎类别 | 典型代表 | 适用场景 | 成本/隐私 |
| --- | --- | --- | --- |
| **内置免费** | MyMemory / Lingva / LibreTranslate | 快速浏览、非敏感内容 | 免费、隐私一般 |
| **专业付费** | DeepL (API) | 专业文档、高质量要求 | 按字符付费、数据进 DeepL |
| **云端 AI** | OpenAI (GPT-4o/4o-mini) / Gemini / DeepSeek / Anthropic | 复杂语境、长文本、术语一致性 | 按 Token 付费、数据进对应厂商 |
| **本地模型** | **Ollama (qwen2.5/llama3.1/gemma2 等) / wllama (WASM 本地推理) / transformers.js (浏览器端 WASM)** | **隐私极敏感、离线环境、零边际成本** | **零云端成本、数据不出浏览器** |

**关键设计**：**每个功能可独立配置引擎**——网页翻译用免费引擎，AI 读书卡用 GPT-4o-mini，文档翻译用 DeepL，图片 OCR 用本地 transformers.js，**互不干扰、按需付费**。

**实测**：配置 `Ollama (qwen2.5:7b)` 后，断网环境下**选词读书卡、文档翻译、图片翻译均可离线工作**，延迟 2-5 秒/句，**隐私敏感文档（合同/医疗报告/内部代码）再也不用担心上传云端**。`wllama` 甚至让**纯浏览器端（无后端）跑 Llama 3.1 8B** 成为可能，虽然首屏加载模型需 4-6GB 内存。

#### 3. 「AI 读书卡 + 学习中心」：把「翻译工具」进化为「语言习得工作流」

这是 FluentRead 区别于「沉浸式翻译/划词翻译/DeepL 扩展」的核心差异——**不止「看懂」，更要「学会」**。

**AI 读书卡**（选词/划句触发）：

```
┌─────────────────────────────────────┐  
│  原文：A good book opens a new world. │  
│  译文：一本好书为你打开一个新世界。   │  
├─────────────────────────────────────┤  
│  📖 句法结构：主语 + 谓语 + 宾语       │  
│  💡 用法解析：opens 表「使成为可能」   │  
│  🎯 练习：改写为被动语态               │  
│  🔊 朗读：原文/译文 TTS               │  
│  ➕ 存入词汇书（保留原句语境）         │  
└─────────────────────────────────────┘
```

**学习中心**（词汇书）：

* • **语境保存**：每个词/句自动关联「来源页面 URL + 原文段落 + 翻译 + 读书卡笔记」
* • **间隔重复**：内置 SRS 复习算法（可配置遗忘曲线参数）
* • **导出 Anki**：一键生成 `.apkg` 导入 Anki/AnkiDroid
* • **多维筛选**：按来源/标签/掌握度/词性/添加时间筛选

**实测**：阅读一篇 3000 词技术博客，**选词存词 15 个 → 学习中心自动关联语境 → 晚间复习 5 分钟 → 导出 Anki 继续刷**。**把「碎片化查词」变成了「结构化习得」**，这才是「双语阅读」的终局。

#### 4. 「全平台分发 + Userscript 兜底」：把「安装门槛」压到最低

| 平台 | 分发渠道 | 功能完整度 | 审核/更新 |
| --- | --- | --- | --- |
| **Chrome** | Chrome Web Store | 100% | 自动更新、审核快 |
| **Edge** | Edge Add-ons | 100% | 自动更新 |
| **Firefox** | Firefox Add-ons (AMO) | 100% | 人工审核、延迟 1-3 天 |
| **Safari** | 自建打包 (MV2) | 核心功能 | 需手动安装 .app、macOS 专属 |
| **Userscript** | Greasy Fork / 独立安装 | **仅网页翻译核心** | 无审核、即装即用、移动端可用 |
| **Thunderbird** | 基于 Firefox 包 | 邮件正文翻译 | 小众但刚需 |

**Userscript 版** 是「破圈」关键：**无需浏览器商店、移动端 Kiwi/Via/浏览器插件均可用、核心双语翻译/划词/规则全保留**。这让「公司电脑禁装扩展/手机 Safari/旧版浏览器」用户也能用上。

#### 5. 「隐私优先 + 可选同步」：把「数据主权」设计进架构里

| 数据类别 | 存储位置 | 同步选项 | 加密 |
| --- | --- | --- | --- |
| **设置/偏好** | 本地 `chrome.storage.local` / `browser.storage.local` | ✅ WebDAV / Google Drive | 本地加密后上传 |
| **学习记录/词汇书** | 本地 IndexedDB (Dexie) | ✅ WebDAV / Google Drive | 本地加密后上传 |
| **对话/会话** | 本地 IndexedDB | ❌ 不同步 | — |
| **使用统计** | 本地 | ❌ 不同步 | — |
| **云翻译文本** | 直发对应 Provider API | N/A | TLS 传输 |
| **本地模型数据** | 本地模型缓存目录 | N/A | — |

**关键承诺**：**「默认不上传任何用户数据，同步仅限配置/词汇书，且本地加密后再传」**。GPL-3.0 协议保证**源码透明、可自建、可审计、不可闭源商用不回馈**。

**实测**：配置 WebDAV (坚果云/Nextcloud/自建) 后，**换设备/换浏览器/重装系统 → 登录同步 → 设置/词汇书/快捷键/规则全回归**，体验接近商业 SaaS，**数据完全在自己手里**。

#### 6. 「WXT + Vue 3 + 单元/功能/回归全覆盖」：把「扩展工程化」做到了教科书级别

技术栈选型极其现代且务实：

| 层面 | 选型 | 理由 |
| --- | --- | --- |
| **构建/打包** | **WXT (Web Extension Tools)** | 零配置多浏览器构建、HMR、类型安全、Manifest V3 原生 |
| **框架** | **Vue 3.5 + TypeScript + Element Plus** | 组件复用、类型推导、UI 一致性、生态成熟 |
| **状态/存储** | **Dexie (IndexedDB) + @wxt-dev/storage** | 类型安全、响应式、跨上下文同步 |
| **PDF 处理** | **pdfjs-dist (渲染) + pdf-lib (编辑/导出)** | 标准库、WASM 加速、字体嵌入 |
| **OCR/视觉** | **tesseract.js + onnxruntime-web + transformers.js** | 纯 WASM/WebGPU、无后端、浏览器端跑模型 |
| **本地 LLM** | **wllama (WASM Llama.cpp) + @huggingface/transformers** | 纯浏览器端推理、量化模型、流式输出 |
| **AI SDK** | **Vercel AI SDK 7.0 (ai) + @ai-sdk/* 提供商* \* | 统一流式/工具调用/结构化输出接口 |
| **测试** | **Vitest 5.1 + 20+ 专用配置** | 单元/功能/回归/架构/翻译核心/视频/文档/用户脚本全覆盖 |
| **文档/演示** | **VitePress + Storybook 10.6** | 组件驱动开发、自动生成文档站、视觉回归 |

**测试矩阵**（package.json scripts 可见）：

* • `test:unit` / `test:functional` / `test:regression` / `test:architecture`
* • `test:translation-core` / `test:translation-sites` (站点兼容性矩阵)
* • `test:document` / `test:pdf-selection` / `test:video:*` / `test:userscript:*`
* • `test:cloud-backup` / `test:agent-bridge` (ChatGPT Plan 桥接)

**实测**：`corepack pnpm test`**全量跑完 2000+ 用例，CI 绿标通过**。这对「频繁发版、多浏览器兼容、用户数据零容错」的扩展项目是生存底线。

### 行业影响

**它与「沉浸式翻译 / 划词翻译 / DeepL 扩展 / KISS Translator / Duo Translator / Read Frog」的区别在于**：

| 维度 | 沉浸式翻译 | 划词翻译/DeepL 扩展 | KISS Translator | Duo Translator | **FluentRead** |
| --- | --- | --- | --- | --- | --- |
| 核心模态 | 网页双语 | 划词/页面 | 网页/PDF/EPUB | 网页/PDF | **网页/选词/文档/图片/视频/会议** |
| AI 读书卡 | 无 | 无 | 无 | 无 | **句法/用法/练习/朗读/语境存词** |
| 学习工作流 | 无 | 无 | 单词本 | 单词本 | **SRS 复习 + Anki 导出 + 语境关联** |
| 本地模型 | 无 | 无 | 无 | 无 | **Ollama / wllama / transformers.js** |
| 翻译引擎 | 固定几家 | 绑定 DeepL | 可配置 | 可配置 | **免费/DeepL/云 AI/本地模型 全矩阵** |
| 平台覆盖 | Chrome/Edge/Firefox | Chrome/Edge/Firefox | Chrome/Edge/Firefox | Chrome/Edge/Firefox | **全平台 + Userscript + Safari + Thunderbird** |
| 许可证 | 专有/源码可用 | 专有 | GPL-3.0 | GPL-3.0 | **GPL-3.0 (强Copyleft)** |
| 隐私模型 | 云端优先 | 云端优先 | 本地优先 | 本地优先 | **本地优先 + 可选加密同步** |
| 文档翻译 | 无 | 无 | PDF/EPUB 对照 | PDF 对照 | **PDF/ePub/DOCX 编辑导出 + 保留排版** |
| 视频字幕 | 无 | 无 | 无 | 无 | **YouTube/X/会议双语字幕 + X 本地转录** |

**行业信号**：

* • **「翻译扩展 → 语言学习工作流」** 是下一个进化方向：单纯「看懂」是底线，「习得/复习/迁移」才是护城河
* • **「本地模型 (Ollama/wllama/transformers.js) + 浏览器扩展」** 打通了「隐私敏感场景」最后一公里
* • **「Userscript 兜底 + 全平台分发」** 是开源扩展触达非技术用户的关键路径
* • **「GPL-3.0 + 商业化探索 (赞助/Ko-fi/企业定制)」** 是可持续开源的成熟范式
