# Modern Web Guidance：Chrome/Edge/Firefox/MDN 联合发布的「AI 编码 Agent 现代 Web 技能包」，Eval 实测准确率提升 19-36 个百分点

Google Chrome 团队联合 **Microsoft Edge、Mozilla Firefox、MDN Web Docs** 发布 **Modern Web Guidance**——一套 **面向 AI 编码 Agent 的「现代 Web 平台专业知识技能包」**，GitHub 源码仓库斩获 7k+ Star、595 Fork。

它的定位极其精准：**「Coding agents often default to older patterns because LLM training data contains vast amounts of legacy code.」**——解决「模型训练数据滞后导致 Agent 写旧代码」的结构性问题。核心交付：**250 个现代 Web 特性指南、6 大核心领域覆盖、Eval 驱动的 Token 高效剪枝、Legacy Scan 代码库现代化扫描、多 Agent 生态原生集成（npx skills / Claude Code / Copilot CLI / Antigravity CLI）**。**Apache-2.0 代码 + CC-BY 4.0 文档、早期预览版、持续扩充中**。

### 核心优势解析

#### 1. 「指南即技能」：把「Web 平台专业知识」封装为 Agent 可直接调用的结构化能力

这是 Modern Web Guidance 最大的架构创新——**不写文档给人看，写「技能」给 Agent 用**。

传统 Web 文档：**MDN / web.dev / CSS-Tricks** → 面向人类阅读、长文本、搜索依赖关键词、Agent 难以精准检索  
Modern Web Guidance：**结构化指南 + CLI 检索 + Agent 技能协议** → 面向 Agent 消费、Token 高效、语义搜索、上下文注入

| 维度 | 传统文档 | Modern Web Guidance 指南 |
| --- | --- | --- |
| 目标受众 | 人类开发者 | **AI 编码 Agent** |
| 内容粒度 | 完整教程/参考页 | **单一特性/模式的最小可行指南** |
| Token 效率 | 低（含大量背景/示例/历史） | **高（Eval 剪枝模型已知内容，仅保留「模型易错/不知」部分）** |
| 检索方式 | 关键词/目录 | **语义搜索 + ID 精准检索 + Legacy Scan 反向映射** |
| 更新机制 | 版本发布/人工维护 | **Eval 持续校准 + 社区贡献 + Baseline 兼容性数据同步** |

**指南结构标准化**（每个指南包含）：

```
# 特性 ID: `animate-to-from-top-layer`  
## 适用场景：何时使用  
## 核心模式：最小可行代码骨架  
## 关键注意点：Agent 易踩的坑（API 误用/兼容性/性能/无障碍）  
## 兼容性：Baseline 状态 + caniuse-lite 数据  
## 负责任的降级：轻量 Polyfill / 优雅降级策略  
## 关联指南：上下游/替代/组合特性
```

**实测体验**：Agent 遇到「做一个模态框背景动画」任务 → 调用 `search "animate a dialog modal backdrop"` → 获得 `animate-to-from-top-layer` 指南 → 上下文注入 → **Agent 直接生成使用 View Transitions API + `::backdrop` 的现代实现，而非 jQuery 动画或 CSS animation hack**。

#### 2. 「六大核心领域 × 250 特性」：系统性覆盖而非碎片化补丁

指南体系按 **Web 平台能力维度** 系统组织，而非零散 API 罗列：

| 领域 | 典型特性示例 | 覆盖数量级 |
| --- | --- | --- |
| **🎨 User Experience** | View Transitions、Entry/Exit Animations、Parallax Scroll、CSS `scrollbar-color`、`::backdrop`、Scroll-driven Animations | ~40 |
| **📐 CSS Layout** | Container Queries、`subgrid`、OKLCH 色彩空间、`text-wrap: balance/pretty`、`line-height: trim`、`:has()`、`:focus-visible`、CSS `@scope`、`@starting-style` | ~55 |
| **⚡ Performance** | Instant Preloading（Speculation Rules）、INP 诊断、`scheduler.yield()`、`content-visibility`、Priority Hints、Early Hints | ~30 |
| **📝 Forms & UI** | Anchor Positioning（Tooltip/Popover）、Popover API、`<dialog>`、`:user-invalid` 验证、Auto-sizing Fields、`field-sizing` | ~35 |
| **♿ Accessibility** | Screen Reader 可操作性、键盘导航、内容可发现性、ARIA 现代模式、Forced Colors、`:focus-visible` 语义 | ~25 |
| **🤖 Built-in AI** | Translation API、Summarization API、Language Detection API、Prompt API（提案阶段） | ~15 |

**特性总数：250+**（README 明确列出），且**持续同步 Baseline（基线）状态**——只有达到「新建立可用」或「广泛可用」的特性才纳入指南，**避免 Agent 生成仅在 Canary/Flag 下工作的代码**。

#### 3. 「Eval 驱动剪枝」：用持续评测保证「指南对 Agent 真有效，而非对人类好看」

这是 Modern Web Guidance 最硬核的工程实践——**把「指南质量」变成可量化、可回归、可优化的指标**。

**Eval 流水线**（package.json scripts 可见）：

```
1. 生成评测用例：从指南自动衍生「任务描述 + 期望代码模式 + 反模式」  
2. 多 Agent × 多模型跑评测：Claude Code (Opus/Sonnet) / Codex CLI (GPT-6.1) / Antigravity CLI (Gemini)  
3. 自动打分：Grader 模型判定「生成代码是否符合指南模式 / 是否包含反模式 / 是否有兼容性问题」  
4. 计算 Uplift：Unguided（无指南）vs Guided（注入指南）的通过率差值  
5. 剪枝决策：Uplift 低 / Token 占比高 / 模型已掌握的指南 → 标记剪枝或重写  
6. 发布技能包：仅保留高 Uplift、高 Token 效率的指南
```

**实测数据**（README 2024-11 近期跑分，多轮一致）：

| Agent + Model | Tasks / Checks | Unguided → Guided | Uplift |
| --- | --- | --- | --- |
| **Antigravity CLI (Gemini 4 Argon)** | 214 / 1673 | 58% → 94% | **+36pp** |
| **Claude Code (Opus 5.5)** | 215 / 1801 | 57% → 88% | **+31pp** |
| **Codex CLI (GPT-6.1)** | 215 / 1795 | 54% → 82% | **+28pp** |
| **Antigravity CLI (Gemini 3.8 Flash)** | 166 / 1344 | 60% → 93% | **+33pp** |
| **Claude Code (Sonnet 5.5)** | 166 / 1382 | 54% → 89% | **+35pp** |

**关键洞察**：

* • **Baseline 很低**：无指南时 Agent 仅 52-60% 通过率 → **训练数据滞后导致现代 API 掌握度极低**
* • **指南极其有效**：+19pp 到 +36pp 提升 → **结构化指南 + 上下文注入** 比单纯 Prompt Engineering 强得多
* • **模型差异大**：Gemini 受益最大（+33-36pp）、GPT 其次（+22-33pp）→ **不同模型的知识盲区不同，指南需针对性校准**

#### 4. 「Legacy Scan」：把「代码库现代化」变成一条命令的自动化审计

除了「指导 Agent 写新代码」，Modern Web Guidance 还提供 **反向能力：扫描现有代码库，找出可现代化的遗留模式**。

```
npx modern-web-guidance@latest legacy-scan .
```

**扫描能力**：

| 检测类别 | 典型遗留模式 | 现代替代目标 |
| --- | --- | --- |
| **动画/过渡** | jQuery `.animate()` / CSS `animation` 手动关键帧 | View Transitions API / `::backdrop` / `@starting-style` |
| **布局** | Float/Flex 复杂布局 / 媒体查询断点硬编码 | Container Queries / `subgrid` / CSS Grid / `flex-wrap: balance` |
| **颜色** | HEX/RGB/HSL 硬编码 / Sass 变量 | OKLCH / 相对色彩语法 / `color-mix()` / CSS 自定义属性 |
| **表单/验证** | 手写验证逻辑 / 自定义 Tooltip/Popover | `:user-invalid` / Popover API / Anchor Positioning / `<dialog>` |
| **性能** | 手动预加载 / 长任务阻塞主线程 | Speculation Rules / `scheduler.yield()` / `content-visibility` |
| **无障碍** | 缺失 ARIA / 焦点管理混乱 | 语义化 HTML / `:focus-visible` / 现代 ARIA 模式 |

**输出**：每个匹配项给出 **文件位置 + 遗留模式描述 + 对应指南 ID + 现代化代码骨架**，Agent 可直接按指南逐个重构。

#### 5. 「多 Agent 原生集成」：把「技能包」做成生态标准接口，而非单一工具绑定

Modern Web Guidance **不绑定单一 Agent**，通过 **标准技能协议** 实现多生态分发：

| 集成方式 | 安装命令 | 适用场景 |
| --- | --- | --- |
| **npx skills (Vercel Agent Skills)** | `npx skills add GoogleChrome/modern-web-guidance` | 通用、项目级、CI/CD 友好 |
| **Claude Code Plugin** | `claude plugin install modern-web-guidance@claude-plugins-official` | Claude Code 用户、插件市场自动更新 |
| **Copilot CLI Plugin** | `/plugin marketplace add GoogleChrome/modern-web-guidance` → `/plugin install modern-web-guidance@googlechrome` | GitHub Copilot CLI 用户 |
| **Antigravity CLI** | `agy plugin install https://github.com/GoogleChrome/modern-web-guidance` | Antigravity 用户 |
| **CLI 直用（无技能协议）** | `npx modern-web-guidance@latest search/retrieve/legacy-scan` | 临时用、脚本集成、无技能协议环境 |

**技能包可选安装**（`--choose` flag）：

| 技能包 | Token 预算 | 覆盖范围 |
| --- | --- | --- |
| `modern-web-guidance` | ~205 tokens | 核心 250 特性指南（6 大领域全覆盖） |
| `chrome-extensions` | ~175 tokens | Manifest V3、Background Workers、Extension APIs、Chrome Web Store 发布 |

**Token 预算极其克制**：**单包 < 210 tokens**，注入上下文窗口**边际成本极低**，且 **Eval 保证每个 token 都有正向 Uplift**。

#### 6. 「浏览器厂商联合维护 + Baseline 数据源」：权威性与时效性的双重保障

| 维度 | 传统社区维护指南 | Modern Web Guidance |
| --- | --- | --- |
| **维护主体** | 个人/小团队 | **Google Chrome + Microsoft Edge + Mozilla Firefox + MDN 团队** |
| **兼容性数据** | 手动更新 / caniuse 抓取 | **直接集成 `@mdn/browser-compat-data` + `caniuse-lite` + `web-features` + `Baseline` 官方数据源** |
| **标准跟踪** | 被动跟进 | **WHATWG/W3C/IETF 规范变更 → 自动同步 → 指南更新 → Eval 回归** |
| **浏览器实现信号** | 博客/Release Notes | **厂商内部实现进度 → 提前布局指南 → 发布同步上线** |
| **社区贡献** | PR 审核 | **CONTRIBUTING.md 规范 + GOVERNANCE.md 治理 + 多厂商 CODEOWNERS** |

**数据依赖链**（package.json 可见）：

```
@mdn/browser-compat-data (8.1.7)  → 权威兼容性矩阵  
caniuse-lite (1.0.30001806)       → 细粒度版本支持  
web-features (3.45.0)             → Web Platform Features 标准化元数据  
Baseline (web-features 内置)       → 「新建立可用/广泛可用」官方分级  
mdn-data (2.29.0)                 → MDN 内容结构化数据
```

### 行业影响

**它与「MDN / web.dev / CSS-Tricks / 框架官方文档 / 公司内部 Wiki / Copilot 内置知识」的区别在于**：

| 维度 | MDN/web.dev | 框架文档 | 公司内部 Wiki | Copilot 内置 | **Modern Web Guidance** |
| --- | --- | --- | --- | --- | --- |
| 目标受众 | 人类 | 人类 | 人类/团队 | Agent（黑盒） | **Agent（白盒技能）** |
| 内容粒度 | 完整参考 | 框架 API | 业务/技术规范 | 隐式训练数据 | **单一特性最小可行指南** |
| Token 效率 | 无概念 | 无概念 | 无概念 | 无概念 | **Eval 驱动剪枝，仅保留高 Uplift 内容** |
| 检索精度 | 搜索引擎 | 目录/搜索 | 搜索/标签 | 向量检索（不透明） | **语义搜索 + ID 精准 + Legacy Scan 反向** |
| 兼容性权威性 | 高 | 中 | 低 | 不可知 | **Baseline 官方 + 多厂商联合维护** |
| 评测驱动 | 无 | 无 | 偶尔 | 黑盒 | **持续多 Agent × 多模型 Eval + Uplift 量化** |
| 遗留代码现代化 | 无 | 迁移指南 | 人工 | 无 | **Legacy Scan 自动化审计 + 指南映射** |
| 生态集成 | 无 | 无 | 无 | 仅 Copilot | **npx skills / Claude Code / Copilot CLI / Antigravity / CLI** |
| 许可证 | CC-BY / 专有 | MIT/Apache | 专有 | 专有 | **Apache-2.0 + CC-BY 4.0（商业友好、可再分发）** |

**行业信号**：

* • **「Agent 技能包」正成为「平台知识分发」的新标准形态**：浏览器厂商不再只写文档，开始写「Agent 可直接消费的技能」
* • **「Eval 驱动指南剪枝」建立了「Agent 教育内容质量」的量化标准**：不再凭直觉写指南，用 Uplift 数据说话
* • **「Baseline + 多厂商联合维护」解决了「Web 平台知识碎片化、滞后、不准」的信任危机**
* • **「Legacy Scan」开启了「存量代码库 AI 现代化」的自动化审计新赛道**
* • **「Token 预算显式化（~205 tokens/包）」确立了「上下文窗口资源经济学」在 Agent 技能设计中的核心地位**
