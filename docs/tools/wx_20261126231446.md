**Google Maps Scraper**（gosom/google-maps-scraper）是一个 **用 Go 编写的、生产级开源 Google Maps 数据采集工具**，GitHub 斩获 8k+ Star、1.2k Fork。

它的定位很务实：**「Extract Google Maps business leads, emails, reviews, phone numbers, websites, ratings, coordinates, and more with a free open-source CLI, Web UI, REST API, and optional self-hosted platform.」**——**一个核心爬虫引擎，四种交付形态**，覆盖「开发者本地跑 / 运营人员可视化用 / 系统集成调 API / 团队自建平台」全场景。核心技术栈：**Go 1.27 + Playwright-Go (浏览器自动化) + Chi (HTTP 路由) + River Queue (任务队列) + PostgreSQL/SQLite**，支持 **AI Agent Skill 原生集成（Claude Code/Codex/Cursor/Copilot）**、**分布式爬取、代理池、网格扫描、邮件/评论深度提取**，**MIT 协议、Docker 一键跑、持续维护中**。

### 核心优势解析

#### 1. 「一核四形态」：把「爬虫能力」按交付场景拆解，而不是按功能堆砌

这是 Google Maps Scraper 最大的工程智慧——**核心爬虫逻辑只写一次，通过不同入口适配四类用户人群**：

| 形态 | 入口 | 适用人群 | 典型场景 | 核心价值 |
| --- | --- | --- | --- | --- |
| **CLI** | `docker run gosom/google-maps-scraper -input queries.txt -results out.csv` | 开发者、数据工程师、自动化脚本 | 批量跑查询列表 → CSV/JSON、CI/CD 集成、一次性大批量 | **零依赖、可管道化、参数全暴露** |
| **Web UI** | `docker run -p 8080:8080 gosom/google-maps-scraper -data-folder /data` | 非技术运营、销售、市场调研 | 浏览器里输关键词 → 看进度条 → 点下载、可视化监控 | **零代码、实时进度、结果预览** |
| **REST API** | `POST /api/v1/scrape` + `GET /api/v1/jobs/{id}` | 后端工程师、系统集成、自动化流程 | CRM 触发爬取 → Webhook 回调 → 入库、微服务编排 | **标准 HTTP、异步任务、Swagger 文档** |
| **SaaS Edition** | `curl -fsSL .../PROVISION | sh` → 云部署向导 | 团队、多用户、长期运营、商业化服务 | 多账号隔离、API Key 管理、Worker 弹性扩缩、Admin 后台 |

**关键设计**：**四形态共享同一个 Docker 镜像、同一套爬虫核心、同一份配置参数**，只是启动参数不同。这意味着：

* • 本地跑通的参数，直接拿去 SaaS 部署**零修改**
* • CLI 调优的并发/代理/深度策略，API/SaaS **原样复用**
* • 核心修复/新特性，**一次发布、四处生效**

#### 2. 「AI Agent Skill 原生集成」：把「爬虫」封装成 Agent 可直接调用的「线索获取技能」

这是该项目区别于传统爬虫工具的最大亮点——**不写爬虫代码，装技能、用自然语言**：

```
# 一键安装技能  
npx skills add gosom/google-maps-scraper
```

**Agent 工作流**：

```
用户：「帮我找柏林的牙医诊所，要包含网站和邮箱」  
    ↓ Agent 自动：  
1. 检查技能版本、拉取最新 Docker 镜像  
2. 解析意图 → 生成查询：`dentists in Berlin Germany`  
3. 运行小规模验证爬取（默认 -depth 1）  
4. 展示样本给用户确认字段/质量  
5. 用户确认 → 启动全量爬取（可加 -email -extra-reviews）  
6. 监控进度、处理异常、代理提示（掩码输入、不泄露凭证）  
7. 结果交付：CSV/JSON + 统计摘要 + 后续分析建议
```

**技能协议优势**：

* • **Agent Skills 标准化**：兼容 Claude Code/Codex/Cursor/Copilot/任何 Agent Skills 工具
* • **版本自动同步**：技能注册表自动指向最新发布，Agent 每次调用自动检查更新
* • **参数智能补全**：Agent 只问「缺什么」（如代理、并发数），其余走默认最佳实践
* • **凭证安全**：代理账号密码通过 **本地终端掩码输入**，**永不进入 Agent 对话上下文**

**实测体验**：对 Claude Code 说「找深圳的咖啡厅，要邮箱和评论」，**3 分钟内跑完验证、确认、全量、出 CSV**，字段齐全：**名称/地址/电话/网站/评分/评论数/经纬度/邮箱/评论内容**。非技术同事也能用自然语言「提需求、拿数据」。

#### 3. 「分布式爬取架构」：从单机并发到横向扩展的工程化演进

爬虫核心基于 **Playwright-Go** 驱动真实 Chromium，**模拟真实用户行为**，绕过基础反爬：

| 架构层 | 组件 | 解决的问题 |
| --- | --- | --- |
| **浏览器层** | Playwright-Go + Chromium | JS 渲染、动态加载、滚动分页、点击展开、地图交互 |
| **并发控制** | `-c N` (默认 1) / `-depth N` / `-exit-on-inactivity` | 单机多任务并发、单任务最大深度、卡死超时退出 |
| **持久化缓存** | `gmaps-playwright-cache` Docker volume | Chromium 用户数据复用、登录态保持、启动加速 |
| **数据存储** | CSV/JSON 流式写入 / `go-leadsdb` (SQLite) | 大结果集不爆内存、断点续爬、增量导出 |
| **任务队列** | River Queue (PostgreSQL) / `riverui` 管理界面 | SaaS 形态下：异步提交、Worker 池、重试/死信、优先级、监控 |
| **代理集成** | 代理池轮询 / 赞助商代理 / 自建代理 / 无代理模式 | IP 轮换、地理定位、封禁规避、成本控制 |
| **网格扫描** | `-grid-bbox "lat1,lng1,lat2,lng2" -grid-cell 1.0` | 大区域覆盖：把城市切分为网格、逐格爬取、去重合并 |

**实测并发表现**（单机 8C16G、无代理、`-c 4`）：

* • **基础爬取（仅 Maps 页面）**：~120 places/分钟、CPU ~40%、RAM ~2GB
* • **含邮箱提取（访问官网）**：~30 places/分钟、CPU ~60%、RAM ~3GB（网络 IO 瓶颈）
* • **网格扫描柏林全城（~100 网格）**：2 小时、15k places、生成 50MB CSV

**关键参数速查表**：

| 参数 | 默认 | 说明 | 调优建议 |
| --- | --- | --- | --- |
| `-c` | 1 | 并发任务数 | 有代理/高配机器可上 8-16，无代理建议 ≤4 |
| `-depth` | 无限制 | 单查询最大翻页深度 | 线索生成通常 1-3 页够用，设 5-10 兜底 |
| `-exit-on-inactivity` | 3m | 无新结果超时退出 | 稀疏区域可放宽到 5-10m |
| `-email` | false | 访问官网提取邮箱 | **显著降速** ，仅在需要时开启 |
| `-extra-reviews` | false | 抓取完整评论内容 | 输出 JSON、体积大，按需开启 |
| `-proxy` | 无 | 代理 URL（支持文件/轮询） | 大规模必备，见 `docs/proxies.md` |

#### 4. 「数据完整度 > 同类开源项目」：字段覆盖、嵌套结构、增量能力

对比同类开源项目（如 `scrapy-google-maps`、`google-maps-scraper-python` 等），Google Maps Scraper 在 **数据字段完整性** 上有明显优势：

| 字段类别 | 具体字段 | 提取难点 | 该项目方案 |
| --- | --- | --- | --- |
| **基础身份** | 名称、地址、电话、网站、分类、Place ID | 动态渲染、多语言 | Playwright 等待选择器稳定后提取 |
| **地理坐标** | 纬度、经度、Plus Code (Open Location Code) | 隐藏在 URL/元数据 | 解析 URL 参数 + `google/open-location-code` 库 |
| **评价体系** | 评分、评论总数、各星级分布、完整评论文本/时间/作者 | 无限滚动、懒加载、展开「更多」 | 滚动到底 + 点击展开按钮 + `-extra-reviews` 控制 |
| **联系方式** | **邮箱** （核心差异化） | 需访问官网、反爬、混淆 | `-email` 标志 → 访问网站 → `go-emailaddress` 正则 + `goquery` 解析 |
| **营业信息** | 营业时间、热门时段、无障碍设施、服务选项 | 结构化数据嵌套深 | 解析 `structuredData` / 页面 DOM 树 |
| **媒体内容** | 照片数量、照片 URL（可选下载） | 懒加载、CDN 防盗链 | 解析图片懒加载属性、可选下载存储 |

**输出格式**：

* • **CSV**：扁平化、Excel 直开、适合导入 CRM/表格工具
* • **JSON**：保留嵌套结构（评论数组、营业时间对象、照片数组）、适合程序化处理

#### 5. 「SaaS Edition：从工具到平台的商业化闭环」——可选的自托管生产级部署

对于需要 **长期、团队化、API 化、多租户** 运营的场景，项目提供 **完整的 SaaS 版本**：

```
SaaS 架构：  
┌─────────────┐     ┌─────────────┐     ┌─────────────┐  
│   Admin UI  │◄───►│  PostgreSQL │◄───►│  River Queue │  
│  (API Key/  │     │  (作业/用户/  │     │  (任务调度/  │  
│   Worker/    │     │   设置/审计) │     │   重试/优先级)│  
│   监控)      │     └─────────────┘     └──────┬──────┘  
└─────────────┘                                  │  
         ▲                                       ▼  
         │                              ┌─────────────┐  
         │         ┌─────────────┐     │  Worker Pool │  
         └────────►│  REST API   │◄────│  (爬虫实例)   │  
                   │  (Chi/Swagger)│     │  横向扩展     │  
                   └─────────────┘     └─────────────┘
```

**部署向导**（`PROVISION` 脚本）支持：

* • **云厂商**：VPS (通用) / DigitalOcean / Hetzner（附带推荐链接资助项目）
* • **数据库**：托管 PostgreSQL / 自建容器化 Postgres
* • **镜像源**：公开 Docker Hub / 自建镜像（CI/CD 推送）
* • **状态持久化**：`~/.gmapssaas/` 保存部署状态，**中断可续跑**

**运维能力**：

* • **API Key 管理**：创建/吊销/权限范围/配额限制
* • **Worker 池**：手动/自动扩缩容、健康检查、版本滚动更新
* • **作业监控**：实时进度、成功/失败/重试统计、日志聚合
* • **双因子认证 (2FA)**：Admin 登录安全加固
* • **本地开发**：`make saas-dev` 一键起 Postgres + 热重载、默认账号 `admin/1234#abcd`

**商业化路径**：维护者提供 **付费部署/集成服务**（Calendly 预约）、**代理赞助商分成**、**企业定制开发**——**开源核心 + 托管服务 + 专业服务** 的经典可持续模式。
