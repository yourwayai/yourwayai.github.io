**PiBot**（w01fb0ss/PiBot）是一个 **开源的、本地优先的「多 AI Agent 团队桌面应用」**，GitHub 新建于 2026-11-21，短期斩获 210 Star。它的定位极其清晰：**「An open-source, local-first AI agent team for your desktop.」**——**不做云端 SaaS、不做单一助手，做「一台电脑上跑一整个 AI 团队」**。

核心架构：**Electron (桌面) + React Native/Expo (Android) + TypeScript + pi agent kernel (npm 依赖，脑层与 Electron 解耦) + `@anthropic-ai/sandbox-runtime` (命令沙箱)**。核心能力：**命名 Bot + 角色分工 + 群聊协调器 + 沙箱命令/文件/浏览器 + 审批引擎/审计日志 + 连接器(MCP/知识库/本地应用) + 例程/触发器 + 记忆隔离 + 手机/Runner 远程协作 (E2E 加密/中继仅转密文) + 本地模型/Ollama/OpenRouter/自带 Key**。**Apache-2.0 协议、无遥测、密钥进系统凭据库、多平台原生分发 (macOS/Windows/Linux/Android/Runner)**。

### 核心优势解析

#### 1. 「Bot 群聊 + 协调器」：把「单一助手」升级为「有分工、有交接、有进度的 AI 团队」

这是 PiBot 最大的交互范式创新——**不再是「你对着一个 AI 说话」，而是「你在一个群里指挥一组专业 Bot」**。

| 传统单一助手 | PiBot Bot 群聊 |
| --- | --- |
| 一个模型、一套人设、一个上下文 | **多个 Bot：各自名字/角色/模型/技能/权限/记忆** |
| 复杂任务全靠提示词拆解 | **群聊有「协调器」：先规划 → 拆分步骤 → 分派给成员 → 汇总结果 → 你确认计划后再执行** |
| 无法并行、无法交接 | **并行协作：Researcher 搜资料 → Writer 写初稿 → Translator 翻译 → 协调器汇总** |
| 进度不可见、中途插手难 | **侧边栏实时进度面板：五步计划、三个子任务、每步完成状态、产物预览** |
| 上下文污染、指令冲突 | **物理隔离：Bot 间仅通过协调器交接产物、不共享完整上下文、各自独立模型预算** |

**官网演示案例**：「Pi (协调器) + Researcher + Writer」三 Bot 群聊协作产出一份 Newsletter：

```
Pi 的任务面板：  
├── 步骤 1：Researcher 搜集本周 AI 资讯 (进行中...)  
├── 步骤 2：Writer 撰写初稿 (等待中)  
├── 步骤 3：Researcher 补充技术细节 (等待中)  
├── 步骤 4：Writer 定稿润色 (等待中)  
└── 步骤 5：Pi 审核发布 (等待中)
```

**你只需在群里说「帮我做本周 AI 周报」，协调器自动规划、分派、汇总，每关键节点 @你确认，侧边栏实时看进度、看产物预览。这不再是「聊天」，是「项目管理」。**

#### 2. 「沙箱执行 + 审批引擎 + 审计日志」：把「危险操作」变成「可审计、可回滚、可策略化的受控动作」

这是 PiBot 区别于「MCP/Function Calling/Computer Use」架构的核心工程护城河——**不给模型「裸奔权限」，给模型「受控运行时 + 策略引擎 + 人工闸口」**。

| 维度 | 传统 Computer Use / MCP | PiBot |
| --- | --- | --- |
| **命令执行** | 直接在宿主 Shell 跑 | **`@anthropic-ai/sandbox-runtime` 隔离沙箱 (macOS/Linux) / Windows 无沙箱但逐条确认** |
| **文件写入** | 直接落盘 | **变更列表 → 侧边栏预览 Diff → 你确认 → 落盘 → macOS 自动检查点可一键还原** |
| **浏览器操作** | 模型直接控制 | **Bot 专属浏览器实例：密码/Token 仅以「占位符」进模型、从不以明文出现** |
| **审批策略** | 无/全局开关 | **统一策略引擎：文件/命令/浏览器/计算机使用 各自独立权限等级 + YOLO 会话级自动通过(显式拒绝永久生效) + 审计日志全记录** |
| **撤销能力** | 无/极难 | **每次写入可回滚、macOS 检查点自动、拒绝记录永久生效、YOLO 仅当前会话** |

**关键设计**：**`packages/teams/builtin` 内置角色库 (pibot-roles 完整版) 离线可用**、**每个工具调用都过统一策略引擎**、**审计日志包含：审批/命令/文件写入/例程/外发内容、时间戳、决策者**。这把「Agent 自主性」从「全有或全无」变成了「分级授权、全程留痕、随时收回」。

#### 3. 「手机 + Runner + 中继」：把「桌面端 AI 团队」延伸为「多设备协作网络」

PiBot 不止一台电脑——**构建了「电脑(大脑) + 手机(遥控/离线大脑) + Runner(远程执行臂) + 中继(打洞/兜底)」的四节点拓扑**：

| 节点 | 角色 | 核心能力 | 连接方式 |
| --- | --- | --- | --- |
| **Desktop (大脑)** | 核心调度、存储、密钥、审计 | Bot 运行、群聊协调、文件/命令/浏览器、连接器、例程、记忆、模型调用 | — |
| **Android Phone** | 移动端入口、离线大脑备用 | 发任务、看进度、批审批、预览结果、**电脑离线时直接调模型、指挥 Runner** | 直连局域网 → 打洞 → 官方中继 (E2E 加密、中继不解密) |
| **Runner** | 远程执行环境 | 在项目所在机器跑命令/改文件、**输出/退出码/变更列表回传、不传文件夹** | 电脑预签名 24h 有效授权、Runner 自带策略副本二次校验、**每命令手机确认** |
| **Relay (Cloudflare Worker)** | 打洞兜底 | 仅转发密文、不存内容、不解密 | 可自建、可禁用 |

**四大数据流场景**（官网演示）：

1. 1. **手机拍发票 → 电脑读照片(去位置)→ 生成报销表 → 手机收预览** (照片进模型端，其余本地)
2. 2. **电脑让 Bot 总结文件夹 PDF** (仅读 Bot 权限内文件、发模型所需文本、写入需确认、可回滚)
3. 3. **手机指挥 Windows Runner 跑测试** (命令电脑审核 → 手机确认 → Runner 执行 → 回输出/变更)
4. 4. **电脑关机/离线 → 手机成离线大脑** (模型设置/Key 同步至手机、直连模型、指挥 Runner、每命令手机确认、上线后同步回电脑)

**安全承诺**：**端到端加密、中继不解密、手机数据(照片/短信验证码)各有开关、Runner 授权 24h 过期、Windows 命令无沙箱强制逐条确认**。这让「多设备协作」不再是「安全妥协」，而是「威胁模型显式建模、每环节可验证」。

#### 4. 「连接器生态 + 例程引擎」：把「AI 团队」接入你的「数字基建」

PiBot 不想做孤岛——**通过「连接器」把 Bot 接入你已有的应用、知识库、MCP 服务**：

| 连接器类型 | 典型示例 | 读/写权限控制 |
| --- | --- | --- |
| **本地应用** | 日历、联系人 (macOS/Windows/Linux 原生) | 读默认开、写需逐次确认 |
| **知识库** | Notion、Obsidian (本地文件/云同步) | 仅读、不写 |
| **MCP 服务** | 任意 MCP Server (stdio/SSE) | 按 MCP 协议协商、PiBot 策略引擎二次把关 |
| **Skills** | 从本机其他 AI 工具迁移的技能包 | 按技能声明的权限申请 |

**例程引擎**（Routines）：

* • **定时触发**：「每天 9 点 Sales Follow-up 群聊跟进线索」
* • **文件夹变更触发**：「`invoices/` 有新文件 → Bookkeeper 群聊处理」
* • **连接触发**：「日历新增会议 → Researcher 准备背景资料」
* • **错过/需决策** → 落入收件箱，**不静默失败、不越权执行**

**实测体验**：配置「每周一早 9 点自动让 Researcher+Writer 群聊产出周报」，周一打开电脑，**侧边栏已有草稿、进度面板显示各步完成度、只需审核发布**。这把「重复性知识工作」从「人工触发」变成了「基础设施级自动化」。

#### 5. 「记忆隔离 + 隐私优先」：把「长期记忆」做成「可视、可编辑、可隔离、不漏」的结构化资产

| 记忆作用域 | 存储位置 | 可见性 | 编辑权 |
| --- | --- | --- | --- |
| **用户级** | 本地 SQLite (规划) / 当前内存 | 你可见 | 你可增删改 |
| **Bot 级** | 每 Bot 独立 | 你可见 | 你可管每个 Bot 的记忆 |
| **群聊级** | 每群聊独立 | 你可见 | 你可管群聊共享记忆 |
| **项目级** | 每工作文件夹独立 | 你可见 | 你可管项目记忆 |

**官网演示**：Memory 面板按类别列出「用户偏好 / Bot 专业知识 / 群聊协作约定 / 项目上下文」，**每条记忆可编辑/删除/置顶**，**模型仅在相关作用域激活时读取对应记忆**。这解决了「长期记忆污染/不可控/不可审计」的通病。

**隐私架构硬核承诺**：

* • **无遥测、无分析、崩溃不自动上报、用户决定提交什么**
* • **模型 Key 进系统凭据库、界面不回显、日志不记 Authorization/正文/载荷**
* • **首次向服务发内容前展示目标域名和数据说明**
* • **设备间 E2E 加密、中继仅转密文、可自建中继**
* • **本地模型 (Ollama) 请求完全不出设备**

#### 6. 「pi agent kernel + 脑层解耦」：把「Agent 核心逻辑」从「Electron」剥离，实现「同一套脑、多种运行时」

PiBot 的代码组织极其清晰（仓库结构可见）：

```
packages/  
├── agent/           # pi kernel (npm 依赖，仅此处使用)  
├── brain/           # 核心逻辑：规划、工具、记忆、策略、记忆、模型适配 —— **不依赖 Electron**  
├── teams/builtin    # 内置角色/群聊库 (离线可用，完整版 pibot-roles)  
├── ...              # 其他能力层  
apps/  
├── desktop/         # Electron 主进程/渲染进程/打包  
├── mobile/          # React Native + Expo (Android)  
├── relay/           # Cloudflare Worker (中继)  
├── runner/          # 无头 Runner (同脑层代码)  
└── cli/             # 命令行入口
```

**架构红利**：

* • **同一套脑层代码**跑在 Electron / Runner / CLI / (未来) 服务端
* • **pi kernel 仅作 npm 依赖锁版本**，不污染脑层、便于升级/回滚/审计
* • **脑层可单元测试、可无头跑、可集成进其他宿主**
* • **Runner/手机离线模式复用脑层，仅网络/存储/权限适配不同**
