# Heretic：全自动「去审查」神器，定向消融+TPE 优化让拒答率从 97% 降到 3%、KL 损失仅 0.16

**Heretic**（p-e-w/heretic）是一个 **全自动的语言模型「去审查」工具**，GitHub 斩获 40.6k Star、4.6k Fork。它的定位极其激进：**「Fully automatic censorship removal for language models」**——**不做微调、不做 RLHF、不做人工参数调优，只做「一条命令、全自动、可复现」的消融**。核心技术栈：**Python + PyTorch + Optuna (TPE 优化器) + Hugging Face Transformers**，**AGPL-3.0 协议、独立开发者 Philipp Emanuel Weidmann 主导、211 次提交持续迭代中**。支持 **稠密模型、多模态、MoE、混合架构 (如 Qwen3.5)**，纯状态空间模型暂不支持。

### 核心优势解析

#### 1. 「全自动化」：把「去审查」从「手工黑盒」变成了「可复现工程流水线」

这是 Heretic 最大的工程贡献——**消除了「去审查需要人工反复试错」的门槛**。

传统消融/去审查流程：

```
人工选层 → 人工定权重 → 跑基准 → 看拒答率 → 看智力损失 → 调参 → 循环 N 次 → 可能发布  
耗时：数天-数周 / 需懂 Transformer 内部 / 结果难复现 / 依赖专家直觉
```

Heretic 流程：

```
pip install -U heretic-llm  
heretic Qwen/Qwen3-4B-Instruct-2507  
# 自动：基准系统 → 搜索残差方向 → Optuna TPE 优化消融参数 → 共同最小化拒答+KL → 产出模型  
耗时：RTX 3090 約 20-30 分钟 / 无需懂内部 / 结果可复现 / 任何会跑 CLI 的人都能用
```

**关键指标对比**（README 实测，Gemma-3-12b-it，PyTorch 2.8 + RTX 5090）：

| 模型 | "有害"提示拒答数 (↓) | "无害"提示 KL 散度 (↓) | 备注 |
| --- | --- | --- | --- |
| google/gemma-3-12b-it (原版) | 97/100 | 0 (基准) | — |
| mlabonne/gemma-3-12b-it-abliterated-v2 (手工 v2) | 3/100 | 1.04 | Maxime Labonne 手工调优 |
| huihui-ai/gemma-3-12b-it-abliterated (手工) | 3/100 | 0.45 | 社区手工消融 |
| **p-e-w/gemma-3-12b-it-heretic (Heretic)** | **3/100** | **0.16** | **全自动、零人工干预** |

**核心洞察**：**同等拒答抑制 (3/100) 下，Heretic 的 KL 散度仅为手工消融的 35%、AutoAbliteration 的 15%**。这意味着\*\*「去审查不再以牺牲模型智力为代价」\*\*，Heretic 找到了「拒答方向」与「保留能力方向」的帕累托最优解。

#### 2. 「三大架构创新」：让自动化搜索真正找到比人工更优解

Heretic 不只是把现有消融算法跑一遍，**在算法层面做了三个关键改进**，才让自动化搜索能超越人工：

| 创新点 | 传统做法 | Heretic 做法 | 效果 |
| --- | --- | --- | --- |
| **消融权重核形状** | 常数权重 / 简单线性衰减 | **高灵活度核函数** ：`max_weight` / `max_weight_position` / `min_weight` / `min_weight_distance` 四参数描述层维分布形状 | 配合 Optuna TPE，搜索空间覆盖「常数/三角/梯形/双峰」等多种形状，自动找到最优分布 |
| **残差方向索引** | 整数层索引 (第 0/1/2... 个方向) | **浮点索引 + 线性插值** ：非整数值时，自动在两个最近方向向量间插值 | **解锁连续方向空间** ，不再局限于差分均值离散出的方向，常能找到「层间插值」更优方向 |
| **组件级独立参数** | 全模型统一参数 / 注意力+MLP 共享 | **注意力输出投影 / MLP 下投影 分别独立优化参数集** | 实测 MLP 干预损害更大，分离参数后「重 MLP 轻注意力」自动涌现，挤出额外性能 |

**工程实现**：**每个 Transformer 组件 (attention out-proj / MLP down-proj) 识别关联矩阵 → 正交化消融 → 参数化权重核 → Optuna TPE 协同优化 (目标：拒答率 + KL 散度加权和)**。搜索空间虽大，但 TPE 的贝叶斯优化特性让收敛极快。

#### 3. 「开箱即用的广泛兼容」：一条命令覆盖主流开源模型生态

| 模型类别 | 支持情况 | 典型示例 |
| --- | --- | --- |
| **稠密解码器** | ✅ 完整支持 | Llama 3/3.1/3.2、Qwen 2/2.5/3、Gemma 2/3、Mistral、Phi、GPT-OSS |
| **多模态** | ✅ 多数支持 | LLaVA、Qwen-VL、Pixtral、InternVL (视觉投影层自动识别) |
| **MoE** | ✅ 多数支持 | Mixtral、DeepSeek-MoE、Qwen-MoE (专家路由层特殊处理) |
| **混合架构** | ✅ 实验支持 | **Qwen3.5 (密集+MoE 混合)** 、Nemotron 3 Ultra |
| **纯状态空间** | ❌ 暂不支持 | Mamba、RWKV、Jamba (架构差异大，需专门实现) |
| **其他研究架构** | ❌ 不支持 | RetNet、xLSTM、Griffin 等 |

**量化支持**：**原生集成 bitsandbytes**，`quantization: bnb_4bit` 即可在 8-12GB 显存跑 7B-14B 模型去审查，**大幅降低硬件门槛**。

#### 4. 「内置评估 + 社区复现」：把「主观好用」变成「可量化、可复现、可对比的基准」

Heretic 不只生成模型，**内置完整评估流水线**：

```
# 评估任意模型 (含对比基准)  
heretic --model google/gemma-3-12b-it --evaluate-model p-e-w/gemma-3-12b-it-heretic
```

**评估维度**：

* • **拒答率**：100 条「有害」提示 (含越狱/敏感/拒答诱导)
* • **KL 散度**：100 条「无害」提示，测原模型 vs 去审查模型输出分布偏移
* • **标准基准**：MMLU / GSM8K / BBH / MMLU-Pro (可选开启)
* • **人类偏好**：可选导出对话供人工标注

**社区验证**：**5000+ 社区发布模型 (Hugging Face `heretic` 标签)**、**独立 Reddit 基准帖 (Abliterlitics) 多轮对比 MMLU/GSM8K**、多位用户实测反馈「最佳去审查版本」。这建立了「去审查质量」的**公开、可复现、可对比**的评估新标准。

#### 5. 「配置预设 + 灵活扩展」：从「零配置跑通」到「精细控制」无缝过渡

Heretic 提供 **4 套官方 TOML 预设**，覆盖不同需求：

| 预设文件 | 适用场景 | 关键差异 |
| --- | --- | --- |
| `config.default.toml` | 通用去审查 | 平衡拒答抑制与能力保留 |
| `config.nohumor.toml` | 去除「过度幽默/人设」 | 针对「滑稽/人设」方向额外消融 |
| `config.noslop.toml` | 去除「废话/重复/拟人化」 | 针对「冗长/重复/过度礼貌」方向消融 |
| `config.piqa.toml` | PIQA 推理任务优化 | 保留常识推理能力为优先 |

**扩展性**：**CLI 参数可覆盖任意配置项、支持自定义提示集合、支持外部评估数据集、预留插件接口给新架构**。这让「科研实验/生产部署/个人折腾」同一工具链无缝切换。

#### 6. 「前沿技术致敬 + 从零重写」：站在巨人肩上，但不复用任何代码

Heretic 明确列出 **6 个前艺术实现** 并声明 **完全从零重写，无代码复用**：

| 前艺术 | 贡献 |
| --- | --- |
| Arditi et al. 2024 | 原始消融论文 (差分均值方向) |
| Maxime Labonne (AutoAbliteration) | 消融权重核形状探索、gemma-3 手工消融基准 |
| Jim Lai (grimjim) | 投影消融 / 范数保持双投影消融 理论基础 |
| FailSpy / wassname / Tsadoq / Sumandora / AUGMXNT | 多种开源消融实现工程参考 |

**学术引用**：提供标准 BibTeX，**鼓励学术使用时引用**，体现开源科研规范。

**行业信号**：

* • **「推理级消融 + 自动参数搜索」确立了「零训练去审查」的新工程范式**：不再需要「微调/RLHF」的算力与数据，**消融是「减法」，比「加法」便宜 1000 倍**
