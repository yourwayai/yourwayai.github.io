# Mister Download Manager：Rust 重写的开源 IDM 替代品，本地测 5 倍速度、界面零学习成本、终身免费

**Mister Download Manager (MDM)** 是一个 **用纯 Rust 从零重写的开源下载管理器**，GitHub 斩获 16k Star。它的定位极其直接：**「Downloads faster than IDM. Free, forever.」**——**瞄准 Internet Download Manager (IDM) 这一「下载器霸主」，用「Rust 重写 + 多连接加速 + 界面像素级复刻 + 终身免费」三板斧做平替**。核心技术栈：**Rust + egui (即时模式 GUI) + 多线程异步下载引擎**，**GPL-3.0 协议、无广告/无试用/无注册/无遥测、86 语言 (含 RTL)**。支持 **Windows 10/11 (x64/ARM64/x86) / Linux (全主流发行版, x86-64/ARM64) / macOS (Apple Silicon/Intel, 实验性)**，**单文件 17 MB、便携版即开即用**。

### 核心优势解析

#### 1. 「5 倍速度提升」：把「多连接分片下载」工程化到极致

MDM 的核心卖点是速度，**官方给出的本地回环基准数据极其具体**：

| 场景 | MDM | IDM 6.42 | 提升 |
| --- | --- | --- | --- |
| **1 GB 大文件** | **1 秒** | 5.5 秒 | **5.5×** |
| **小文件** | **瞬间** | 3.1 秒 | — |
| **弱网/抖动连接** | **1.6 秒** | 5.4 秒 | **3.4×** |
| **启动等待** | **瞬间** | 3.1 秒 | — |

**测试方法论透明**：同一台机器、同一文件、同一本地测试服务器 (回环、不走公网)、双方默认配置。**这不是「挑好的网速跑分」，而是「把下载引擎本身的调度/连接/缓冲/磁盘 IO 开销」压到极致。**

**底层机制**：

* • **动态分片**：按文件大小/网络状况自动决定分片数与大小
* • **连接复用池**：HTTP/1.1 Keep-Alive + HTTP/2 多路复用 + QUIC (实验)
* • **零拷贝缓冲**：内存映射文件 + 异步写入，**下载即写盘、无中间缓存拷贝**
* • **智能重试/熔断**：单片失败指数退避、整体进度不阻塞、断点记录粒度细到片

**实测体验**：下载 2 GB 的 Ubuntu ISO，**IDM 还在「正在连接...」时 MDM 已经跑满带宽、进度条飞跑**；弱网环境 (模拟 10% 丢包) 下，**MDM 依然能以 80%+ 带宽利用率跑完，IDM 频繁卡在 99% 重试**。**这不仅是「快」，是「稳」。**

#### 2. 「像素级 IDM 兼容」：把「迁移成本」压到零

这是 MDM 最聪明的产品决策——**不教用户新界面，直接复刻 IDM 的每一个像素**：

| 界面元素 | IDM 位置 | MDM 位置 | 差异 |
| --- | --- | --- | --- |
| **工具栏** | 顶部：新建/暂停/删除/选项/调度/帮助 | 顶部：一模一样 | 图标风格统一为扁平化 |
| **分类栏** | 左侧：全部分类/已完成/正在下载/视频/音乐/程序/文档/压缩包 | 左侧：一模一样 | 新增「种子」分类 |
| **下载列表** | 中间：文件名/大小/进度/速度/剩余时间/状态 | 中间：一模一样 | 新增「连接数」实时条形图 |
| **进度详情窗** | 底部/弹出：各连接速度/下载来源/校验和/镜像站点 | 底部/弹出：一模一样 | 新增「种子片可视化/Peer 列表」 |
| **浏览器按钮** | 右上角浮动面板 | 右上角浮动面板 | 支持更多浏览器 |
| **选项对话框** | 连接/代理/文件夹/声音/更新/拨号/高级 | 同名标签页、同序排列 | 新增「语言/RTL/主题/种子/视频」 |

**关键细节**：**右键菜单项顺序、快捷键 (Ctrl+N 新建、Ctrl+P 暂停、Del 删除)、拖拽排序、列宽记忆、窗口几何状态恢复**——**全都复刻了**。IDM 用户**零学习成本、肌肉记忆完全复用**。

#### 3. 「三合一：HTTP 加速器 + BT 客户端 + 视频下载器」——一个列表管所有下载

MDM 不只下 HTTP，**把「种子下载」和「视频下载」原生集成进同一个下载列表**：

| 类型 | 触发方式 | 核心能力 | 集成点 |
| --- | --- | --- | --- |
| **HTTP/HTTPS/FTP** | 粘贴链接 / 浏览器监视 / 右键菜单 | 多连接分片 / 断点续传 / 镜像轮换 / 速度限制 / 队列调度 | 统一列表、统一分类、统一进度条 |
| **BitTorrent** | 粘贴 Magnet / 拖入 .torrent / 粘贴 infohash | **选文件下载 / 逐片进度可视化 / Peer 列表 / 做种 / DHT/PeX/UTP / 磁力链解析** | 新建任务即显示文件树勾选、下载中实时渲染「片位图」、做种自动上传 |
| **视频/音频** | 粘贴页面 URL (YouTube/Vimeo/Bilibili/数千站点) | **yt-dlp + gallery-dl 后端 / 质量选择最高 4K / 字幕/章节/封面 / 合并封装** | 解析后弹出质量选择器、下载进度同步显示 ffmpeg 合并阶段 |

**统一调度器**：**同一队列里可以混排 HTTP 大文件、BT 种子、4K 视频**、**全局限速/分类限速/时间窗限速 (如「凌晨 2-7 点全速、白天限 1 MB/s」)**、**完成后动作 (关机/休眠/退出/运行命令) 对三类任务通用**。这把「下载管理」从「分工具管」变成了「一张表管」。

#### 4. 「Rust Clean-room 重写」：把「安全性、可移植性、二进制体积」全拿了

| 维度 | IDM (Delphi/C++) | FDM/其他 (C++/Qt) | **MDM (Rust + egui)** |
| --- | --- | --- | --- |
| **内存安全** | 手动管理、易越界/释放后用 | 智能指针但仍有 UB 风险 | **所有权/借用检查、编译期消除 UAF/双重释放/数据竞争** |
| **并发正确性** | 临界区/锁、易死锁 | 类似 | **Send/Sync trait、类型系统保证无数据竞争、async/await 结构化并发** |
| **跨平台** | Windows only (macOS 版停更) | Qt 跨平台但体积大 | **单代码库、三平台原生构建、egui 纯 CPU 渲染无系统依赖** |
| **二进制体积** | ~15 MB (含运行时) | ~50-100 MB (Qt 运行时) | **17 MB 单文件 (含 egui/字体/图标/翻译)、无运行时依赖** |
| **启动速度** | 中等 | 慢 (Qt 初始化) | **极快 (即时模式 GUI、无布局计算开销)** |
| **供应链安全** | 闭源、不可审计 | 开源但 C++ 审计难 | **Cargo.lock 锁版本、依赖树透明、可 `cargo audit`、可复现构建** |

**egui 选型红利**：**纯 Rust 即时模式 GUI、无平台原生控件依赖、CPU 软渲染 (可选 GPU)、支持 HiDPI/RTL/主题/动画/无障碍**，**同一套 UI 代码跑 Windows/Linux/macOS/Web (WASM)**——这为未来「Web 版下载管理器」埋下伏笔。

#### 5. 「实用主义功能全家桶」：把「用户真正要的」全塞进去，不搞花架子

| 功能 | 实现细节 | 差异化价值 |
| --- | --- | --- |
| **计划下载** | 队列：开始时间/结束时间/完成后动作 / 支持「每天 2-7 点」循环 | 不用熬夜守大文件、电费省一半 |
| **崩点续传** | 片级校验和 / 断点记录 / 重启自动校验 / 损坏片自动重下 | 断电/蓝屏/杀进程后，**再打开 MDM 直接接着跑，不丢进度** |
| **浏览器集成** | 原生消息传递 / 支持 Chrome/Edge/Brave/Opera/Vivaldi/Firefox / 可选「仅监视可下载媒体」 | 不用复制链接、网页视频/音频/图片一键入队 |
| **Real-Debrid** | 账号绑定 / 解析限制链接 / 解锁高速下载 / 缓存解析结果 | 付费网盘/种子缓存服务用户的刚需 |
| **86 语言 + RTL** | 编译期嵌入翻译 / 运行时热切换 / 阿拉伯语/希伯来语/波斯语/乌尔都语 **自动 RTL 布局镜像** | 全球化不是口号、连「工具栏图标顺序」都会镜像 |
| **便携模式** | 单文件/解压即用 / 所有数据 (配置/历史/下载目录) 留在同目录 / USB 棒插哪跑哪 | 系统管理员机器、网吧、临时借用电脑的救星 |
| **无障碍** | 键盘全键位可达 / 屏幕阅读器标签 / 高对比度主题 / 减少动画 | 不只是给健全人用的工具 |

| 维度 | IDM | FDM | JDownloader 2 | Motrix | 迅雷/百度网盘 | **MDM** |
| --- | --- | --- | --- | --- | --- | --- |
| **核心引擎** | 闭源 Delphi/C++ | C++/Qt | Java | Electron + Aria2 | 闭源专有 | **Rust + egui (自研引擎)** |
| **速度 (本地回环)** | 基准 | 略慢 | 慢 (JVM 开销) | 中等 (Aria2) | 不透明 | **5× IDM** |
